# web-desk — 웹 Claude 계정과 주고받는 책상

찬종의 두 번째 Claude 계정(웹 전용 · Pro)에 일을 맡길 때 쓰는 폴더. 설계 에이전트가 **보낼 것**을 만들어 두고, 찬종이 웹에 올려 받은 결과를 **받은것** 에 넣으면, 설계가 검사해서 GEN 에 넘긴다.

```
web-desk/
  README.md            ← 이 파일
  <일 이름>/
    지시서.md          ← 웹에 올릴 문서(일마다 하나 · 프로젝트 지식에 한 번만)
    프롬프트.txt       ← 채팅에 붙여 넣을 글
    보낼것/조각-NN.txt  ← 한 번에 하나씩 올릴 입력
    받은것/결과-NN.json ← 웹이 돌려준 것(찬종이 저장)
    _*.json            ← 설계 검사용 — 웹에 올리지 않는다
```

## 찬종이 하는 일 (일마다 같음)

1. claude.ai 에서 **프로젝트**를 하나 만들고(일 이름으로) `지시서.md` 를 프로젝트 지식에 올린다. — 한 번만.
2. 그 프로젝트에서 **새 채팅** → `보낼것/조각-NN.txt` 하나를 첨부 → `프롬프트.txt` 내용을 붙여 넣고 보낸다.
3. 돌아온 JSON 을 `받은것/결과-NN.json` 으로 저장한다(파일로 주면 내려받아 이름만 맞추고, 코드 블록이면 복사해서 새 파일에 붙여 넣기 · 메모장 저장은 UTF-8).
   - 중간에 끊기면 "계속" 이라고 치고, 이어서 나온 것도 같은 파일 아래에 그대로 붙여 넣으면 된다(설계가 합쳐 읽는다).
4. **조각마다 새 채팅**(한 채팅에 여러 조각을 넣으면 뒤로 갈수록 판정이 흐려진다).
5. 몇 개 쌓이면 설계 창에 "web-desk 확인" 이라고 한다.

## 품질은 어떻게 보장하나

- 조각마다 **이미 판정이 끝난 단어 10개**를 몰래 섞어 뒀다 → 그 10개의 결과로 조각별 점수를 낸다.
- 빠진 단어 · 더해진 단어 · 형식 오류는 기계로 잡는다.
- 점수가 낮은 조각은 버리고 다시 돌린다 — 잃는 것이 없다.
- **첫 조각 하나만 먼저** 돌려서 보여 주면 모델 · 설정이 맞는지 확인하고 나머지를 진행한다.
