# web-desk — 웹 Claude 계정과 주고받는 책상

찬종의 두 번째 Claude 계정(웹 전용 · Pro)에 일을 맡길 때 쓰는 폴더. 설계 에이전트가 **보낼것**을 만들어 두고, 찬종이 웹에 올려 받은 결과를 **받은것** 에 넣으면, 설계가 검사해서 GEN 에 넘긴다.

```
web-desk/
  README.md            ← 이 파일
  <일 이름>/
    지시서.md          ← 프로젝트 "컨텍스트" 에 한 번만 올린다
    프롬프트.txt       ← 프로젝트 "지침" 에 넣어 두거나 채팅에 붙여 넣는다
    보낼것/조각-NN.txt  ← 한 번에 하나씩 첨부
    받은것/결과-NN.json ← 빈 파일이 미리 있다 — 열어서 붙여 넣고 저장
    _*.json            ← 설계 검사용 — 웹에 올리지 않는다
```

## 쓰는 법 (일마다 같음)

1. claude.ai 에서 **일마다 프로젝트 하나**(지시서가 섞이지 않게) → `지시서.md` 를 컨텍스트에 · `프롬프트.txt` 내용을 지침에.
2. **조각마다 새 채팅** → 조각 파일 하나 첨부 → "진행".
3. 돌아온 JSON 을 `받은것/결과-NN.json` 에 붙여 넣고 저장. 끊겨서 "계속" 으로 받은 것도 아래에 그대로 이어 붙인다.
4. 몇 개 쌓이면 설계 창에 "web-desk 확인".

## 원칙 (찬종 2026-11-10)

- **작은 일 여러 개.** 조각 하나가 한 단위 — 한 번에 다 할 필요 없다. 세션 한도가 차기 전에 멈추고 다음에 이어서 한다(조각은 순서 상관없음 · 빈 결과 파일이 남은 것).
- 토큰을 아끼라는 뜻이 아니다 — 한도 100% 로 흐름이 끊기지 않게 하라는 뜻.
- 그래서 여기 올리는 일은 **급하지 않고 · 조각으로 나뉘고 · 중간에 멈춰도 되는 일**만.

## 품질 보장

- 빠진 항목 · 더해진 항목 · 형식 오류는 기계로 잡는다.
- 판정 일은 조각마다 숨긴 확인 단어로 점수를 낸다. 생성 일은 GEN 이 기계 검사(정답 · 변형과 겹침 · 중복 · 길이) + VERIFY 표본.
- 나쁜 조각은 버리고 다시 돌린다.
