조각 02 — 노래 퀴즈를 하는 다른 길 (chunk = "02")

2-1. 노래 맞히기 웹게임 · 앱은 노래를 어디서 가져오나 — 사례 사이트를 직접 열어서: 예) Heardle 류(옛 Heardle · Spotify 인수 뒤) · Bandle · SongTrivia · Song Quiz · 국내 노래 퀴즈 사이트 · 디스코드 노래 봇. 각각 음원이 어디서 오는지(유튜브 퍼가기 · 스포티파이 · 디저 · 애플 · 직접 녹음 등)와 광고가 있는지.
2-2. 유튜브 퍼가기(IFrame Player API)로 노래를 틀고 화면을 가리거나 소리만 쓰는 것이 유튜브 API 약관 · 개발자 정책에 맞는가 — 정책 원문(영상 가리기 · 광고 · 자동 재생 · 오락 용도에 대한 조항).
2-3. 다른 음원 서비스의 미리듣기 조건 원문: 스포티파이(Web API · preview 주소가 지금도 되는지 · 개발자 약관의 게임 · 퀴즈 금지 조항) · 디저(Deezer API 약관) · 애플(아이튠즈 검색 API · Apple Music API · MusicKit 의 미리듣기 조건 — 오락 용도 · 광고 사이트).
2-4. 한국에서 노래 일부(10~30초)를 게임에 쓰려면 받는 허락: 한국음악저작권협회(KOMCA) · 음반 제작자(음실련 · 음산협) · 웹 서비스 사용료 기준이 있는지 · 개인 · 비영리 사용료.
