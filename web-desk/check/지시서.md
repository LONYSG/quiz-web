# 질문 점검 + 난이도 매기기(표본) — 지시서 (v1 · 2026-11-17)

한국어 파티 퀴즈 게임의 일반 상식 문제 카드다. 조각 파일에는 카드가 100장쯤 들어 있다(번호 · 정답 · 질문). **카드마다 두 가지**를 매긴다. 문장을 고치지 않는다 · 검색하지 않는다 · 사실이 맞는지 따지지 않는다(이미 확인된 카드다).

## 1. `q` — 질문이 정답의 "대표 사실"을 묻는가

- `"core"` = 질문이 **그 정답이 무엇으로 유명한가**를 묻는다 — 답을 들으면 누구나 "아, 그거!" 하는 것. 대표 사실에 흥미로운 사실이 **곁들여진** 질문도 core 다.
- `"tidbit"` = 질문이 **곁가지 일화 · 낯선 연도 · 낯선 인명으로만** 서 있다 — 답을 들어도 "그래서 뭐?" 하게 된다. 그런 이야기는 해설에 있어야 한다.

| 정답 | 질문 | q | 기획자의 말 |
|---|---|---|---|
| 3M | 스카치테이프와 포스트잇으로 유명하며, N95 마스크도 개발한 미국 기업은 어디일까요? | core | |
| 3M | 1902년 다섯 사업가가 미네소타에서 채굴 사업으로 세웠으나 광물 때문에 첫 사업에 실패한 미국 기업은 어디일까요? | tidbit | "광물 때문에 첫 사업에 실패했다고만 하면 '뭐 어쩌라고?' 느낌이지 새로운 정보를 얻었다는 느낌이 아니야. 해설 쪽으로 가야 맞는 거 같은데?" |
| 루지 | 1968년 동계 올림픽에서 여자부 메달권 동독 선수들이 썰매 날을 데웠다는 혐의로 실격당한 썰매 종목은 무엇일까요? | tidbit | "해설에나 나올 법한 토막 상식이 질문에 들어가 있는 케이스네." |
| 명왕성 | 2006년 국제천문연맹이 행성의 조건을 새로 정하면서 행성에서 빠지고 왜소행성으로 분류된 천체는 무엇일까요? | core | |
| 명왕성 | 1930년 발견된 뒤 영국의 열한 살 소녀가 로마 신화 속 저승의 신 이름을 제안해 이름 붙은 천체는 무엇일까요? | tidbit | |
| 구미 | 전자·반도체 산업이 발달한 국가산업단지가 있으며, 국내 신라면의 대부분을 만드는 라면 공장으로도 유명한 경북의 도시는 어디일까요? | core | (대표 사실 + 곁들인 사실 — 좋은 꼴) |
| 하마 | 피부에서 자외선을 막고 세균의 성장을 억제하는 붉은 물질을 내보내는, 입이 큰 아프리카 초식동물은 무엇일까요? | core | (사실은 좋다고 했다 — 문장 꼴은 여기서 따지지 않는다) |

가르기 어려우면: **"이 질문을 듣고 정답을 맞힌 사람이, 이 정답이 뭔지 모르는 친구에게 질문 문장만으로 설명해 줄 수 있나"** — 되면 core, 안 되면 tidbit.

## 2. `grade` — 난이도 1~5 (지금 붙어 있는 등급은 일부러 보여 주지 않는다)

**"그 사람(들)이 30초 안에 맞힐 확률"** — 정답을 아는가 + **이 질문 꼴로 떠올릴 수 있는가** 둘 다. 답은 주관식으로 직접 쳐야 한다.

| 등급 | 기준 인물 | 기준 |
|---|---|---|
| 1 아주 쉬움 | **일반인**(퀴즈에 익숙하지 않은 20~30대 · 학교 용어는 가물가물 · 일상 · 대중문화는 바로) | 힌트 없이 5초 안에 거의 확실히 떠올린다 |
| 2 쉬움 | 일반인 | 10초 안에 대부분 맞힌다 — 이름이 한 번 생각나야 하는 정도 |
| 3 보통 | **똑똑한 친구 4명이 있는 방**(대졸 · 퀴즈 좋아함) | 방에서 한두 명이 맞힌다 — 방 정답률 45~70% |
| 4 어려움 | 똑똑한 방 4명 | 방 정답률 20~45% · "이걸 어떻게 알아" |
| 5 매우 어려움 | 똑똑한 방 4명 | 20% 아래 · 전공 · 마니아 |

규칙:
1. **학교에서만 쓰는 용어**는 일상에서 안 쓰면 3 부터(완전변태 · 체세포분열 · 가시광선 · 매질). 어른이 잊은 교과 지식은 3~4.
2. 단서가 어려운 용어로만 쓰였으면 정답이 쉬워도 한 단계 올리고, 단서가 답을 거의 말해 주면 한 단계 내린다.
3. **세대**: 주 플레이어는 1990년대 이후 출생. 1990~2010년대 대중문화는 2~3, 그 밖은 3~5. 스포츠 · 게임 세부는 "아는 사람은 바로"여도 일반인 기준 3.
4. 숫자 · 연도 · 순서가 정답이면 한 단계 올린다(정확히 써야 한다).
5. **너는 사람보다 많이 안다 — 네 지식으로 매기지 말고 기준 인물을 어림한다.** 질문이 친절해서 네게 쉬워 보여도, 일반인이 그 이름을 **직접 쳐서** 낼 수 있는지 본다. 한쪽(쉬움)으로 쏠리지 않게.

- 2: 카시오페이아자리 · 웰시 코기 · 레 미제라블 · 이솝 우화 · 다도해 · 헌법재판소 · VPN
- 3: 완전변태 · 체세포분열 · 연역법 · 국제연맹 · 아다지오 · 희생번트 · 핼리 혜성 · 반감기 · 하이쿠
- 4: 우루과이(1회 월드컵 개최국) · 12표법 · 광주기성 · 낯설게 하기 · 맥주 순수령 · 매직 아워 · 소뇌 · 교토 애니메이션

## 3. 출력 — JSON 하나만(코드 블록) · 설명 글 없이

```json
{
 "chunk": "01",
 "results": [
  {"id": 5877, "q": "core", "grade": 3, "why": "쿠크다스 광고·등대섬 = 대표 / 섬 이름을 쳐야 함"},
  {"id": 817, "q": "core", "grade": 1, "why": "일상 낱말"}
 ]
}
```

- 조각의 **모든 카드**를 차례대로, 하나도 빠뜨리지 않는다. `why` 는 30자 안팎 한 줄(q 와 grade 의 까닭).
