# 라이어 게임 제시어 늘리기 — 지시서

당신은 한국어 파티 게임 "라이어 게임"의 **제시어를 더 만드는 일**을 맡았습니다. 함께 올라온 `조각-NN-<주제>.txt` 에는 주제 하나와, 그 주제에 **이미 있는 단어**(소분류별)와 항목 예가 들어 있습니다. 그 주제의 **새 제시어 40개**를 만들어 주세요.

플레이어는 20~40대 한국인 친구들입니다. 지금은 2026년입니다.

## 게임이 어떻게 돌아가나

- 모두에게 같은 주제가 공개되고, 한 명(라이어)만 빼고 **제시어**를 받습니다. 돌아가며 제시어를 한마디씩 돌려 설명하고, 투표로 라이어를 찾습니다. 라이어는 남들 설명을 듣고 제시어를 맞히면 점수를 얻습니다.
- **기본형**: 라이어는 "당신은 라이어" 라는 것만 알고 제시어를 모릅니다.
- **바보형**: 라이어에게 라이어라는 사실을 숨기고, 제시어 대신 **비슷한 다른 단어(`fool`)** 를 진짜인 것처럼 줍니다. 라이어는 자기 단어를 성실히 설명하다가 미묘하게 어긋나서 들킵니다.

## 1. 좋은 제시어

- **보편성**: 20~40대 한국인 대부분이 아는 것. 한철 유행 · 올해 밈 · 특정 팬덤만 아는 것 · 전공자만 아는 것은 안 됩니다.
- **게임성**: 한마디로 돌려 설명할 거리가 여러 개 있는 것(생김새 · 쓰임 · 장소 · 느낌 …). 설명이 한 가지뿐인 것은 약합니다.
- 너무 넓은 상위어(음식 · 동물 · 디즈니) X · 너무 좁은 모델명 · 편수(아이폰 15 프로 · 007 카지노 로얄) X · 한 글자 단어 X.
- 실존 인물은 전 국민이 아는 사람만. **범죄 · 사건으로 처벌받았거나 정치적으로 싸움이 날 인물은 넣지 않습니다**(확신이 없으면 넣지 않습니다).
- **이미 있는 단어와 겹치지 않게**(같은 말의 다른 표기도 안 됨). 이미 있는 소분류를 더 채워도 되고, 그 주제에 어울리는 새 소분류를 만들어도 됩니다.
- 40개 가운데 2015년 이후에 자리 잡은 요즘 것(`modern`)은 **6개 이하**. 나머지는 세대를 타지 않는 것(`classic`).

## 2. `fool` — 바보형 단어 (항목마다 3개)

이 일에서 가장 중요한 부분입니다. 판단 기준은 하나입니다.

> **이 단어를 받은 사람이 남들의 설명을 들어도 "어, 내 단어가 가짜네 — 진짜는 ○○겠다" 하고 하나로 좁힐 수 없어야 한다. 동시에, 첫 한마디에 들킬 만큼 멀어서도 안 된다.**

- 제시어와 **같은 소분류** 안의 다른 것(같은 종류 · 비슷한 급).
- **금지 — 너무 가까움**: 1:1 라이벌 · 고정 짝(호날두 ↔ 메시 · 코카콜라 ↔ 펩시 · 삼성 ↔ 애플 · 가야금 ↔ 거문고) / 같은 작품의 인물 · 같은 그룹 멤버 / 동의어 · 아종(거북이 ↔ 자라) / 시리즈의 다른 편 / 상위 · 하위 관계(국악 ↔ 판소리 · 칫솔 ↔ 전동칫솔) / 맛 · 색만 다른 같은 상품(바나나우유 ↔ 딸기우유).
- **금지 — 너무 멂**: 설명 한마디가 전혀 안 통하는 것(돼지 ↔ 하마 · 애국가 ↔ 생일 축하 노래).
- **fool 도 누구나 아는 단어**여야 합니다(제시어보다 낯선 단어 X).
- fool 은 이미 있는 단어나 이번에 만드는 다른 제시어여도 됩니다. 한 항목 안에서 서로 다른 3개.
- 좋은 예: 호날두 → 네이마르 · 손흥민 · 음바페(메시 없음) / 맥도날드 → 롯데리아 · 맘스터치 · KFC / 김치찌개 → 된장찌개 · 부대찌개 · 순두부찌개 / 병원 → 보건소 · 한의원 · 약국 / 소방관 → 경찰관 · 구급대원 · 해양경찰

## 3. 칸

| 칸 | 뜻 |
|---|---|
| `w` | 제시어(가장 흔한 한국어 표기) |
| `sub` | 소분류(짧게 — "국물 음식" · "축구 선수") |
| `era` | `classic` 또는 `modern` |
| `diff` | 1 쉬움(아이도 앎) · 2 보통 · 3 어려움(알긴 아는데 설명하기 까다로움) — 40개 중 대략 16 · 16 · 8 |
| `fool` | 바보형 단어 3개 |
| `var` | 라이어가 채팅에 이렇게 쳐도 정답으로 받을 **같은 뜻의 다른 표기**(없으면 `[]` · 띄어쓰기 · 대소문자 차이는 적지 않음 · 상위어 X) |

## 4. 출력 — 이 형식 그대로

**JSON 하나만**(설명 글 없이 · 코드 블록 하나).

```json
{
  "chunk": "08",
  "topic": "liar-job",
  "results": [
    {"w": "치과의사", "sub": "의료", "era": "classic", "diff": 1, "fool": ["안과의사", "한의사", "약사"], "var": []},
    {"w": "소믈리에", "sub": "음식", "era": "classic", "diff": 3, "fool": ["바텐더", "바리스타", "요리사"], "var": []}
  ]
}
```

규칙:
- `results` 는 **정확히 40개**. `chunk` 와 `topic` 은 조각 파일 첫 줄의 번호와 괄호 안 글자 그대로.
- 40개를 다 쓴 뒤 **fool 120개를 하나씩 다시 읽고** 2절의 금지에 걸리는 것을 바꿉니다(가장 흔한 실수: 가장 먼저 떠오르는 짝을 fool 로 쓰는 것).
- 마지막 확인: 이미 있는 단어와 겹침 0 · 40개끼리 겹침 0 · modern 6개 이하.
