# 정답 표기 확인 — 지시서 (v2 · 2026-11-26)

한국어 파티 퀴즈 게임의 주관식 문제다. 사람들이 정답을 **직접 쳐서** 낸다. 그래서 사람들이 흔히 쓰는 다른 표기도 맞는 답으로 받아야 한다.

조각 파일에는 정답이 40개쯤 들어 있다. 정답마다 **분류 · 위키백과가 넘겨주는 제목 · 카드 질문 · 지금 맞는 답으로 받는 것 · 열 주소(나무위키)** 가 적혀 있다.

## 1. 기획자가 정한 기준

> 1. 표준국어대사전 표제어가 대표 정답이다.
> 2. 위키백과에는 있는데 사전과 표기가 다르면 둘 다 맞는 답으로 받는다.
> 3. **사전에도 위키에도 없을 때만** 나무위키 제목을 가져와 본다.

이 조각의 정답은 모두 3 에 해당한다 — 표준국어대사전은 우리 쪽에서 기계로 이미 찾아봤고(띄어쓰기를 빼고도) **없었다.** 그래서 사전은 다시 열지 않는다. **나무위키만 본다.**

## 2. 정답마다 할 일

1. 조각에 적힌 **열 주소**를 연다(사용자가 준 주소다). 주소가 둘이면 둘 다 연다. 다른 문서로 넘겨지면 넘겨진 문서의 제목을 적는다.
2. 그 문서가 **카드 질문이 묻는 바로 그것**인지 본다. 이름만 같고 다른 것(동명이인 · 더 넓은 말 · 더 좁은 말 · 동음이의어 문서)이면 `same: false`.
3. `add` — 맞는 답으로 **더 받을 표기**: 나무위키 제목(같은 것을 가리킬 때) 가운데 지금 받는 것에 **없는** 것. 문서 첫머리에 적힌 흔한 다른 이름이 있으면 그것도 넣어도 된다. 없으면 `[]`.
4. **넣지 않는 것**: 뜻이 다른 낱말 · 더 넓은/좁은 말(질문의 답이 아니게 되는 것) · 이미 받는 것과 띄어쓰기만 다른 것(게임이 띄어쓰기를 무시한다) · 카드가 표기 자체를 묻는 문제의 다른 표기.
5. 대표 정답은 바꾸지 않는다(사전 표제어가 없으니). 지금 정답이 명백히 틀린 표기로 보이면 `note` 에 한 줄 적는다.
6. **주소가 안 열리면** 그 정답은 `namu: null` · `add: []` · `note: "못 엶"` 으로 두고 다음으로 간다. **기억으로 채우지 않는다.** 한 조각 안에서 열리는 것만 다 해서 낸다.

## 3. 본보기

| 정답 | 지금 받는 것 | 나무위키에서 본 것 | 결론 |
|---|---|---|---|
| 히딩크 | 히딩크 | "거스 히딩크" · 같은 사람 | `add: ["거스 히딩크"]` |
| 로부스타 | 로부스타 | "로부스타" 문서 · 같은 것 | `add: []` — 지금 것과 같다 |
| 흥남 철수 | 흥남 철수 | "흥남 철수 작전" · 같은 사건 | `add: ["흥남 철수 작전"]` |
| 염소 가스 | 염소 가스 | "염소" 는 동물 문서로 넘어감 | `same: false` · `add: []` |
| 전북 현대 모터스 | 전북 현대 모터스 / 전북 현대 / 전북 현대 모터스 FC | "전북 현대 모터스" | `add: []` — 이미 다 받는다 |

(나무위키 결과는 본보기를 위한 가정이다. 실제로는 열어서 확인한다.)

## 4. 돌려줄 형식 — JSON 하나만, 코드 블록으로

```json
{
  "chunk": "03",
  "items": [
    {"n": 1, "answer": "전북 현대 모터스", "namu": "전북 현대 모터스", "same": true, "add": [], "note": ""},
    {"n": 2, "answer": "흥남 철수", "namu": "흥남 철수 작전", "same": true, "add": ["흥남 철수 작전"], "note": ""}
  ]
}
```

- `n` = 조각의 [번호] · `answer` = 조각에 적힌 정답 그대로 · `namu` = 열어서 본 나무위키 제목(못 열면 null).
- 조각의 정답을 **하나도 빠뜨리지 않는다**(못 연 것도 `"못 엶"`으로 넣는다). 길어서 끊기면 마지막에 `"남은 번호: …"`라고만 쓰고 멈춘다. "계속"이라고 하면 남은 번호부터 같은 형식으로 이어서 쓴다.
