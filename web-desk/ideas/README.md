# ideas — 다른 AI 에게 아이디어 받기

- `프롬프트.md` 를 통째로 복사해 다른 AI(ChatGPT · Gemini · Claude 웹 등) 채팅에 붙여 넣는다. 첨부 파일 없음.
- 돌아온 답(코드 블록 안)을 `받은것/답-<AI이름>.md` 로 저장한다(예: 답-gpt.md · 답-gemini.md). 여러 AI 에게 받아도 된다 — 많을수록 겹치는 아이디어를 골라내기 쉽다.
- 설계 창에 "web-desk 확인" → 설계가 AI 별 답을 합쳐 겹침 · 우선순위 · 우리 조건(2명 가능 · AI 데이터 생성 가능 · 구현 난도)으로 추려 보고한다.
