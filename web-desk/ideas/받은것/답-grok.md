# 답: Grok

## A. 평가
- 강점: 주관식 퀴즈 + 짧은 미니게임 + 라이어/캐치마인드의 조합이 지식·운·눈치·창작을 고루 섞어 30분~2시간 파티에 딱 맞음. 힌트 시스템과 표기 변형 처리가 완성도 높고, 음성 통화 전제의 말하기 요소가 자연스럽게 녹아 있음. 데이터 AI 생성·검증 파이프라인이 이미 있어 확장성이 좋음.
- 약점: 2~3명일 때 라이어·겹치면 무효 같은 게임이 급격히 싱거워지거나 성립이 어려워짐. 본게임 주관식이 길어지면 지식 격차가 커져 약한 사람이 소외됨. 미니게임 중 일부(특히 손감각)가 폰/PC 입력 차이로 공정성 논란 생기기 쉬움. 역전 장치나 배신·협동이 약해 후반부 긴장감이 떨어질 수 있음. 주제 목록이 닫힌 집합이라 반복 플레이 시 금방 익숙해짐. 처음 온 사람이 규칙 파악에 시간이 좀 걸림.
- 빠진재미: 협동 — 팀으로 같이 맞춰야 하는 순간이 거의 없어 혼자 잘하는 사람만 빛남. 배신/심리 역전 — 라이어 외에는 서로를 속이는 장치가 부족함. 창작 공유 — 캐치마인드 외 말이나 그림으로 공동 창작하는 요소가 약함. 내기·리스크 — 점수만 쌓이는 구조라 한 판에 올인하는 짜릿함이 적음. 운의 극적인 역전 — 후반에 갑자기 뒤집을 수 있는 장치 부족.

## B1. 라이어 주제 — 누구나
### B1-01 한국 음식 브랜드/메뉴
- 제시어: 신라면, 짜파게티, 불닭볶음면, 삼각김밥, 참치김밥, 육개장, 비빔밥, 떡볶이
- 바보짝: 신라면 → 안성탕면 / 불닭볶음면 → 핵불닭볶음면
- 메모: 누구나 아는 브랜드·메뉴라 설명하기 좋음
### B1-02 지하철/버스 관련
- 제시어: 환승, 개찰구, 교통카드, 막차, 급행, 종점, 승강장, 하차벨
- 바보짝: 환승 → 갈아타기 / 막차 → 첫차
- 메모: 일상 경험으로 바로 설명 가능
### B1-03 한국 명절/세시풍속
- 제시어: 설날, 추석, 단오, 한식, 동지, 정월대보름, 추석송편, 세배
- 바보짝: 설날 → 구정 / 추석 → 한가위
- 메모: 공통 추억이 많아 웃음 포인트 많음
### B1-04 편의점 상품
- 제시어: 도시락, 삼각김밥, 컵라면, 핫바, 소세지, 맥주, 음료수, 아이스크림
- 바보짝: 삼각김밥 → 유부초밥 / 핫바 → 핫도그
- 메모: 20~40대 공통 경험
### B1-05 한국 날씨/계절 표현
- 제시어: 황사, 미세먼지, 장마, 태풍, 폭염, 한파, 봄바람, 가을하늘
- 바보짝: 황사 → 미세먼지 / 장마 → 우기
- 메모: 설명하다 보면 자연스럽게 투덜거림 나옴
### B1-06 한국 학교 생활
- 제시어: 야자, 보충수업, 교무실, 담임, 수행평가, 중간고사, 체육복, 급식
- 바보짝: 야자 → 자율학습 / 수행평가 → 과제
- 메모: 학창시절 공유 경험
### B1-07 한국 직장/회사 용어
- 제시어: 회식, 야근, 출근, 퇴근, 보고서, 결재, 상사, 동료
- 바보짝: 회식 → 회합 / 야근 → 특근
- 메모: 직장인 친구 모임에 특히 잘 맞음
### B1-08 한국 교통수단
- 제시어: 지하철, 버스, 택시, KTX, 고속버스, 따릉이, 킥보드, 자가용
- 바보짝: 지하철 → 전철 / KTX → SRT
- 메모: 일상적이라 설명 쉬움
### B1-09 한국 음료/주류
- 제시어: 소주, 맥주, 막걸리, 동동주, 커피, 유자차, 식혜, 수정과
- 바보짝: 소주 → 청주 / 막걸리 → 동동주
- 메모: 술자리 분위기와 잘 어울림
### B1-10 한국 동물/곤충 관련 표현
- 제시어: 모기, 파리, 바퀴벌레, 개미, 거미, 뱀, 쥐, 고양이
- 바보짝: 모기 → 날파리 / 바퀴벌레 → 바퀴
- 메모: 혐오/호감이 갈려 설명이 재밌어짐
### B1-11 한국 명절 음식
- 제시어: 송편, 전, 잡채, 갈비찜, 떡국, 세배돈, 과일, 한과
- 바보짝: 송편 → 인절미 / 떡국 → 만두국
- 메모: 없음
### B1-12 한국 계절 음식
- 제시어: 냉면, 삼계탕, 팥빙수, 군고구마, 붕어빵, 호떡, 찐빵, 어묵
- 바보짝: 냉면 → 물냉면 / 팥빙수 → 빙수
- 메모: 계절감으로 설명하기 좋음

## B2. 라이어 주제 — 아는 사람만
### B2-01 리그 오브 레전드
- 대상: 롤 해본 사람 (20~40대 남성 비중 높음)
- 제시어: 아리, 야스오, 리신, 미스 포츈, 제드, 카타리나, 바루스, 아지르
- 바보짝: 아리 → 아칼리 / 야스오 → 요네

### B2-02 포켓몬

## C. 새 미니게임
### C-01 초성 연쇄
- 종류: 말하기창작
- 한줄규칙: 주어진 초성으로 시작하는 단어를 번갈아 말하기. 겹치면 탈락
- 진행: 주제가 주어지고 초성 하나가 공개됨. 차례로 해당 초성으로 시작하는 주제 관련 단어를 말함. 못 말하거나 겹치면 탈락. 30~60초 동안 진행
- 점수: 살아남은 순서 또는 말한 개수
- 인원: 2명 됨 — 서로 번갈아 / 8명 순서가 길어져 긴장감 좋음
- 데이터: 주제별 초성 단어 목록 필요 · AI 생성 가능 · 검증은 실제 존재 여부 확인
- 구현난도: 중 — 실시간 중복 체크와 음성 인식 없이도 채팅으로 가능
- 왜맞나: 한국어 초성 특성과 눈치·말하기가 결합되어 파티 분위기와 잘 맞음
- 위험: 단어가 고갈되면 금방 끝남
### C-02 한 글자 차이
- 종류: 지식
- 한줄규칙: 주어진 단어와 한 글자만 다른 단어를 최대한 많이 찾기
- 진행: 기준 단어가 나오고 30초 동안 한 글자만 바꿔서 되는 실제 단어를 타이핑. 중복 불가
- 점수: 유효 단어 개수
- 인원: 2명 됨 · 8명 경쟁이 치열해짐
- 데이터: 기준 단어 + 가능한 변형 목록 · AI 생성·검증 가능
- 구현난도: 중 — 정답 판정 사전 필요
- 왜맞나: 한국어 음절 구조와 말장난을 살릴 수 있음
- 위험: 너무 쉬운/어려운 단어가 나오면 재미 반감
### C-03 감정 연기
- 종류: 말하기창작
- 한줄규칙: 주어진 문장을 지정된 감정으로 읽기. 다른 사람이 감정 맞히기
- 진행: 한 명이 문장+감정을 받아 연기. 나머지가 어떤 감정인지 맞춤. 30초 내 진행
- 점수: 맞힌 사람 점수 + 연기 성공 보너스
- 인원: 2명 됨 · 8명 투표로 재미
- 데이터: 문장+감정 쌍 · AI 생성 가능
- 구현난도: 하 — 채팅/음성으로 충분
- 왜맞나: 음성 통화 전제와 웃음 포인트가 강함
- 위험: 연기를 안 하는 사람 있으면 흐름 끊김
### C-04 반대로 말하기
- 종류: 손감각
- 한줄규칙: 화면에 나오는 단어를 반대로 빠르게 타이핑
- 진행: 단어가 나오고 5초 안에 반대로 된 철자를 입력. 10연속
- 점수: 맞힌 개수 + 속도
- 인원: 2명 됨 · 8명 개인전으로 좋음
- 데이터: 단어 목록 · AI 생성 가능
- 구현난도: 하
- 왜맞나: 짧고 손맛 있으며 실수하면 웃음
- 위험: 너무 쉬우면 금방 끝남
### C-05 공통점 찾기
- 종류: 눈치심리
- 한줄규칙: 세 단어가 나오고 공통점을 가장 빨리 맞히기
- 진행: 세 단어 공개 후 공통 카테고리나 특징을 타이핑. 먼저 맞힌 사람 점수
- 점수: 속도 + 정확도
- 인원: 2명 됨 · 8명 경쟁 좋음

## D. 새 방식 게임
### D-01 스파이 회의
- 한줄소개: 한 명이 스파이. 회의로 찾아내거나 스파이가 임무를 완수
- 진행: 주제가 공개되고 스파이는 다른 임무를 받음. 돌아가며 발언 후 투표. 스파이가 특정 단어를 유도하면 스파이 승리. 여러 라운드
- 인원: 최소 4 · 최적 6~7 · 2~3명일 때 안 됨
- 데이터: 주제+임무 쌍 · AI 생성 가능
- 구현난도: 중 — 발언 타이밍과 투표 시스템
- 왜맞나: 라이어와 비슷하면서 협동·배신 강화
- 위험: 발언이 길어지면 지루
### D-02 공동 스토리
- 한줄소개: 돌아가며 한 문장씩 이야기를 이어가기. 마지막에 투표로 최고 작가 선정
- 진행: 시작 문장이 나오고 순서대로 한 문장씩 추가. 일정 문장 후 종료. 가장 재밌었던 사람 투표
- 인원: 최소 3 · 최적 5~6 · 2~3명일 때 됨
- 데이터: 시작 문장 · AI 가능
- 구현난도: 하
- 왜맞나: 창작과 웃음이 자연스럽게 나옴
- 위험: 한 사람이 흐름을 망치면 전체 분위기 다운
### D-03 비밀 역할 퀴즈
- 한줄소개: 각자 비밀 역할(방해자·도우미 등)을 받고 퀴즈를 풀며 역할을 숨김
- 진행: 역할 배정 후 본게임 퀴즈 진행. 방해자는 일부러 틀리거나 힌트를 잘못 줌. 중간중간 역할 추리 투표
- 인원: 최소 4 · 최적 6~8 · 2~3명일 때 안 됨
- 데이터: 역할 카드 · AI 불필요
- 구현난도: 중
- 왜맞나: 기존 퀴즈에 배신 요소 추가
- 위험: 역할이 티나면 재미 반감
### D-04 가격 경매
- 한줄소개: 상품이 나오고 눈치로 가격을 경매. 가장 가까운 사람이 점수
- 진행: 상품 공개 후 각자 가격을 비밀 입찰. 공개 후 실제 가격과 비교. 여러 라운드
- 인원: 최소 2 · 최적 4~6 · 2~3명일 때 됨
- 데이터: 상품+가격 · AI 가능하나 검증 필요
- 구현난도: 하
- 왜맞나: 생활 감각과 눈치
- 위험: 가격 데이터가 부정확하면 신뢰 하락
### D-05 집단 기억
- 한줄소개: 한 사람이 이야기를 하고 나머지가 세부 사항을 기억해 맞히기
- 진행: 한 명이 짧은 이야기를 함. 이후 세부 질문. 맞힌 개수로 점수. 역할 교대
- 인원: 최소 3 · 최적 5~7 · 2~3명일 때 됨
- 데이터: 이야기 템플릿 · AI 가능
- 구현난도: 하
- 왜맞나: 말하기와 기억력 결합
- 위험: 이야기가 너무 복잡하면 포기

## E. 있는 게임 개선
### E-01 본게임 퀴즈 — 팀 협동 모드
- 내용: 팀전에서 한 문제가 나오면 팀원끼리 채팅으로만 상의 후 한 명이 대표 제출. 시간 제한 있음. 성공 시 팀 전원 점수
- 효과: 혼자 잘하는 사람 독주 방지, 협동 재미 추가
- 구현난도: 중
### E-02 라이어 게임 — 이중 라이어
- 내용: 가끔 라이어가 두 명 나오거나, 바보형과 기본형이 섞인 모드. 투표 후 라이어가 서로 지목하는 페이즈 추가
- 효과: 배신과 심리 게임 깊이 증가
- 구현난도: 중
### E-03 캐치마인드 — 공동 그리기
- 내용: 두 명이 동시에 같은 제시어를 나눠서 그림. 나머지는 맞춤. 또는 한 명이 그리고 다른 사람이 색칠
- 효과: 협동 창작 요소 강화
- 구현난도: 중
### E-04 많이 말하기/겹치면 무효 — 라이프 시스템
- 내용: 겹치거나 틀리면 라이프 감소. 라이프 0이면 그 라운드 탈락. 마지막까지 남은 사람 보너스
- 효과: 긴장감과 역전 가능성 증가
- 구현난도: 하
### E-05 노래 맞히기 — 가사 힌트 모드
- 내용: 노래가 나오기 전 가사 한 줄을 초성으로 보여주거나, 중간에 가사 일부를 공개하는 옵션
- 효과: 난이도 조절과 참여율 상승
- 구현난도: 하

## F. 그 밖의 개선
### F-01 빠른 규칙 카드
- 내용: 처음 들어온 사람에게 각 게임별 한 줄 규칙 + 예시 화면을 5초 팝업으로 보여줌. 스킵 가능

- 효과: 후반 역전과 전략성 추가
- 구현난도: 중

- 효과: 다시 하고 싶은 동기와 공유 욕구 증가
- 구현난도: 중
### F-04 2~3인용 특별 규칙
- 내용: 인원이 적을 때 자동으로 규칙 조정 (라이어는 바보형 강제, 겹치면 무효는 시간 제한 강화 등)
- 효과: 소수 인원에서도 재미 유지
- 구현난도: 중
