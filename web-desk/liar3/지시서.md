# 라이어 게임 새 주제 만들기 — 지시서

당신은 한국어 파티 게임 "라이어 게임"의 **새 주제 하나의 제시어 목록**을 만드는 일을 맡았습니다. 함께 올라온 `조각-NN-<주제>.txt` 에는 주제 이름 · 종류(누구나 / 아는 사람만) · 범위 · 피할 단어가 들어 있습니다. 그 주제의 **제시어 40개**를 만들어 주세요.

플레이어는 20~40대 한국인 친구들입니다. 지금은 2026년입니다.

## 게임이 어떻게 돌아가나

- 모두에게 같은 주제가 공개되고, 한 명(라이어)만 빼고 **제시어**를 받습니다. 돌아가며 제시어를 한마디씩 돌려 설명하고, 투표로 라이어를 찾습니다. 라이어는 남들 설명을 듣고 제시어를 맞히면 점수를 얻습니다.
- **기본형**: 라이어는 "당신은 라이어" 라는 것만 알고 제시어를 모릅니다.
- **바보형**: 라이어에게 라이어라는 사실을 숨기고, 제시어 대신 **비슷한 다른 단어(`fool`)** 를 진짜인 것처럼 줍니다. 라이어는 자기 단어를 성실히 설명하다가 미묘하게 어긋나서 들킵니다.
- 방장은 주제를 체크해서 고릅니다. **"아는 사람만" 주제는 기본으로 꺼져 있고**, 그 주제를 다 아는 모임에서만 방장이 켭니다.

## 1. 좋은 제시어

**종류가 "누구나" 일 때**
- 20~40대 한국인 대부분이 아는 것. 한철 유행 · 올해 밈 · 전공자만 아는 것은 안 됩니다.

**종류가 "아는 사람만" 일 때**
- 기준은 "**그 주제를 즐긴 사람이면 누구나 아는 것**"입니다. 그 안에서도 깊은 팬만 아는 것(조연의 조연 · 한 번 나온 아이템 · 최신 패치 내용)은 넣지 않습니다. 그 게임 · 작품을 가볍게 즐긴 사람도 "아 그거!" 할 것만.
- **이름은 한국에서 통하는 공식 표기**(한국 서버 · 한국어판 · 한국 개봉명)로. **실제로 있는 것만** — 이름이 확실하지 않으면 넣지 않습니다. 지어내지 않습니다.
- 범위에 적힌 갈래(인물 · 아이템 · 장소 · 용어 …)를 고루 섞습니다. 한 갈래만 40개 채우지 않습니다.

**공통**
- **게임성**: 한마디로 돌려 설명할 거리가 여러 개 있는 것(생김새 · 쓰임 · 상황 · 느낌 …).
- 너무 넓은 상위어 X · 한 글자 단어 X · 주제 이름 그 자체 X.
- 조각 파일의 "다른 주제에 이미 있는 단어" 는 제시어로 쓰지 않습니다(fool 로는 가능).
- 실존 인물은 범죄 · 사건으로 처벌받았거나 정치적으로 싸움이 날 사람을 넣지 않습니다.
- **억지로 40을 채우지 않습니다.** 좋은 것이 30개뿐이면 30개만(최소 30 · 최대 40).

## 2. `fool` — 바보형 단어 (항목마다 3개)

이 일에서 가장 중요한 부분입니다. 판단 기준은 하나입니다.

> **이 단어를 받은 사람이 남들의 설명을 들어도 "어, 내 단어가 가짜네 — 진짜는 ○○겠다" 하고 하나로 좁힐 수 없어야 한다. 동시에, 첫 한마디에 들킬 만큼 멀어서도 안 된다.**

- 제시어와 **같은 소분류** 안의 다른 것(같은 종류 · 비슷한 급). 같은 주제 안의 단어여야 합니다.
- **금지 — 너무 가까움**: 1:1 라이벌 · 고정 짝(야스오 ↔ 요네 · 강백호 ↔ 서태웅 · 소주 ↔ 맥주처럼 "하나 하면 바로 다른 하나") / 동의어 · 줄임말(설날 ↔ 구정 · 방탄소년단 ↔ 방탄) / 진화 · 강화 · 상위 버전(파이리 ↔ 리자드 · 불닭볶음면 ↔ 핵불닭볶음면) / 상위 · 하위 관계(냉면 ↔ 물냉면) / 맛 · 색만 다른 같은 것.
- **금지 — 너무 멂**: 설명 한마디가 전혀 안 통하는 것.
- fool 도 그 주제를 아는 사람이면 누구나 아는 단어여야 합니다. 한 항목 안에서 서로 다른 3개. 이번에 만드는 다른 제시어여도 됩니다.
- 좋은 예: 삼각김밥 → 컵라면 · 샌드위치 · 핫바 / 수학여행 → 수련회 · 소풍 · 체육대회 / 티모 → 룰루 · 트리스타나 · 베이가 / 질럿 → 마린 · 저글링 · 히드라리스크

## 3. 칸

| 칸 | 뜻 |
|---|---|
| `w` | 제시어(가장 흔한 한국어 표기) |
| `sub` | 소분류(짧게 — "챔피언" · "아이템" · "학교 행사") |
| `era` | `classic`(세대를 타지 않음 · 오래 자리 잡음) 또는 `modern`(2015년 이후 자리 잡음) |
| `diff` | 1 쉬움 · 2 보통 · 3 어려움(알긴 아는데 설명하기 까다로움) — 대략 4 : 4 : 2 |
| `fool` | 바보형 단어 3개 |
| `var` | 라이어가 채팅에 이렇게 쳐도 정답으로 받을 **같은 뜻의 다른 표기 · 줄임말 · 별명**(없으면 `[]` · 띄어쓰기 · 대소문자 차이는 적지 않음) |

## 4. 출력 — 이 형식 그대로

**JSON 하나만**(설명 글 없이 · 코드 블록 하나).

```json
{
  "chunk": "03",
  "topic": "liar-school",
  "results": [
    {"w": "수학여행", "sub": "학교 행사", "era": "classic", "diff": 1, "fool": ["수련회", "소풍", "체육대회"], "var": []},
    {"w": "야간자율학습", "sub": "공부", "era": "classic", "diff": 2, "fool": ["보충수업", "모의고사", "독서실"], "var": ["야자"]}
  ]
}
```

규칙:
- `chunk` 와 `topic` 은 조각 파일 첫 줄의 번호와 괄호 안 글자 그대로. `results` 는 30~40개.
- 다 쓴 뒤 **fool 을 하나씩 다시 읽고** 2절의 금지에 걸리는 것을 바꿉니다(가장 흔한 실수: 가장 먼저 떠오르는 짝을 fool 로 쓰는 것).
- 마지막 확인: 피할 단어와 겹침 0 · 서로 겹침 0 · "아는 사람만" 주제는 이름 표기를 한 번 더.
