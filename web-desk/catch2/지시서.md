# 캐치마인드 제시어 고르기 — 지시서

당신은 한국어 파티 게임 "캐치마인드"(한 사람이 제시어를 그림으로 그리고 나머지가 채팅으로 맞히는 게임)의 **제시어 목록을 고르는 일**을 맡았습니다. 함께 올라온 `조각-NN.txt` 에는 단어가 한 줄에 하나씩 약 300개 들어 있습니다. **단어 하나하나**에 대해 아래 판정을 내려 JSON 으로 돌려주세요.

플레이어는 20~40대 한국인 친구들입니다. 지금은 2026년입니다.

## 1. 남길지 뺄지 — 기준은 하나

제품 책임자의 말(그대로):

> "그리기 어려운 걸 어떻게든 창의적으로 그림으로 표현해내는 게 재미인데 왜 자꾸 빼자고 하는 거임? 단어도 너무 어렵지 않은 개념이면 엥간하면 괜찮아. 단어 한 글자 한 글자를 그림으로 표현할 수도 있고… 잘 그려도 '이게 무슨 단어야?' 와 같은 상황만 없으면 돼. 일반적으로 사람들이 맞힐 만한 수준이면 거의 다 괜찮음."

그래서 **남기는 것이 기본**입니다. 빼는 경우는 아래뿐입니다.

| `why` | 빼는 경우 | 예 |
|---|---|---|
| `낯섦` | 정답을 듣고도 "그게 뭔데?" 가 나올 단어 — 보통 사람이 뜻을 모르는 옛말 · 전문어 · 사어 | 지남철 · 경륜(競輪 뜻을 모르는 사람이 많음) · 견본 |
| `조각` | 단어가 아니거나 뜻이 하나로 안 잡히는 글자 묶음 · 오타 | — |
| `비속` | 욕설 · 성적 표현 · 혐오 표현 (몸 · 화장실 낱말 같은 가벼운 것은 남김 — 방귀 · 변비 OK) | — |
| `논란` | 범죄 · 사건으로 알려진 실존 인물, 정치적으로 싸움이 날 인물 · 단체, 현직 · 최근 정치인 | — |
| `같은말:<기존 단어>` | 아래 6절 "이미 있는 단어" 와 **뜻이 같은 다른 이름**(탁자 = 테이블) — `<기존 단어>` 자리에 그 단어를 적기 | `같은말:테이블` |
| `상표` | 특정 회사 상품 · 서비스 이름. 단 보통명사처럼 쓰이는 것(호치키스 · 포스트잇 · 스카치테이프)은 남김 | 그램 · 린스(상표로 쓰인 경우) |

**빼는 사유가 아닌 것** — 아래는 전부 남깁니다(대신 3절 난이도로 표현):
- 추상어(가격 · 과거 · 경고) · 감정 · 개념
- 한 장면으로 그리기 어려움 · 그림이 다른 단어와 헷갈림(두통 ↔ 감기)
- 상위어 · 하위어(셔츠 ↔ 티셔츠 — 둘 다 남김. "같은말" 은 뜻이 **완전히** 같을 때만)
- 나라 · 도시 · 명소 이름(독도 · 독일) — 누구나 알면 남김
- 실존 인물 · 위인 · 종교 · 신화 인물 — 전 국민이 알고 `논란` 이 아니면 남김(김구 · 계백 · 세종대왕 OK)
- 영화 · 노래 · 책 제목 — 전 국민이 알면 남김, 일부만 알면 `낯섦`

"아는 단어인가" 가 애매하면: **20~40대 열 명 중 일곱 명 이상이 뜻을 안다**고 생각되면 남깁니다.

## 2. 세트 (`set`)

남기는 단어는 아래 가운데 하나에 넣습니다.

- `draw-action` 동작·상황
- `draw-animal` 동물
- `draw-character` 캐릭터·인물
- `draw-food` 음식
- `draw-job` 직업
- `draw-nature` 자연·날씨
- `draw-object` 사물
- `draw-place` 장소·건물
- `draw-proverb` 속담·사자성어
- `draw-vehicle` 탈것
- `draw-etc` 기타 — 위 어디에도 안 맞는 것(추상어 · 개념 · 나라 · 도시 · 작품 제목 · 몸 · 색 · 숫자 …)

## 3. 난이도 (`diff`)

그리는 사람 기준입니다.
- `1` 쉬움 — 아이도 바로 그린다(사과 · 기차)
- `2` 보통 — 조금 생각하면 한 장면으로 그려진다(백화점 · 파일럿)
- `3` 어려움 — 추상어 · 상황 · 헷갈리는 그림 · 글자를 쪼개 표현해야 하는 것(과거 · 경고 · 가격)

## 4. 게임성 (`g`)

빼는 기준이 아니라 **나중에 우선순위를 정하기 위한 표시**입니다.
- `3` 그리는 쪽도 맞히는 쪽도 재미있겠다 — 떠오르는 장면 · 표현 방법이 여럿
- `2` 무난
- `1` 밋밋하다 — 아는 단어지만 그릴 실마리도 맞힐 실마리도 거의 없다(각도 · 가공 · 그룹)

## 5. 다른 이름 (`var`)

채팅에 이렇게 쳐도 정답으로 받아야 하는 **뜻이 같은 다른 표기 · 이름**만 적습니다(없으면 빈 배열). 띄어쓰기 · 대소문자 차이는 프로그램이 알아서 받으니 적지 않습니다. 상위어 · 하위어 · 비슷한 말은 적지 않습니다.
예: 도넛 → `["도너츠"]` · 오토바이 → `["바이크"]` · 큐피드 → `["큐피트"]`

## 6. 출력 — 이 형식 그대로

**JSON 하나만** 돌려주세요(설명 글 없이 · 파일로 만들 수 있으면 `결과-NN.json` 파일로, 아니면 코드 블록 하나로).

```json
{
  "chunk": "01",
  "results": [
    {"w": "설렁탕", "keep": true,  "set": "draw-food", "diff": 2, "g": 2, "var": []},
    {"w": "가격",   "keep": true,  "set": "draw-etc",  "diff": 3, "g": 2, "var": ["값"]},
    {"w": "지남철", "keep": false, "why": "낯섦"},
    {"w": "탁자",   "keep": false, "why": "같은말:테이블"}
  ]
}
```

규칙:
- 조각 파일의 **모든 단어가 한 번씩, 파일에 나온 순서대로** 들어가야 합니다. 건너뛰거나 합치거나 새 단어를 더하지 않습니다. `w` 는 파일에 적힌 글자 그대로.
- `keep: true` 면 `set` · `diff` · `g` · `var` 전부, `keep: false` 면 `why` 만.
- 300개를 한 번에 다 쓰기 어려우면 "계속" 이라고 하면 이어서 쓰되, **같은 형식의 JSON 을 이어 붙일 수 있게** `results` 항목만 이어서 주세요.
- 목록을 훑어 묶음으로 판단하지 말고 **한 단어씩** 판단하세요. 앞 단어들의 판정에 끌려가지 않습니다(연달아 "남김" 이 나와도, 연달아 "뺌" 이 나와도 정상).
- 뜻이 둘 이상인 단어는 가장 흔한 뜻으로 판단합니다.
- 다 쓴 뒤 스스로 확인: 결과 수 = 조각 첫 줄의 단어 수.
