## 1. 단계

1. **지침서** — `web-desk/tone/지시서.md` 는 설계 초안이다. 찬종이 GPT 에 초안을 넣고 다듬는다(아래 §3 GPT 프롬프트). 확정본을 같은 파일에 덮어쓰고 설계 창에 "지침 확정" 이라고 알린다. 확정 전에 조각을 돌리지 않는다.
2. **시범 조각 1**(100문항 · 어미 다섯 무리를 20개씩 섞어서 · 설계가 `보낼것/조각-00.txt` 로 만든다) → 웹 Sonnet 5.5 → `받은것/결과-00.json` → 설계가 기계 검사 + 찬종이 20개쯤 눈으로 봄 → 지침 손질 → 필요하면 시범 한 번 더.
3. **전수** — 100문항씩 **79 조각**. 순서: 비표준 어미 3,420(35 조각) 먼저 → "~은/는?" 4,460(44 조각) 나중(이미 기준 어미라 자연어 손질만). 조각은 순서 상관없고 중간에 멈춰도 된다(web-desk 원칙). 하루 10~15 조각이면 6~8일.
4. **적재** — 받은 조각이 10~20개 쌓일 때마다 GEN 라운드 하나(G06x): 기계 검사(§4) → 통과한 것만 두 DB 적용(before 같을 때만 · undo 파일) → `hint-check-active` 막힘 0 → 보류 목록은 설계가 본다. 중간에 적용해도 게임은 멀쩡하다(문항 단위 · 섞여 있어도 됨).
5. **VERIFY 표본 300**(전수 끝 뒤 1회): 뜻 · 단서 · 정답 유일성이 바뀌지 않았나 · 어미 규칙 위반 0.
6. **생성 쪽도 같은 말투** — 15 §3-1 에 어미 규칙 한 줄 · 생성 프롬프트(criteria-sync) 개정 · 이모지 지시서는 이미 "~는?" 꼴.

## 2. 조각 · 결과 형식

- `보낼것/조각-NN.txt`: 한 줄 = `id<TAB>질문문` · 100줄 · 맨 위 두 줄 주석(조각 번호 · "질문문만 고친다").
- `받은것/결과-NN.json`: `{ "chunk": "NN", "results": [ { "id": 1234, "question": "고친 질문문" }, … ] }` — 100개 전부(바꿀 필요가 없으면 **원문 그대로** 돌려준다 · 기계가 "같음" 으로 센다).
- 모델: 웹 **Sonnet 5.5**(자연어 다듬기는 충분 · 사실은 안 바꾸니 Opus 필요 없음). GPT 는 지침서 다듬기에만.

## 3. GPT 에 줄 말 (찬종이 붙여 넣기)

> 아래는 한국어 퀴즈 7,880문항의 질문문 말투를 하나로 통일하는 작업 지침서 초안이다. 이 지침을 받은 AI 가 100문항씩 질문문을 다시 쓴다. 사실·정답·단서는 바꾸면 안 된다. 지침서를 읽고 ① 모호해서 결과가 갈릴 규칙 ② 빠진 경우(예외) ③ 예문이 규칙과 어긋나는 곳 ④ 더 자연스러운 한국어 질문문 꼴 제안 을 짚어 주고, 고친 지침서 전문을 돌려 줘. 규칙은 짧고 예문은 실제 문항으로.

→ 돌아온 전문을 `지시서.md` 에 덮어쓴다. 설계가 한 번 더 읽어 기계 검사와 어긋나는 부분(§4)만 맞춘다.

## 4. 기계 검사 (설계 · GEN — 조각마다)

| 검사 | 통과 |
|---|---|
| id 집합 | 조각과 같음(빠짐 · 더함 0) |
| 끝 글자 | `?` 로 끝남 · 끝 어미가 지침 꼴("~은/는?" · "~는 몇 개?" · "~는 어디?" · "~는 누구?" · "~는 몇 년?") |
| 질문 위치 | 마지막 문장이 질문문 하나 · 질문 뒤에 설명문 0 |
| 정답 노출 | 정답 · 변형이 질문문에 없음(crossans 그대로) |
| 보존 | 원문의 숫자 · 따옴표 안 글 · 괄호 안 글이 전부 남아 있음(순서는 달라도 됨) |
| 길이 | 원문의 0.7~1.3배 · 문장 70자 · 2~4문장(D-328 길이 규칙) |
| 힌트 충돌 | 적용 뒤 `hint-check-active` 막힘 0 |

위반은 그 문항만 보류 → 설계가 보고 재조각 또는 손 고침. 조각 전체가 이상하면(위반 20% 초과) 조각을 버리고 다시 돌린다.

## 5. 아직 정하지 않은 것 (지침 확정 때 찬종)

- 수량·사람·장소·연도 질문의 기준 꼴("몇 개인가?" → "몇 개?" 가 너무 짧게 느껴지면 "몇 개일까?" 같은 둘째 꼴을 허용할지).
- 설명문 어미 "~습니다" 로 통일할지(지금 대부분 "~습니다" · 일부 "~이다" 꼴).
- 2단계 시범에서 찬종이 보는 수(20 안팎 제안).
