# 전체 검토 결과 — 조각 74

전체 55문항을 원문(질문·정답·힌트·해설), 지시서 v7, 재작성 JSON과 대조했습니다.

먼저 총평부터 말하면, 사실관계는 대체로 잘 보존했지만, 문장을 자연스럽게 만들려는 과정에서 불필요하게 길어진 문항이 상당수 있습니다. 특히 다른 AI가 `short`를 지나치게 적극적으로 사용했습니다.

원문이 이미 자연스러운 한 문장인 경우에도 다음과 같은 패턴으로 바꾸는 경향이 있습니다.

- `~한 것이 있습니다. ~한 이것은 무엇일까요?`
- `~라는 원칙이 있습니다. ~라는 이 원칙은 무엇일까요?`
- `~하는 사람이 있습니다. 이 사람은 누구일까요?`

이 방식은 문법적으로 틀리지는 않지만, 퀴즈 진행자가 읽어 주는 듯한 자연스러움과는 거리가 있습니다. 40초 동안 화면에 표시되는 게임이라는 점에서도 불필요한 글자 수입니다.

판정 요약

| 검토 항목        | 판정                |
| ------------ | ----------------- |
| 문장 자연스러움     | 일부 수정 필요          |
| 길이·형식 선택     | `short` 과다 사용     |
| `~는데요` 활용    | 대체로 양호            |
| 사실·숫자·고유명사   | 일부 핵심 정보 누락       |
| 마지막 질문의 답 종류 | 대부분 적절            |
| discard 판정   | 전부 rewrite한 것은 적절 |
| 지시서 개선       | 형식 선택 기준 보완 필요    |

아래에서는 실제로 수정할 가치가 있는 문항을 중심으로 짚겠습니다. 단순히 끝 어미만 바뀐 문항이나 자연스럽게 잘 고쳐진 문항은 반복해서 나열하지 않겠습니다.

## 8. 지시서 v7에서 수정해야 할 부분

이번 결과에서 반복적으로 나타난 문제는 AI가 지시를 잘못 이해했다기보다, 형식 선택 기준에 빈틈이 있고 서로 충돌하는 지시가 있다는 것입니다.

지시서 전체를 다시 작성할 필요는 없습니다. 아래 네 군데만 보완하면 됩니다.

### 수정 ① 1절 — 세 가지 꼴 고르기

현재 19\~24번 규칙은 한 문장과 짧은 꼴의 선택 기준을 설명하지만, AI가 원문을 무조건 두 문장으로 나누는 것을 충분히 막지 못합니다.

24번 뒤에 다음 내용을 추가하는 것을 추천합니다.

- **한 문장으로 자연스럽게 읽히면 한 문장을 우선합니다.** 글자 수가 60자를 조금 넘더라도 단서가 자연스럽게 연결되고 읽는 데 무리가 없다면 `line`을 선택합니다. 60자는 절대적인 제한이 아닙니다.
- `short`는 문장을 나누었을 때 정보가 더 잘 전달되는 경우에만 사용합니다. 첫 문장이 단순히 정답의 종류를 소개하거나, 다음 문장에서 같은 대상을 다시 설명하는 역할만 한다면 `short`로 만들지 않습니다.
- 특히 `~하는 사람이 있습니다. 이 사람은 누구일까요?` · `~라는 현상이 있습니다. 이 현상은 무엇일까요?`처럼 첫 문장이 정답의 종류만 미리 알려 주는 구조는 피합니다. 원문의 단서를 그대로 이어 한 문장으로 만들 수 있는지 먼저 검토합니다.

이 수정이 가장 중요합니다.

### 수정 ② 1절 — 긴 꼴의 선택 기준

이번 결과에서는 ID 1616, 2415가 긴 꼴로 잘못 분류됐습니다.

기존 34번의 정의를 조금 더 명확하게 바꾸는 것을 추천합니다.

- **긴 꼴**(`long` · 설명 두세 문장 + 질문) — 단서가 여럿이거나 배경·사건을 차례로 풀어야 읽히는 문항에 사용합니다. 단순히 설명 한 문장과 질문으로 구성된 문항은 `short`입니다. 설명을 두 문장 이상으로 나누더라도 새로운 단서나 인과관계가 자연스럽게 쌓여야 하며, 같은 정의를 반복해서는 안 됩니다.

### 수정 ③ 4절 — 정답 일부와 고유명사 보존의 충돌

이 부분은 이번 ID 126에서 실제 문제가 발생한 원인으로 보입니다.

기존 지시:

> 정답이 되는 말(과 그 일부 · 다른 이름)을 질문에 쓰지 않습니다.

그런데 ID 126의 정답은 `서태지와 아이들`이고, 원문에는 구성원인 서태지의 이름이 명시되어 있습니다.

AI가 정답 일부를 질문에 쓰지 말라는 규칙을 우선해 서태지를 삭제한 것으로 보입니다.

이 규칙은 다음처럼 바꾸는 것이 좋습니다.

- **정답 자체를 질문에 직접 노출하지 않습니다.** 다만 원문에 정답과 이름 일부가 겹치는 인명·고유명사가 독립적인 단서로 명시되어 있다면, 해당 고유명사는 임의로 삭제하지 않습니다. 정답 문자열의 일부와 우연히 겹친다는 이유만으로 원문의 핵심 단서를 제거해서는 안 됩니다.

### 수정 ④ 1절 — 정의 반복 금지 규칙 강화

기존 35번에 이미 정의 반복 금지가 있습니다. 하지만 이번 결과를 보면 실제로 제대로 지켜지지 않았습니다.

기존 문장을 다음처럼 강화하면 좋겠습니다.

- **정의를 평서문으로 바꾼 뒤 같은 것을 다시 묻지 않습니다.** `~가 있습니다. 이 ~는 무엇일까요?`처럼 첫 문장에서 정답의 종류나 정의만 소개하고 다음 문장에서 동일한 대상을 다시 묻는 구조는 사용하지 않습니다. 문장을 나누어야 한다면 첫 문장에는 독립적으로 가치 있는 배경이나 추가 단서를 담습니다. 추가 정보가 없다면 한 문장으로 합칩니다.

수정 우선순위

이 차이를 AI가 확실하게 이해해야 합니다.
