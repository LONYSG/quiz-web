전체적으로는 시범 2에서 정한 방향이 잘 반영됐고, 전수 작업을 계속해도 될 수준이야. 문장 꼴도 다양하고, 스토리형 문항도 단서를 순서대로 제시하는 방식으로 잘 구성됐어.

다만 이번 조각은 문장 표현보다 폐기 기준, 답의 유일성, 허용 답안 쪽에서 손볼 부분이 보여. 특히 네가 새로 정한 단순 언어 문제 배제 원칙과 지나치게 쉬운 문항 정리 원칙을 적용하면 몇 가지를 다시 판단해야 해.

## 1. 우선 수정하거나 재검토할 문항

\#4496 — 정답이 모호해질 수 있음

현재 질문은 모수의 일화를 설명하면서 마지막에 "이 식객의 이름이 들어간 사자성어"를 묻고 있어.

문제는 이야기 속에 두 가지 사자성어가 연결된다는 점이야.

- 낭중지추: 주머니 속 송곳처럼 재능이 드러난다는 뜻
- 모수자천: 모수가 스스로 자신을 추천했다는 뜻

현재 설명은 낭중지추 쪽 단서가 더 강한데, 질문은 모수자천을 요구하는 형태야.

권장: 정답을 모수자천으로 유지한다면 모수가 스스로 나서 평원군을 설득했다는 행동을 중심으로 서술하는 게 좋아. 낭중지추를 정답으로 한다면 마지막 질문을 재능이 드러나는 상황을 묻는 형태로 바꿔야 해.

\#2225 — aliases 수정 필요

`하면발효`는 라거의 동의어가 아니야. 하면발효는 발효 방식이고 라거는 그 방식으로 발효한 맥주 계열이야.

- 유지 가능: 라거
- 삭제 권장: 하면발효

이건 앞서 지적했던 `규칙과 위반 명칭` 문제처럼, 관련 개념을 정답 별칭으로 처리한 사례야.

\#2658 — 질문의 정확도 보완

활주로 번호는 활주로 방향의 자북 기준 방위각을 10으로 나누고 반올림한 값에 해당해. 현재 질문은 단순히 10으로 나눈 값이라고만 해서 반올림과 기준 방향이 빠져 있어.

권장 문장:

"활주로 끝에 적힌 '09' '27' 같은 숫자는 자북을 기준으로 한 활주로 방향의 방위각을 10으로 나눈 뒤 반올림한 값일까요?"

다만 마지막 질문은 "무엇일까요?"로 끝내는 편이 자연스러워.

\#6605 — aliases 범위

`바이에른`은 지역명이나 다른 대상을 가리킬 수도 있어서 FC 바이에른 뮌헨의 정확한 별칭으로 자동 허용하기엔 범위가 넓어.

- 유지: FC 바이에른 뮌헨
- 재검토 또는 삭제: 바이에른

\#4498 — 사자성어 질문은 적절하지만 길이 조정 가능

우나라와 괵나라의 이야기를 모두 설명해야 해서 긴 꼴 자체는 적절해. 다만 핵심은 두 나라가 서로 의지하는 관계였다는 점이므로, 궁지기의 간언을 조금 압축해도 돼.

지금 문장도 충분히 이해할 수 있으므로 필수 수정은 아니야.

## 2. 지나치게 쉬워서 폐기를 검토할 문항

이번 결과에서 `too_easy: true`가 붙은 문항은 모두 `rewrite`로 남아 있어. 이건 네가 전달한 새 기준과 실제 처리 결과가 일치하지 않는 부분이야.

특히 다음은 현재 퀴즈에 넣지 않는 쪽을 권하고 싶어.

| ID   | 정답  | 판단                     |
| ---- | --- | ---------------------- |
| 93   | 금   | 원소 기호 Au만 알면 되는 단순 암기  |
| 1683 | 붕어빵 | 일상 상식 수준의 너무 쉬운 문제     |
| 2323 | 식혜  | 일상 음식의 단순 정의           |
| 146  | 배트맨 | 캐릭터의 대표적인 설정만으로 답이 드러남 |
| 1659 | 간   | 신체 기관의 기초 상식           |
| 2924 | 양모  | 단순 정의형 어휘 문제           |
| 1855 | 낙엽  | 일상적인 단어의 정의            |
| 2438 | 부작용 | 기본적인 용어 정의             |

위 항목은 독립적인 사실 오류가 아니라, 현재 게임의 문항 선별 기준에 따른 폐기 권고야.

반면 다음은 쉬운 편이어도 퀴즈 소재로서 의미가 있으므로 무조건 폐기할 필요는 없어.

- \#189 대동여지도
- \#3219 최저임금
- \#3185 트라우마
- \#1732 전화위복
- \#3258 하이브리드차
- \#126 서태지와 아이들
- \#1643 저고리

여기서는 난이도 자체보다 소재의 인지도, 지식 가치, 다른 문항과의 중복 여부를 함께 봐야 해.

중요한 점: `too_easy`라는 표시만 붙이고 `verdict`를 `rewrite`로 두면 실제 배포 단계에서 폐기되지 않을 수 있어. 폐기를 원한다면 `verdict: discard`로 명시하거나, 배포 과정에서 해당 태그를 확실히 제외하도록 해야 해.

## 3. 영어·한국어 표기 문제

네가 전달한 방침과 비교하면 이번 조각은 크게 어긋나지 않아. 다만 다음 문항은 허용 답안에서 언어 표기를 함께 처리하는 게 좋겠어.

| ID   | 질문 소재       | 검토 의견                        |
| ---- | ----------- | ---------------------------- |
| 626  | 토르에서 유래한 요일 | Thursday와 목요일을 같은 정답으로 처리 가능 |
| 7031 | 원자          | 원자와 atom 모두 같은 대상으로 인정 가능    |
| 1242 | 인구총조사 방식    | 센서스와 census 표기 차이 허용 가능      |
| 1947 | 자동차 식별 번호   | VIN이라는 약어 자체가 핵심이므로 그대로 유지   |

특히 #626은 영어 요일 이름의 어원을 묻는 문항이므로 영어 표현이 소재에 꼭 필요해. 그렇다고 답을 반드시 영어로만 입력하게 할 필요는 없어. 목요일과 Thursday를 함께 인정하면 돼.

이런 문항은 영어 단어를 묻는 단순 번역 문제와 구분해야 해.

## 4. 그 외 문장 품질

대체로 괜찮아. 굳이 문장을 고치기보다 현재 표현을 유지할 문항이 더 많아.

몇 가지만 짚으면 다음과 같아.

- \#3244: "이 관습에서 나온 말"보다는 "이 가상의 벽을 무엇이라고 할까요?"가 정확해. 답이 제4의 벽이라면 개념 자체를 묻는 게 좋아.
- \#6172: 단서가 두 개라서 짧은 꼴을 선택한 것은 적절해. 다만 식물의 생태 관련 사실은 별도 검증 대상이야.
- \#7031: 긴 꼴은 다소 길어. 데모크리토스의 설명과 그리스어 어원 중 하나를 중심으로 압축할 수 있어.
- \#1150: "이 행사를 무엇이라고 할까요?"보다 "이 행사의 이름은 무엇일까요?"가 조금 더 자연스러워. 정답이 성화 봉송인지 성화 채화인지도 원본 정답과 대조할 필요가 있어.
- \#2575: "어떤 종류의 회사일까요?"는 회계법인을 묻는 데 적절해. 특정 회사명을 묻는 것으로 오해할 가능성도 적어.
- \#6635: "강원도에 있는 산입니다"라는 첫 문장은 정보량이 적어서 생략해도 무방해. 다만 원문에 필요한 지리적 단서가 있다면 보존해야 해.
