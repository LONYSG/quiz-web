# 퀴즈 질문문 말투 통일 — 지시서 (★ 설계 초안 2026-11-11 — 찬종 + GPT 가 다듬은 뒤 확정)

당신은 한국어 파티 퀴즈 게임의 **질문문 말투를 하나로 맞추는** 일을 맡았습니다. 함께 올라온 `조각-NN.txt` 에 질문문 100개가 있습니다(한 줄 = `id<TAB>질문문`). 질문문마다 아래 규칙에 맞게 **다시 써서** 돌려 주세요. 플레이어는 20~40대 한국인 친구들이고, 질문은 화면에 그대로 보이며 채팅창에 정답을 칩니다.

## 1. 절대 바꾸지 않는 것

- **사실 · 숫자 · 연도 · 고유명사 · 따옴표 안의 글 · 괄호 안의 글.** 단서를 더하거나 빼지 않습니다. 정답이 더 쉽거나 어려워지면 안 됩니다.
- 정답이 되는 말을 질문문에 넣지 않습니다(원문에도 없습니다 — 새로 만들지 마세요).
- 이모지 문항(`🚢🧊💔 — 이모지가 나타내는 외국 영화는?`)은 **그대로** 돌려줍니다.
- 바꿀 필요가 없는 질문문은 **원문 그대로** 돌려줍니다.

## 2. 꼴 — 설명문 + 마지막 질문문 하나

- 질문문은 **설명문(0~3문장) + 마지막에 짧은 질문문 하나**로 끝납니다. 질문 뒤에 설명이 오면 설명을 앞으로 옮깁니다.
  - 전: `실에 추를 매달아 흔드는 장치를 무엇이라 합니까? 이 장치에서는 추의 왕복 주기가 … 실의 길이에 따라 정해집니다.`
  - 후: `실에 추를 매달아 흔드는 장치입니다. 추의 왕복 주기는 추의 무게가 아니라 실의 길이에 따라 정해집니다. 이 장치는?`
- 설명문은 **"~습니다 · ~입니다"** 로 씁니다("~이다 · ~했다" 는 바꿉니다).
- 문장 하나는 70자 안팎까지. 전체는 원문 길이의 0.7~1.3배.

## 3. 마지막 질문문의 어미 — "~은/는?" 하나로

| 묻는 것 | 꼴 | 전 → 후 |
|---|---|---|
| 사물 · 개념 · 작품(대부분) | **`…은?` / `…는?`** | `…을 무엇이라 합니까?` → `…은?` · `이 앨범의 제목은 무엇일까요?` → `이 앨범의 제목은?` · `이 무술은?`(그대로) |
| 사람 | `이 사람은?` · `이 정치인은?` · `이 가수는?` | `이 정치인은 누구일까요?` → `이 정치인은?` |
| 장소 · 나라 | `이 나라는?` · `이곳은?` · `…는 어디?` | `등재를 신청한 나라는 어디인가?` → `등재를 신청한 나라는?` |
| 수량 | `…는 몇 개?` · `…는 몇 명?` | `보통 몇 개씩 가지고 있는가?` → `보통 몇 개씩 가지고 있을까?`(★ 미정 — §6) |
| 연도 · 때 | `…는 몇 년?` · `…는 언제?` | |
| 가장 흔한 이름을 묻는 것 | `…를 흔히 무엇이라 부르는가?` → `…를 흔히 부르는 말은?` | `이 제도를 흔히 무엇이라 할까요?` → `이 제도를 흔히 부르는 말은?` |

- 질문문의 주어가 앞 설명문에 이미 나왔으면 **"이 X 는?"** 처럼 짧게 받습니다(`이 미국 해군 잠수함은 무엇일까요?` → `이 잠수함은?`). 같은 말을 두 번 하지 않습니다(설계 D-328 — 주어·지시어 중복 금지).
- 질문문 한 문장이 너무 길면(40자 넘게) 설명을 앞 문장으로 떼어 냅니다.
- "무엇 · 누구 · 어디" 같은 의문사는 **마지막 꼴에서 뺄 수 있을 때만** 뺍니다. 빼면 뜻이 흐려지는 문장은 둡니다(`사과를 영어로 쓰면?` → 그대로).

## 4. 읽기 쉽게 — 손질 허용 범위

- 어색한 번역투 · 겹말 · 지나치게 긴 수식은 **뜻이 같은 범위에서** 자연스럽게 고칩니다.
- 쉼표 · 띄어쓰기 · 맞춤법은 표준으로.
- 외국 이름 · 작품 제목의 표기는 원문 그대로(표기법 교정 안 함).

## 5. 출력 — 이 형식 그대로

**JSON 하나만**(설명 글 없이 · 코드 블록 하나). 100개 전부 · 순서 그대로 · 바꾸지 않은 것도 넣습니다.

```json
{
  "chunk": "01",
  "results": [
    { "id": 4622, "question": "1969년 비틀즈가 마지막으로 녹음한 앨범입니다. 네 멤버가 EMI 스튜디오 앞 횡단보도를 한 줄로 건너는 표지 사진으로 유명합니다. 이 앨범의 제목은?" },
    { "id": 22, "question": "사과를 영어로 쓰면?" }
  ]
}
```

## 6. (찬종 · GPT 가 정할 것 — 확정 때 지움)

- 수량 질문 둘째 꼴("몇 개?" 만으로 짧으면 "몇 개일까?" 를 허용할지).
- 설명문 어미를 "~습니다" 로 완전 통일할지.
- "~는 어디?" / "~는 언제?" 를 "~는?" 으로 더 줄일지.
