- 정답 겹침 후보 12건(extraSameAnswer)을 확인한 결과: 지구돋이·아타리 쇼크는 정상 짝(철회), V2·오티스·나이트·칸트·베르사유 등은 different, 칼리닌그라드만 drop.

## 6. 반복되는 오류 유형 — 생성 규칙에 넣을 것
1) 2회차가 1회차의 정의·사건 이름을 단서만 바꿔 되묻기 (same-fact fix·drop 22건, sameFact same 20·partial 73). 십장생·비색·튤립 파동·연습생·성악설·특별시·진주만·브리티시 인베이전. 규칙 제안: 2회차를 쓰기 전에 "1회차 질문·해설에 이미 있는 사실을 묻고 있지 않은가"를 한 줄로 적고, 정답을 바꾸지 않을 거면 1회차가 묻지 않은 속성(연도·인물·장소·수치)을 묻는다.
2) 질문 안에 정답 조각이 들어간 것(exposed): 약어 풀이(H.O.T. = High-five Of Teenagers, DC = 디텍티브 코믹스의 머리글자). 질문 규칙에도 "정답의 머리글자·풀이를 질문에 쓰지 않는다"를 넣을 것.
3) 해설·질문의 확인 안 된 상세 단정: 칸트가 쾨니히스베르크를 평생 안 떠났다(실제 1748~54 가정교사), 몽골 원정 두 번 모두 태풍(1274 는 철수), 『초학기』의 高麗를 고려로(실제 고구려), 패러데이가 크리스마스 강연을 시작, 해리 벡 시험 인쇄 연도, 골드러시 반죽 씨 등. 연도·"처음/마지막/모두"·"평생" 같은 단정어는 출처 한 줄이 없으면 "전한다/흔히 알려져 있다"로 쓰거나 뺀다.
4) 빈칸·글자 수가 정답과 어긋남(프로메테우스 5칸 vs 6음절), 부제 오타(미레레레 → 미제레레): 생성 직후 기계 검사 가능 — 질문 안 ○ 개수 = 정답 글자 수, 고유명사 표기 대조를 파이프라인에 넣을 것.
5) 한정어가 모자라 답이 둘 이상(반지의 제왕 ↔ 호빗): 같은 작가의 다른 작품·같은 인물의 다른 업적이 답이 될 수 있는지 확인.
6) 같은 R030 안에서 서로 다른 시드가 같은 소재를 생성(오일러·8월·루이 14세): 시드 간 dedupe 가 파일 단위로만 도는 듯하다. 적재 전 R030 내부 대조를 게이트에 추가.
7) 2회차가 db 1회차 질문에 이미 담긴 이름 대응을 되묻는 경우(칼리닌그라드: db:3306 이 "옛 이름은 쾨니히스베르크").
8) 힌트: 이번 hint-v3 는 거의 깨끗(2/188). 신 이름·별칭을 풀어 쓸 때 정답 조각이 섞이는 것만 남음(아프로디테 ⊃ 프로).

## 7. 자기 점검
- 대량 판정이라 판정자 6+6개 조각으로 나눴다. 같은 항목이 여러 쌍에 걸치면 따로 판정되어 갈린다는 V001 교훈에 따라 같은 정답 묶음을 5절·2-3 에서 한꺼번에 다시 봤다. 짝 판정 일관성은 완전하지 않다 — 경계선 20건을 4-2 에 드러냈다.
- 짝 ok 563건 중 내가 문구까지 읽은 것은 sameFact≠different 로 표시된 ok 68건, fix·drop·unsure 전부다. sameFact=different 인 ok 약 500건은 판정자 결과를 그대로 받았고 개별로 다시 읽지 않았다 (표본 검증 안 함).
- 힌트 188건은 내가 전부 읽고 checkHint 로 돌렸다. 힌트의 사실은 웹으로 확인하지 못했다.
- 사실: 1차에서 출처 없이 지식으로만 둔 255 주장 중 일부는 WebFetch 로 보강했으나 미확인 96건이 남았다. 2차에서 새로 틀린 것 2건(고구려, 칸트)이 나왔으니 남은 미확인 중에도 틀린 것이 있을 수 있다.
- V001 교훈(실제 문구에서 확인한 것만 적기): fix 사유의 인용은 입력 파일에서 가져왔고, 힌트 제안 2건은 checkHint 로 통과 확인. 인용 전수 기계 검증은 하지 않았다.
- 판정만 했다: DB 쓰기·적재·생성·규칙 변경·서버 기동 없음. 읽기 전용 DB 조회(정답 누적 집계)만 사용.
