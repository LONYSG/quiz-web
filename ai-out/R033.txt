1. A — 바로 고칠 것
=====================================================================

  A-1. 시작은 항상 5초 (D-145 · Q-11 개정)
    · 설정 화면에서 시작 방식(즉시/카운트다운)·카운트다운 초 칸을 없앴다
    · 서버는 들어온 값을 보지 않고 countdown / 5초로 맞춘다 — ★ 거부하지 않는다
      (거부하면 옛 클라이언트·봇이 문제 수만 바꾸려는 요청까지 막힌다)
    · 게임 시작 직전에 설정을 다시 맞춘다 — 방에 옛 설정(즉시 시작)이 남아 있어도 5초가 된다
    · ★ 판단 — 유지되는가
        방장 취소           유지 (카운트다운 화면 "카운트다운 취소")
        카운트다운 중 입장   유지 (봇 countdown 확인)
        만료 재검증(D-025)  유지 (봇 difficulty [5] 확인 — 5초 안에 문제가 줄면 로비로)
        다시 하기·기존 방    충돌 없음 (시작 방식이 하나뿐이다)
    · 남겨 둔 것: 즉시 시작 코드 경로(T02) — 이제 타지 않는다. 다음 라운드 정리 대상

  A-2. 서버 시각 오프셋 표시 제거 (D-146)

    · ★ 시계 동기화 기능은 그대로 — 타이머·카운트다운이 기대고 있다

  A-3. OpenTDB 문항 내림 + 출처 문구 제거 (D-147)

2. B — 디자인 전면 개편 (D-148)
=====================================================================

  2-1. 테마 3종 — 색·테두리 두께·둥글기·그림자만 다르다 (간격·글자 크기는 같다 → 한 화면이 테마와 무관하게 지켜진다)

    | 테마 | 방향 |
    |---|---|
    | 파스텔 (기본) | 크림 바탕 · 보라·분홍 · 큰 둥글기 · 부드러운 그림자 — 캐치마인드 쪽 |
    | 원색 | 노란 줄무늬 바탕 · 빨강·파랑 · 굵은 검정 테두리 · 만화 그림자 — 가장 또렷하다 |
    | 밤 | 짙은 남색 · 형광 보라·분홍 — 어두운 변형 |

    · 토큰 한 곳: client/src/styles.css 맨 위 [data-theme] 세 묶음. 화면 규칙은 var(--…) 만 쓴다
    · 플레이어 색 10종도 테마마다 따로 — 밝은 바탕에서는 진한 쪽으로 (닉네임이 읽히게)

  2-2. 정보 우선순위 — 문제 지문 > 정답 공개·정답자 > 타이머·점수
    · 문제 카드: 굵은 테두리 + 위쪽 색띠 + 띄운 그림자 — "문제와 시간초가 있는 공간이 티가 안 난다" 에 대한 답
    · 문제 지문 1.45rem 굵게, 새 문제마다 살짝 올라오며 나타난다
    · ★ 타이머: 큰 숫자(2.6rem)를 없앴다 → 머리줄 오른쪽 작은 숫자 + 카드 안 줄어드는 막대. 10초 주황 · 5초 빨강으로 뛴다
    · ★ 힌트 자리를 처음부터 두 줄 잡아 둔다 — 초성이 나와도 아래가 밀리지 않는다 ("줄바꿈이 생겨 못생겨진다")
    · 상태 알약 — 영문 상태값(QUESTION_ACTIVE)을 "문제 풀이 중" 같은 말로
    · 아바타 — 닉네임 첫 글자 + 플레이어 색 (캐치마인드의 캐릭터 자리). 색만으로 가르지 않는다 (글자가 함께)

  2-3. ★★ 정답자 연출
    · 정답이 나오면 정답 공개 카드에 아바타(큰 원) + "정답!" + **이름이 화면에서 가장 큰 글씨** + "+1" + 꽃가루 몇 조각
      ★ ui-check 가 잰다 — 정답자 이름 36.8px > 문제 지문 23.2px
    · 내가 맞혔으면 "나" 배지 + 반짝이는 효과음이 덧붙는다
    · 점수판 — 점수가 오르면 숫자가 톡 튄다 / 1위 줄을 옅게 칠한다
    · 결과 화면 — 🏆 우승자(공동이면 모두) · 1·2·3위 메달

  2-4. ★ 로비도 한 화면 (원래 게이트가 아니었다 — 1.71배)
    · 세로 칸 두 개(왼쪽 게임 설정·시작 / 오른쪽 초대 링크·참가자) — 2×2 격자는 카드 높이가 달라 빈자리가 생겼다(1.16배)
    · 참가자 목록 고정 높이(10명이면 안에서 스크롤) · 로비에서는 채팅 폭을 조금 줄였다
    · ★ 정보는 지우지 않았다 — 글자 크기·여백만 줄였다 (D-076 의 원칙)
    · 결과: **네 화면 × 세 테마 = 12개 게이트 전부 1.00배.** 로비도 이제 ui-check 게이트다

  2-5. 지킨 것
    · 한 화면 게이트(테마마다) / D-022 라벨 규칙(ui-check 레이아웃 검사 통과) / 토스트 화면 아래 고정(R009, 겹침 검사 통과) / 단축키 전부
    · 움직임은 짧게(0.2~0.6초). 움직임을 줄이는 시스템 설정이면 끈다

3. C — 소리 (D-149)
=====================================================================

  3-1. 출처 — ★ 전부 브라우저에서 합성 (Web Audio). 음원 파일이 없다
    · 근거: 수집·변환·용량·출처 확인이 필요 없다 / 후보를 코드 몇 줄로 바꿔 끼운다 / 터널 데이터가 늘지 않는다
    · ★ 대가: 녹음된 음원보다 단순한 소리다. 고른 뒤 실제 음원으로 바꾸는 것은 쉽다 (sfx() 한 함수)

  3-2. 목록
    | 언제 | 소리 |
    |---|---|
    | 배경음악 (3곡 중 하나) | 통통 경쾌 / 잔잔한 오르골 / 8비트 게임기 — 작게, 문제 푸는 동안은 조금 더 줄인다 |
    | ★ 정답 (3종 중 하나) | 딩동댕 / 코인 / 빰빠밤 |
    | 내가 정답 | 정답 소리 + 반짝 |
    | ★ 오답 | **없음** (건우 확정 — 채팅이 곧 답이라 오답이 아주 많다) |
    | 다른 사람 입장 (로비) | 뽁뽁 |
    | 카운트다운 5·4·3·2·1 | 똑 |
    | 게임 시작 / 문제 등장 | 띠리링 / 쓸어 올림 |
    | 힌트 공개 (20초·10초) | 반짝 |
    | 마지막 5초 | 아주 작은 똑딱 |
    | 시간 종료 / 넘김 | 부드럽게 내려가는 두 음 / 미끄러짐 |
    | 일시정지 · 재개 | 낮은 음 · 올라가는 두 음 |
    | 결과 화면 | 종소리 아르페지오 |

  3-3. 끄기·음량·자동재생
    · 배경음악·효과음 **따로** 켜기·끄기 + 음량 슬라이더 / Alt+M 은 둘 다
    · 첫 클릭·키 입력 뒤부터 나온다 (브라우저 자동재생 정책)
    · 설정은 같은 브라우저에서 유지
    · ★ 입장·재접속 순간에는 지난 일을 다시 울리지 않는다 (처음 그림은 무음)
