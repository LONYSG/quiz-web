■ 1. 스위치 `BETA_MAIN`(.env · 1 = 켬 · 없거나 그 밖 = 오늘과 똑같다). `config.ts` 의 자리 키 목록(31줄 — 개발 트리가 실 값을 물려받지 않게 하는 그 목록)에도 넣는다. 켜졌을 때:
  1) **공개 주소로 온 요청**(Host = `PUBLIC_HOSTNAME` · `www.` 포함 — `siteOf` 가 'public' 으로 보는 것 가운데 이 두 Host 만) → `302` 로 `https://<FRIEND_HOSTNAME><원래 경로 + 쿼리>`. **302**(임시 — 나중에 공개 주소를 정식으로 쓸 때 브라우저 · 검색 엔진에 박혀 있지 않게). `/healthz` 는 보내지 않고 지금처럼 답한다. 준비 중 한 장(R111)은 켜진 동안 안 나온다(코드는 지우지 않는다 — 끄면 돌아온다). 모르는 Host · 임시 주소(5번 규칙 → 공개)는 보내지 않는다(그대로 · 안전한 쪽).
  2) **베타 자리의 계정 문을 연다** — `friendGate` 가 켜진 동안 false: 베타에서 가입 됨(authRoutes 120) · 지인 표시 없는 계정도 로그인 됨(238) · `/api` 의 FRIEND_ONLY 403 없음(index 185) · 소켓 쪽 같은 검사(304 · `socket/index.ts`)도. `is_friend` 값과 칸은 그대로 둔다(나중에 정식으로 가를 때 쓸 수 있게).
  3) **베타에 보이는 것은 그대로** — 자리 = 'friend' 로 판별되는 것은 바꾸지 않는다: 치이카와 이모티콘 · 노래 맞히기 · 지인 전용 미니게임 · 모드가 전부 보인다(`hiddenFor('friend')`).
  4) 가입 · 로그인 한도(속도 제한 · 봇 막기)가 공개 자리 가입에 걸던 것과 **같이 베타 가입에도 걸리는지** 확인 — 공개 자리에만 걸려 있었다면 베타에도 건다.
  5) 화면 말: 베타 자리 화면에 "초대받은 계정만" · "공개 주소에서 가입해 주세요" · 공개 주소로 가는 안내 링크(`publicUrl`) 같은 말이 켜진 동안 안 나오게. 이름 옆 "베타" 표시는 남긴다(찬종 말 그대로 "beta").
  6) 검색 엔진: 베타의 `X-Robots-Tag: noindex` 는 **그대로 둔다**(찬종이 정할 일 — 보고 맨 위에 한 줄로 "지금은 검색에 안 나온다 · 풀려면 스위치 하나"). 풀 수 있게 `BETA_INDEX=1` 을 따로 하나 둔다(기본 꺼짐).
  7) 쿠키: 로그인 쿠키가 베타 Host 에 붙는지(공개 주소에서 로그인했던 사람은 베타에서 다시 로그인해야 한다 — 그것이 맞으면 그대로 두고 보고에 한 줄).
