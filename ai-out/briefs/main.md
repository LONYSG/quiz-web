■ A. 고정 주소 — Cloudflare "이름 붙인 터널"
  · `scripts/dev-tunnel.mjs` · `play.mjs`: `.env` 에 `TUNNEL_NAME` · `PUBLIC_HOSTNAME`(예: play.내도메인) 이 **둘 다 있으면** `cloudflared tunnel run <이름>` 으로 띄우고(주소가 바뀌지 않는다 · 주소 = `https://<PUBLIC_HOSTNAME>`), 없으면 **지금처럼 임시 주소**(trycloudflare)로. 켠 뒤 확인(밖에서 `/healthz` 200 → 브라우저) · 클립보드 · 로그는 지금 흐름 그대로. 메뉴 4(상태)에 "주소: 고정/임시" 한 줄.
  · 고정 주소일 때 달라지는 것을 확인: 세션 쿠키가 주소가 같아 **다시 켜도 로그인이 유지**된다 · 초대 링크 · `PUBLIC_BASE_URL`. 임시 주소 때만 맞던 문구("주소는 켤 때마다 바뀝니다")는 갈래를 나눈다.
  · 터널 설정 파일(`config.yml`)이 필요하면 저장소 밖(사용자 폴더 `.cloudflared`)에 두는 것을 전제로 하고, 저장소에는 **본보기 파일**만(`ops/cloudflared.example.yml` — 실제 이름 · ID · 인증 파일은 커밋하지 않는다 · `.gitignore` 확인).
  · ★ 도메인이 아직 없으므로 실제 연결은 못 해 본다 — 임시 주소 흐름이 그대로 도는 것 + 고정 주소 갈래는 명령 조립 · 설정 읽기를 테스트로. 찬종이 따라 할 순서는 `docs/11` 에 "도메인 연결 — 한 번만"으로(아래 D).
■ B. 서버 보안 — 먼저 지금 상태를 재고(표로), 그다음 막는다
  설계가 본 것(확인하고 고친다): 로그인 · 가입에 시도 제한 없음 · 보안 헤더 없음 · 소켓 연결 수 · 이벤트 속도의 일반 한도 없음(채팅 도배 제한만) · 서버가 `0.0.0.0` 으로 듣는다 · DB 포트(5434)가 모든 주소에 열려 있고 비밀번호가 공개 저장소의 `docker-compose.yml` 에 적혀 있다.
  1. **진짜 IP**: 터널 뒤에서는 접속 주소가 전부 127.0.0.1 이다. 요청이 **루프백에서 왔을 때만** `CF-Connecting-IP` 를 믿는 함수 하나(`clientIp(req)` · 소켓도 같은 함수) — 아래 한도가 전부 이것을 쓴다. 헤더를 직접 보내 속이는 경우를 테스트.
  2. **로그인 · 가입 시도 제한**(메모리): 로그인 실패 = 아이디마다 5회/10분 → 그 뒤 15분 잠금(맞는 비밀번호도 그동안 거부 · 안내 "잠시 뒤 다시") + IP 마다 30회/10분. 가입 = IP 마다 5개/시간 · 20개/하루. 잠금 안내는 지금 오류 문구 꼴로.
  3. **비밀번호 계산(argon2) 동시 실행 한도**: 한 번에 2개 · 대기 줄 20 · 넘치면 "잠시 뒤 다시"(503 꼴) — 로그인 폭주가 게임 진행(틱 · 판정)을 굶기지 않게. 폭주 중 판정 지연을 봇으로 잰다(기준 2ms — R015).
  4. **HTTP**: 보안 헤더(`X-Content-Type-Options` · `Referrer-Policy` · `frame-ancestors 'none'`(끼워 넣기 금지) · https 일 때 HSTS) — CSP 는 지금 화면(인라인 스타일 · 소리 · Apple 미리듣기 · 그림 data:)이 깨지지 않는 범위로만, 깨지면 보고서에 "보류"로. 요청 본문 한도(지금 32kb) 확인 · 아바타 등 올리기 경로의 크기 · 형식 검사 · 제보/평가 경로의 계정당 속도 한도 · 오류 응답에 스택 · 내부 경로가 나가지 않는지.
  5. **소켓**: 연결할 때 `Origin` 검사(허용 = `PUBLIC_HOSTNAME` · localhost · 임시 주소 꼴) · IP 당 동시 연결 40 · 계정당 8 · 로그인 안 된 소켓은 10초 안에 끊기 · 소켓당 이벤트 속도 한도(모든 이벤트 합쳐 초당 30 · 넘으면 그 소켓만 끊음 — 캐치마인드 그리기 · 연타 미니게임이 정상 속도에서 걸리지 않는지 실측해 값을 정한다) · `maxHttpBufferSize` 를 가장 큰 정상 메시지(그림 획) + 여유로 명시 · 방 만들기 계정당 5개/10분.
  6. **듣는 주소**: 서버는 기본 `127.0.0.1` 로 듣는다(`HOST` 환경 변수로 바꿀 수 있게 — 같은 공유기의 다른 기기에서 직접 붙는 길을 막는다 · 터널은 루프백으로 들어온다). 봇 · ui-check · smoke 가 그대로 도는지.
  7. **DB**: `docker-compose.yml` 의 포트를 `127.0.0.1:5434:5432` 로 · 비밀번호를 `${POSTGRES_PASSWORD:-quizlocal}` 꼴로 바꾸고, **지금 볼륨의 비밀번호를 실제로 바꾸는 일은 하지 않는다**(GEN · 다른 창이 같은 값을 쓴다 — 바꾸는 순서를 `docs/11` 에 적고 찬종 할 일로). 컨테이너를 다시 만들 때는 열린 판 0 · GEN 이 쓰는 중이 아닐 때(트랜잭션 조회) · 끝나고 두 DB 응답 확인.
  8. `npm audit` 결과를 표로(높음 이상만) — 고치는 것은 패치 수준만, 큰 버전 올림은 목록.
  9. **공격 봇**: `bot.mjs` 에 `attack` 묶음 — 로그인 무차별 · 가입 폭주 · 소켓 연결 폭주 · 이벤트 폭주 · 큰 메시지 · 가짜 IP 헤더. 각각 "막혔다 + 그동안 옆 방의 판이 정상(판정 지연 · 틱)"을 확인한다. 고치기 전 / 뒤 숫자를 보고에.
