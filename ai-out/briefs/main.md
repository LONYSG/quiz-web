■ 1. 주소와 계정
  · `.env` 의 `FRIEND_HOSTNAME`(★ 찬종 2026-11-19 확정 = `beta.quizdojang.com` · "지인"이라는 말이 드러나지 않는 평범한 서브 네임으로 골랐다 — 화면 글 · 안내에도 "지인 전용" 대신 "베타" 쪽 말을 쓴다: 예 "베타 주소는 초대받은 계정만 들어올 수 있어요")으로 들어온 요청 = **지인 자리**, `PUBLIC_HOSTNAME` = **공개 자리**. 판별은 한 함수(`siteOf(req)` — Host 머리말 · 소켓도 같은 함수 · R107 의 Origin 허용 목록에 지인 주소 추가).
  · ★ 지금과 같게: `PUBLIC_HOSTNAME` 이 **없으면**(임시 주소 · localhost — 오늘까지의 쓰임) 전부 **지인 자리로 본다**. 그래야 도메인을 붙이기 전의 친구 플레이가 그대로다. dev(3001)는 환경 변수 `SITE_FORCE=public|friend` 로 양쪽을 시험한다.
  · 계정에 `is_friend`(마이그레이션 · 기본 false). **이 마이그레이션이 도는 시점에 이미 있는 계정은 전부 true**(지금까지의 가입자는 다 지인이다 · 봇 포함). 새로 가입하는 계정은 false. 찬종이 켜고 끄는 길 = ops 메뉴 한 줄("지인 표시 켜기/끄기" — 아이디 여러 개 · 보여 주기 → 확인 → 실행 · 스크립트 `scripts/friend-set.mjs`).
  · 지인 자리에는 **지인 계정만** 들어간다: 지인이 아닌 계정이 로그인하면 "지인 전용 주소입니다" 안내와 공개 주소 링크. 지인 자리에서의 **가입은 막는다**(가입은 공개 주소에서 · 그 뒤 찬종이 표시를 켠다). 세션 쿠키는 주소마다 따로다(도메인이 달라 자연히 — 한쪽 로그인이 다른 쪽에 영향 없음을 확인).
  · 지인 자리의 모든 응답에 `X-Robots-Tag: noindex` · 공개 자리 화면 어디에도 지인 주소 링크를 두지 않는다. 광고는 아직 없지만 부트 정보에 `site: 'public' | 'friend'` 를 실어 나중에 광고 코드를 공개 쪽에만 넣을 수 있게 한다.
■ 2. 방 — 지인 방에서만 켜진다
  · 방은 **만든 주소의 자리**를 물려받는다(`room.site`). 지인 방에는 지인 계정만 들어온다(초대 링크는 방장 브라우저 주소로 만들어지므로 저절로 지인 주소). 공개 방 ↔ 지인 방은 로비 목록 · 방 코드로 서로 보이지도 들어가지도 않는다.
  · **지인 전용 내용은 `room.site === 'friend'` 일 때만 서버가 내보낸다**:
    - 미니게임 뽑기 · 방식 메뉴: 공개 방에서는 song · songyear · (숨김 규칙에 걸린) price 가 목록에 없고, 항목 뽑기에서 지인 전용 항목이 빠진다(경험 기록 · 가방 섞기가 깨지지 않는지 — 항목 수가 준 상태로 한 바퀴).
    - 그림 길(`/api/minigame/image/:id`): `product-page` 그림은 **지인 자리 요청 + 지인 계정**일 때만. 공개 자리에서는 404(주소를 알아도 못 받는다). 노래 미리듣기 주소 · 앨범 표지 주소는 공개 방 스냅샷 · 이벤트 어디에도 실리지 않는다(테스트 한 건씩).
    - 치이카와: 공개 자리에서는 상점 · 뽑기 · 이모티콘 창 · 그림 길에 **나오지 않는다**(가진 사람도 공개 방에서는 못 보낸다 · 가진 것은 지워지지 않는다 — 지인 방에 가면 그대로). 지인 자리에서는 지금과 같다.
  · 기록은 한 DB 에 그대로: 판 · 답 · 경험 · 포인트 · 전적 · 업적 · 제보는 자리와 상관없이 같은 계정에 쌓인다. 판에 자리를 남긴다(`games.site` 또는 있는 칸 — 나중에 공개 쪽 통계만 따로 보려고). 전적 화면에서 지인 방의 노래 판이 공개 자리에서도 **기록(점수 · 순위)으로는 보이되** 곡 제목 · 표지 같은 지인 전용 내용은 보이지 않는지 확인.

  · 사진류 공개 화면: 그림이 나오는 모든 게임에서 저작자 · 라이선스 줄이 **빠짐없이** 보이는지(CC BY · BY-SA 는 의무다 — "고침"이 적힌 그림은 그 말까지). 빠진 게임이 있으면 같은 꼴로 넣는다.
  · 표기 문구의 정본은 한 파일(`shared` 또는 `docs/22-CREDITS.md`)에 둔다.
  · ★ 문제 데이터 라이선스 정리(찬종: "문제 데이터 라이선스도 없잖아. 전부 ai 창작인데"): 문항은 전부 우리가 만든 것이다(외부 문제집은 R106 에서 지웠다). 옛날 그 문제집과 섞일 때 맞추려고 붙였던 "CC BY-SA 4.0 으로 배포한다"는 선언을 걷는다 — `DATA_LICENSE.md` 를 "문제 데이터는 퀴즈도장이 직접 만든 것이며 공개 라이선스로 내놓지 않는다"로 다시 쓰고(나무위키 줄 · 표도 뺀다), `sources.license` · `questions.license` 의 `CC-BY-SA-4.0` 값은 마이그레이션으로 비운다(칸은 둔다 · 코드가 그 값을 화면이나 응답에 쓰는 곳이 있으면 같이 걷는다) · `package.json` 의 코드 라이선스(MIT)는 건드리지 않는다. 주제 세트 파일의 `source` 칸(만든 경위 기록)은 그대로 둔다.
