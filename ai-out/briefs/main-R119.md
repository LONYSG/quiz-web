■ 1. 스위치 `SITE_ONE`(.env · 1 = 켬 · 없거나 그 밖 = 오늘과 똑같다). `config.ts` 의 자리 키 목록(31줄 — 개발 트리가 실 값을 물려받지 않게 하는 그 목록)에도 넣는다. 두 자리를 가르는 코드(R109 · R111)는 **지우지 않는다** — 나중에 "문제제기 되면 기능 빼고 정비"할 때 다시 쓸 수 있게 스위치 하나로 갈라 둔다. 켜졌을 때:
  1) **자리 판별 = 늘 한 자리**: 어느 Host 로 와도 지금 베타가 보이는 것과 같은 내용(`hiddenFor` 가 지인 자리와 같은 결과 — 숨김 없음). 판별 함수 한 곳(`siteOf` / `siteOfHost`)에서 처리하고 곳곳에 `if` 를 흩지 않는다.
  2) **계정 문 열기**: `friendGate` = false — 가입 됨(authRoutes 120) · 지인 표시 없는 계정도 로그인 됨(238) · `/api` FRIEND_ONLY 403 없음(index 185) · 소켓 쪽 같은 검사(304 · `socket/index.ts`)도. `is_friend` 값과 칸은 그대로 둔다.
  3) **닫힌 공개 자리 끄기**: 준비 중 한 장 · 403 블록(index 154~)이 켜진 동안 안 걸린다(`PUBLIC_OPEN` 과 상관없이).
  4) **beta 주소 → 메인**: Host = `FRIEND_HOSTNAME` 인 화면 요청 → `301` 로 `https://<PUBLIC_HOSTNAME><원래 경로 + 쿼리>`(철수했으니 영구). `/healthz` 는 보내지 않는다. `/api` · 소켓 요청은 보내지 말고 그대로 받는다(이미 열린 탭이 갑자기 끊기지 않게 — 새로 고치면 화면 요청이 메인으로 간다).
  5) **Origin**(`security/socket.ts`): 메인은 지금처럼 허용 · beta Host 도 허용 유지(4 의 열린 탭).
  6) **검색 엔진**: 메인에는 `noindex` 를 붙이지 않는다(검색에 나오게 — 공개 자리의 기존 규칙대로). beta 는 301 이라 따로 필요 없다. `robots.txt` · 사이트맵이 있으면 메인 기준인지 본다(없으면 만들지 않는다 · 보고에 한 줄).
  7) **한도**: 가입 · 로그인 속도 제한 · 봇 막기가 켜진 동안에도 메인 가입에 걸리는지 확인(지금 공개 자리 가입에 걸던 것과 같게).
  8) **화면 말**: "초대받은 계정만" · "공개 주소에서 가입해 주세요" · 공개 주소로 가는 안내 링크(`publicUrl`) · "베타 주소" 같은 두 자리 전제의 말이 켜진 동안 안 나오게. 이름 옆 "베타" 표시가 있으면 **떼지 않는다**(정식 출시 전이라는 표시 — 찬종이 빼라고 하면 그때).
  9) 쿠키: 로그인 쿠키는 메인 Host 에 붙는다 — beta 에서 로그인해 있던 사람(찬종의 지인)은 메인에서 한 번 다시 로그인한다. 그대로 두고 보고에 한 줄.
