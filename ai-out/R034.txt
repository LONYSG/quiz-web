1. 스킵 투표 — 무엇이 빠져 있었나 / 남은 "미구현" 문구
=====================================================================

  ★ 증상: "스킵 투표가 아예 안 된다"
  ★ 원인 (서버와 화면 양쪽에 하나씩 + 테스트 구멍)

    (1) 서버 — 문제가 시작될 때 투표 현황(0표 / 필요 표수)을 보내지 않았다.
        현황은 누가 투표하거나 인원이 바뀔 때만 나갔다.
    (2) 화면 — 새 문제의 "필요 표수" 를 직전 값에서 이어받았는데, 직전 값은 정답 공개 때 지워져 있었다
        → 늘 "모름" → 투표 버튼 대신 "혼자일 때는 투표로 넘길 수 없습니다" 가 뜨고 Alt+S 도 꺼져 있었다.
        ★ 2명 이상이어도 그랬다. 이것이 "아예 안 된다" 의 정체다.
    (3) 화면 — "내가 투표했는지" 를 몰랐다(서버도 안 보냈고 화면도 안 바꿨다) → 투표 취소가 되지 않았다.
    (4) 테스트 — 봇은 소켓으로 직접 투표해 **화면을 거치지 않았다.** ui-check 에는 두 사람 게임이 없었다.
        → 서버의 투표 처리·임계값·방장 강제 스킵 자체는 정상이었다(봇이 계속 통과한 이유).

  ★ 고친 것
    · 문제 시작 때마다 현황을 보낸다 / 일시정지 뒤 재개 때도 보낸다 (재개 뒤 버튼이 사라지던 것도 이번에 찾아 고쳤다)
    · 현황을 사람마다 보내며 "본인이 투표했는지" 만 담는다 — 누가 투표했는지는 여전히 안 보낸다(guide 22절)
    · 화면: 문제 아래 행동 줄에 **분홍 "⏭ 넘기기 투표 Alt+S"** 버튼 + "1 / 2" + 점 + "접속 N명 중 M명이 누르면 넘어가요".
      누르면 "넘기기 취소" 로 바뀐다. 방장 버튼(방장 넘기기·강제 종료)은 작게 옆에.
    · ★ ui-check 가 **두 브라우저로** 확인 — 0/2 로 시작 · 방장 클릭 1/2 · 한글 자판 상태 Alt+S 로 취소 0/2 ·
      F2 로 다시 1/2 · 게스트 Alt+S → "투표로 넘겼습니다". 봇 concur 도 시작 현황·selfVoted 를 확인한다.

  ★ 화면의 "미구현" / "Phase" / "나중에" 문구
    · 찾은 것: 로비 참가자 카드 안내 "…판정 대상에서 빠집니다(Phase 6)" 1건 → 기능이 있으므로 지웠다(안내는 ⓘ 로 옮김).
    · 그 밖: 화면에 보이는 문구 0건. (코드 주석의 Phase 표기는 화면에 안 나온다. "방장이 다음 게임을 준비 중입니다" 는
      진짜 상태 안내라 남겼다.) 서버가 보내는 안내 문구에도 0건.

2. 화면 재구성 — 배치 / 말풍선 마스킹 / 넓게 쓰기 / 줄바꿈
=====================================================================

  ★ 배치 (1280×720 기준, 로비·게임·결과 공통)
    [참여자 1~5] [ 가운데: 로비 설정 / 문제·정답 공개·행동 줄 / 결과  +  아래 채팅 로그·입력창 ] [참여자 6~10]
    · 무대 높이를 화면에 맞춰 고정 — 참여자 칸은 5등분, 채팅은 가운데의 남는 높이를 채운다
    · 참여자 칸: 자리 번호 · 아바타 · 닉네임(색) · 점수(게임·결과) · 배지 방장/나/경험/접속 종료 · 로비에서는 경험률 ·
      방장에게는 접속 종료자 칸의 "내보내기". 1등 칸은 보라 테두리. 빈 자리는 점선
    · 점수판 카드와 "이 퀴즈를 풀어본 사람" 줄은 없앴다 → 점수는 칸으로, 경험자는 "경험" 배지로 (전원 공개 그대로)
    · 1000px 미만은 한 열로 쌓는다 (모바일 "깨지지만 않게" — 320px 가로 넘침 없음 ui-check 확인)

  ★★★ 말풍선 마스킹
    · 말풍선은 채팅 로그와 **같은 메시지**를 같은 그리기 함수(ChatText)로 그린다. 마스킹은 서버가 받는 사람마다
      가려서 보낸 본문에 이미 들어 있으므로 로그와 말풍선이 어긋날 수 없다.
    · ui-check 실측: 경험자(게스트)가 정답을 치면 방장 화면 그 칸 말풍선 = "가려짐", 로그에도 정답 없음,
      본인 말풍선은 원문 + "가려져서 전송됨", 정답 처리 안 됨.
    · 말풍선은 칸 **안**에 4초 — 가운데로 튀어나오면 문제 지문을 가린다.

  ★ 넓게 쓰기 / 줄바꿈
    · 문제 지문 칸 ≈ 820px (전에는 2열의 왼쪽 ≈ 640px). 글자 1.45 → 1.28rem.
    · 한국어 **어절 단위 줄바꿈**(word-break: keep-all) — "문장 중간 줄바꿈" 이 사라진다. 아주 긴 낱말만 예외.
    · 안내 문장은 오른쪽 위 **ⓘ 안내** 안으로. 입력창 자리표시가 "정답을 입력하세요 — 모든 메시지가 답안입니다" /
      "정답 공개 중 — 지금은 판정되지 않습니다" 처럼 지금 상태를 알려 준다.

  ★ 유지 확인 (ui-check)
    · 한 화면 게이트: 로비·게임(힌트 두 줄)·정답 공개·결과 × 테마 3 = 12개 전부 1.00배
    · 정답자 이름이 지문보다 크다 · 토스트 위치(아래) · 라벨 줄바꿈 규칙(D-022)
