    · ★ 손실률 3% 는 **더 오를 수 있다.** 대조 대상이 387 → 3,000 으로 늘면
      후보 쌍이 급격히 늘어난다. ★ 후보 추리기 비율(0.009%)이 유지된다는 보장이 없다
    · ★★ 그리고 **품질의 하한이 어디서 무너지는지는 아직 모른다.**
      R018 에서 접근성 평균이 3.50 → 3.16 으로 내려갔다. 12건으로 올리면 더 내려갈 것이다.
      ★ 알 가치 1~2 는 두 라운드 모두 0건이었지만, 12건을 요구하면 그 방어선이 시험된다

  ★ 권장하는 확인 방법: **다음 라운드에 소분류 12건으로 60개를 돌려 본다.**
    ★ 근거 — 12건이 실제로 되는지, 접근성·알 가치가 어디까지 내려가는지를 한 번에 잰다.

5. 세션 분리 준비
════════════════════════════════════════

5-1. 입출력 형식을 정리했다

  ```
  [1단계] 소재 세션
     입력   scripts/seeds-banlist.mjs 가 조립한 블록 (카테고리 + 경계 + 금지 목록)
     출력   tmp/<round>/seeds/<slug>.json      { round, subId, seedPrompt, generator, seedResult, seeds[] }
       ↓  node scripts/seeds-ingest.mjs <파일>
     저장   data/pipeline/seeds/<midKey>.json           (소재 이력, 영구 누적)
            data/pipeline/generated/<round>/<slug>.json (question.status = "pending")

  [2단계] 문제 세션
     입력   generated/<round>/<slug>.json 의 pending 항목
     출력   tmp/<round>/questions/<slug>.json  { round, subId, questionPrompt, generator, items[] }
       ↓  node scripts/seeds-attach.mjs <파일>
     저장   같은 generated 파일에 question 을 채운다
  ```

5-2. ★ 두 세션이 같은 파일을 동시에 쓰지 않게 한 방법

  · `tmp/<round>/seeds/` 는 1단계만, `tmp/<round>/questions/` 는 2단계만 쓴다
  · `seeds-ingest.mjs` 는 이미 반영된 배치를 **건너뛴다** (`--force` 로만 덮어쓴다)
  · `seeds-attach.mjs` 는 이미 문제가 붙은 소재에 **예외를 던진다.** 덮어쓰지 않는다
  · ★★ 둘 다 **seedId 로 짝을 맞춘다. 순서에 기대지 않는다** —
    문제 세션이 일부만 돌려주거나 순서를 바꿔 돌려줄 수 있기 때문이다

5-3. 지시서

  → **docs/14-GEN-SESSION.md** (신설). 12-SONNET-SESSION.md 와 같은 형식이다.

5-4. ★★ 이번 라운드에 실제로 나누지는 않았다. 그러나 **순서를 나눴다**

  ★ 지시대로 소분류 20개의 **소재를 전부 만든 뒤** 문제로 넘어갔다.
  ★★ 그러자 **거절이 처음으로 나왔다.**

    energy/4#010  소재 "그린워싱 + 실제보다 친환경으로 보이게 하는 행위"  → ok:false
      사유: 소분류 'energy/4 환경 협약·오염' 은 협약과 오염 현상을 다루는 자리인데,
            그린워싱은 협약도 오염 현상도 아니라 **기업의 광고·마케팅 행태**다.
            억지로 맞추려면 소재의 뜻을 바꿔야 하므로 만들지 않았다.

  ★ 순서를 나눈 것만으로도 효과가 있었다는 뜻이다. 세션을 나누면 더 늘어날 것으로 **추정**한다.
  ★★ 다만 **1건은 표본이 너무 작다.** 실제 거절률은 세션을 나눠 돌려 봐야 안다.

  ★ 판단이 갈렸으나 통과시킨 것도 하나 기록한다 —
    religion/5#010(원불교). 소분류 경계가 "불교는 각자의 소분류로" 인데 원불교는 불교 계열이다.
    ★ 근대 한국 신종교로 독립적으로 다뤄지므로 "고대·소수 종교" 가 맞다고 보았으나 확신은 낮다.
