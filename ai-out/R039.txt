1. 버그 · 스크롤 · 모바일 — 원인과 수정 (D-182 · D-183)
=====================================================================

  ★ 방 밖 화면(로그인 · 회원가입 · 방 목록) 스크롤
    원인: 바깥 틀 .wrap 의 바닥 여백 180px (예전 알림 자리). 1280×720 에서 화면을 넘겼다.
    수정: 한 화면 가운데 정렬(min-height 100dvh) · 여백 16px. ui-check 게이트에 세 화면 추가(PC 5해상도 × 테마 3 + 모바일 폭).

  ★ 긴 문장이 잘림
    원인: 문제 글자 맞춤은 "줄이기 → 안 되면 줄바꿈" 인데, 다시 잴 때 data-wrap 을 '0' 으로 바꿔 두고
          결과가 이전과 같으면 React 가 다시 그리지 않아 '0' 이 그대로 남았다 → 줄바꿈이 꺼진 채 잘림.
    수정: 측정 끝에서 줄바꿈 여부를 직접 다시 쓴다. 글자 줄이기는 권장 하한까지, 그 아래는 줄바꿈(브리핑대로).

  ★★ 모바일 키보드 — 아래 빈 공간이 생기고 내려가도 남음
    원인 ① 모바일 하단 여백 160px(알림이 입력칸을 가리지 않게 둔 자리) — 키보드가 올라오면 브라우저가 이 여백까지 끌어올렸다.
    원인 ② 키보드가 내려간 뒤 스크롤 위치를 되돌리는 코드가 없었다 → 끌어올린 자리 그대로 빈 공간.
    수정: 여백 제거(알림은 화면 위로) · visualViewport 로 "키보드 올라오기 전 위치" 를 기억 → 높이가 돌아오면 그 위치로 복귀 ·
          방 높이 100dvh + 채팅 칸이 남은 높이를 채운다(빈 공간이 생길 자리가 없다).
    ★ 확인 필요: 데스크톱 Chrome 은 키보드를 흉내만 낸다 — 실제 폰 확인은 13-PENDING A35.

  ★ 모바일 채팅이 오른쪽으로 넘침
    원인: 채팅 로그가 flex: 0 0 auto 라 내용(글자) 폭으로 쪼그라들고, 긴 줄이 바깥을 밀었다. → 폭 100%.

  ★ 그 밖 모바일
    단축키 줄·⌨ 버튼 숨김 · 상단 바 아이콘만(🔗 ✏️ ⚙ ⓘ 🚪) · 버튼 작게 · 다시 하기/로비로 넘침 없음 ·
    방장 확인창 "이 문제를 넘길까요?" 한 줄 · 방장·게스트 화면 둘 다 찍어 확인.

  - 바꾸기는 닉네임과 같은 규칙 — 방 밖·대기실만, 게임 중 409. 바꾸면 방 사람들에게 바로 보인다.
  - 쓰이는 곳: 참여자 칸 · 채팅 줄(작게) · 정답자 · 결과 · 프로필 창. 없거나 실패하면 글자 아바타.
  - 검사: 봇 avatar(형식·위장 파일 400·200KB 413·게임 중 409·지우기 404·방 목록 avatarV) · ui-check 실제 파일 선택 → 편집기 → 등록 → 상대 화면 256px.

  ★ 개인 10칸: 😊 → "✏️ 칸 바꾸기" → 칸 고르고 목록에서 누르면 다음 칸으로. 분류 탭 10개 · 이름·검색어 검색(한국어). 계정 설정(prefs.emojiSlots)에 저장.

  ★★ 번호 · DB 틀:
    - 표 emojis (0013) 하나에 표준 1,855개 + 직접 등록. 보내기·채팅 로그·칸·10칸 저장이 전부 id 번호.
    - 표준 목록은 scripts/gen-emoji-migration.mjs 가 emojibase(한국어 이름·검색어) + @twemoji/svg 로 만든다
      (피부색 변형·구성 요소 제외, 그림 없는 51개 제외).
    - 직접 등록 = kind 'custom' + 그림을 DB 에(PNG · GIF · WebP · APNG · SVG, 움직임 가능, 1MB). 등록 화면 없음 — DB-ADMIN 에 SQL.
      ★ 검증: 백업 뒤 실제로 한 개 넣어 → 30초 안에 목록 맨 앞(⭐ 분류)에 나오고 그림이 200 image/png 로 나오는 것 확인 → 지웠다.

    없는 번호·글자 BAD_REQUEST · 단축키 목록에 "Alt+1~0" 한 줄.
  ★ 소리: 채팅 "톡" 과 다른 위로 튀는 "뽀잉". ★ 채팅 소리 음량을 따른다(자체 판단 — 설정 줄을 늘리지 않으려고). 70ms 간격·0.5초 5개로 솎는다.
  - 검사: 봇 emoji(번호로 오감 · 판정 안 됨 · answer_events 0 · 잘못된 번호 거부 · 1초 20개) · ui-check 6-E(칸에 크게 · 로그 · Twemoji · 창 · 검색 · 10칸 저장 · 모바일 보내기).

  D-1. 이모티콘 소리 음량 = 채팅 소리 음량을 따른다 (따로 줄을 만들지 않음).
  D-2. PC 에도 😊 고르기 창을 둔다.
  D-3. 그림 세트 = Twemoji (무료 · SVG · 전부 대응). 다른 세트(Noto 등)로 바꾸려면 파일 경로만 바꾸면 된다.
  D-4. 칸의 이모티콘은 6초 뒤 흐려진다 (마지막 것이 계속 남지 않게). 순위는 0점에 붙이지 않는다.
  D-5. 프로필 사진 상한 200KB · 256px · webp. 사진 바꾸기는 닉네임처럼 대기실에서만.
  D-6. 도배 제한 1초 20개 (채팅과 같은 서버 보호 수준). 넘친 것은 알림 없이 버린다.
  D-7. 기본 10칸 ☠️ 는 "해골과 뼈다귀"(☠️) — 브리핑의 ☠️ 그대로. 💀(해골)을 원했다면 한 줄 바꾸면 된다.

  ★ 봇 difficulty 가 한 번 실패(출제 가능 3 기대 → 2) — 원인: 봇이 "남길 상 문제" 를 id 순 앞 3개로 고르는데, 같은 시나리오의 앞 판에서
    그중 하나가 무작위로 출제돼 이미 경험이 된 경우가 있었다(게임 코드 문제 아님). 남길 문제를 "아직 안 본 것" 에서 고르게 고쳤다 → 통과.
