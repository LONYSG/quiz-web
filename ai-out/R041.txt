6. ★ 소리 — 원인과 수정 (D-198)
=====================================================================

  원인 (코드로 확인)
    ① 오디오를 **첫 pointerdown 한 번**에만 깨우고 리스너를 지웠다.
       터치의 pointerdown 은 HTML 명세상 "사용자 활성화" 이벤트가 아니다(활성화 = keydown · pointerup · touchend · click 등).
       → 휴대폰에서 그 한 번의 깨우기가 실패할 수 있고, 실패하면 다시 시도할 길이 없었다 = "소리가 아예 안 난다".
    ② 오디오가 잠들면(탭 전환 · 화면 꺼짐 · 전화 · iOS interrupted) 다시 깨우는 코드가 없었다 = "불안정".
    ③ 배경음악 실제 음량이 효과음보다 약 20dB 작았다 (배경: 0.35²×0.5, 문제 중 ×0.55, 음 0.16 ≈ 0.01 / 효과음: 0.7²×약 0.2 ≈ 0.1)
       = "효과음은 나는데 배경음은 안 들린다" (노트북 스피커).
  추정 (확인 필요)
    · 카카오톡 안 브라우저는 WebView 라 자동 재생 제한이 느슨해 ① 의 한 번으로도 열렸을 것.
    · 삼성 인터넷은 Chrome 과 같은 활성화 규칙을 따를 것. 삼성 인터넷 자체 설정(소리 차단 등)일 가능성은 낮다(같은 폰에서 카카오는 났다).
  고침
    · 조작마다(pointerdown · pointerup · touchend · click · keydown) 오디오가 잠들어 있으면 깨운다 — 리스너를 지우지 않는다.
    · 깨어나면(statechange) 배경음악을 이어 튼다 · 화면으로 돌아오면(visibilitychange) 한 번 깨워 본다.
    · 조작 안에서 무음 1샘플 재생(WebKit 계열이 출력을 확실히 연다).
    · 탭이 가려져 타이머가 늦으면 밀린 음을 한꺼번에 울리지 않고 건너뛴다.
    · 배경음 비중 0.5 → 1.2, 문제 중 줄임 0.55 → 0.7 (효과음보다 약 12dB 작게 — 배경으로 들리는 정도).
    · 소리 확인 버튼은 만들지 않았다(건우).
  검사: ui-check — 화면을 한 번 누르면 AudioContext running. ★ 삼성 인터넷·카카오톡·iOS 는 자동 검사로 못 잰다 → 13-PENDING A40.

  2. QHD 2560×1440 — 상한 22px 에 걸려 글자가 여전히 작아 보임 → 상한 24px
  3. 강퇴 고르기 팝업 제목 "○○ 님을" 에서 끊겨 어색 → "○○ 님을 어떻게 할까요?"
  4. "⚙ 설정" 이 다른 상단 버튼보다 크게 보임(아이콘 버튼 크기 규칙) → 같은 크기
  5. 사진 편집기를 닫으면 프로필 창이 사라져 이어서 닉네임을 못 바꿈(ui-check 가 찾음 — 팝업 하나 규칙의 부작용) → 편집기를 닫으면 프로필 창으로 돌아감
  6. 결과 화면 360 — 한글 10자 닉네임 줄이 카드 밖으로 나가 점수가 잘림 → 순위 칸(grid)의 최소 폭이 닉네임 전체 폭이었다 → 카드 폭에 묶음 ·
     접속 종료 배지가 붙은 줄의 영어 12자는 두 줄로 꺾여 → 순위 줄의 최소 글자 13 → 11px
  7. ★★ 버그 — 두 사람이 다 떠나도 일시정지가 안 됨(검수 촬영이 못 찍어서 찾음): 떠난 페이지가 뒤로 가기 캐시(bfcache)에 얼어
     소켓이 열린 채 남았다(bfcache 를 끄면 정상 — 실측). 실제로는 뒤로 가기·다른 주소로 갈 때 접속 종료가 늦게 잡힌다
     → 페이지를 떠날 때(pagehide) 소켓을 직접 닫고, 캐시에서 돌아오면(pageshow) 다시 연결 (D-199). 고친 뒤 일시정지 정상.

=====================================================================
8. 새로 발생한 결정 필요 항목 (전부 되돌리기 쉬운 것)
=====================================================================

  D-1. 팝업 하나 — 새 것이 열리면 먼저 것을 닫는다(막지 않는다). 메뉴 창·이모티콘 창까지 같은 규칙.
  D-2. 차단은 방이 살아 있는 동안만(메모리). 서버를 껐다 켜면 방과 함께 사라진다.
  D-3. 강퇴된 사람의 그 판 점수는 결과 화면에 없다(DB 의 게임 참가 행은 남고 최종 점수 칸은 빈다).
  D-4. 모바일 참여자 창 순서 — 게임 중·결과는 점수 순, 로비는 들어온 순. 아이콘에 인원 수.
  D-5. 단축키 목록 — 방장 전용은 방장에게만, 지금 못 쓰는 것은 흐리게.
  D-6. 화면 크기별 글자 공식(1280×720 = 16px 기준, 15~24px). 노트북 안쪽 높이에서는 거의 그대로다 — 더 키우길 원하면 공식의 기준을 바꾸면 된다.
  D-7. 배경음 비중(효과음보다 약 12dB 작게).
