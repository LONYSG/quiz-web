## 0. ★★ 왜 사람이 봐야 하는가 (D-028)

자동 검사는 세 가지를 할 수 없다.

| 할 수 없는 것 | 예 |
|--------------|-----|
| ★ **사람의 판단** | "조잡하다" / "헷갈린다" / "글자가 너무 작다" — 통과·실패로 나눌 수 없다 |
| ★ **실기기 동작** | iOS 소프트 키보드 / 실제 터치 / 모바일 브라우저의 IME |
| ★ **외부 환경** | 터널 URL 이 실제로 바뀌는 상황 / 네트워크가 1~2분 끊기는 상황 |

★ 그 외의 것은 **이미 자동으로 검사한다** (`npm run verify` 의 ui-check 107항목 + 봇 20종).
★ 그래서 아래 목록은 위 세 가지에 해당하는 것만 남긴 것이다.

## 1. 준비 (한 번만 하면 된다)

```bash
npm run db:up        # 이미 떠 있으면 생략
npm run build
npm run dev          # → http://localhost:5173
```

- ★ **창을 두 개 연다.** 창 A = 방장 / 창 B = 게스트
  (다른 브라우저 프로필 또는 시크릿 창. 같은 창의 다른 탭은 같은 계정이 되어 소용없다)
- ★ 계정 두 개로 각각 로그인하고, 창 A 가 방을 만들고 창 B 가 초대 링크로 들어온다
- ★ 게임 설정은 **문제 수 3, 즉시 시작**이 편하다. (한 판이 2분 안에 끝난다)
- ★ 브라우저 창은 **최대화**한다. "스크롤 없이 한 화면" 검사의 기준이 1280×720 이다

> ★ 이상한 점이 보이면 **화면에 무엇이 보였는지 그대로** 알려주면 된다.
> 소켓·DOM 좌표는 내가 볼 수 있지만, "조잡하다 / 헷갈린다" 는 건우만 판단할 수 있다.
