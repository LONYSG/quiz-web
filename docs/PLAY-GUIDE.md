## 1부 — 방장(건우)용

### 켜기 (순서대로)

| # | 명령 | 하는 일 | 건너뛰어도 될 때 |
|---|------|--------|-----------------|
| 0 | Docker Desktop 실행 | DB 컨테이너가 돌 바탕 | — |
| 1 | `git pull` | 최신 코드·문항 파일 받기 | ★ 에러가 나면 먼저 **VPN** 을 끈다/확인한다 |
| 2 | `npm install` | 의존성 설치 | `package.json`·`package-lock.json` 이 안 바뀌었으면 |
| 3 | `npm run db:up` | DB(PostgreSQL, 포트 5434) 컨테이너 켜기 | 이미 떠 있으면 |
| 4 | `npm run db:backup` | 지금 DB 를 `backups/quizweb-날짜.dump` 로 저장 | — (플레이 전 권장) |
| 5 | `npm run db:migrate` | 새 DB 변경(마이그레이션)만 골라 적용 — 이미 적용된 것은 건너뛴다 | 새 `migrations/*.sql` 이 없으면 (돌려도 무해) |
| 6 | `npm run build` | shared·server·client 빌드 (화면 파일 `client/dist` 를 만든다) | 코드가 안 바뀌었으면 |
| 7 | 터미널 A: `npm run dev` | 서버 켜기 (`http://localhost:3000`). 시작할 때 shared·server 를 다시 빌드한다 | — |
| 8 | 터미널 B: `npm run dev:tunnel` | 외부 접속 주소(`https://….trycloudflare.com`)를 받는다 | — |
| 9 | 터미널 B 에 뜬 주소를 단톡방에 공유 | 방을 만든 뒤 방 안 **"초대 링크 복사"** 로 방 링크를 공유해도 된다 | — |

> ★ 처음 한 번만: `.env` 파일(`DATABASE_URL` · `PORT` · `SESSION_SECRET`)과 `cloudflared` 설치가 필요하다 — 11-DEPLOY 1장.
> ★ R024~R034 에 DB 변경(0007 문제 점수 · 0008 일반 힌트 · **0009 분야 묶음 · 0010 계정 설정**)이 추가됐다 — 오래 안 켰다면 5번을 빼먹지 않는다.
> ★ DB 를 직접 들여다볼 때: [DB-ADMIN.md](DB-ADMIN.md) (회원·닉네임·문제 내리기·경험 기록 쿼리)

### 끄기

1. 터미널 B `Ctrl+C` (터널) → 2. 터미널 A `Ctrl+C` (서버) → 3. `npm run db:backup` (경험 기록 보관) → 4. `npm run db:down` (DB — 켜 둬도 된다)

### 방장 조작

| 하는 일 | 방법 |
|--------|------|
| 방 만들기 | 로그인 후 "방 만들기" — 1인당 방 1개 · 최대 10명 |
| 설정 | 문제 수(1~200, 프리셋 50/100/200) · **난이도 하·중·상** · ★ **분야**(한국·역사·사회·과학·기술·문화·예술·스포츠·생활·미디어·콘텐츠 — 복수 선택, "전체" 버튼) — 둘 다 하나 이상. 출제 가능 수가 바로 다시 계산된다. 다시 하기는 설정을 이어받는다 |
| 시작 | 시작 버튼 → ★ **항상 5초 뒤 시작** (R033). 5초 안에 취소 가능 |
| ★ 테마·소리·로그아웃 | 방 안: 상단 바 **⚙** (방 밖: 화면 맨 아래 "🎨 테마 · 🔊 소리") — 테마 3종(파스텔 기본·원색·밤) · 배경음악 2곡 · 배경음악/효과음/★ 채팅 소리 따로 끄기·음량 · 로그아웃. 단축키 `Alt+T` · `Alt+M`. ★ **로그인하면 계정에 저장** |
| 초대 | 상단 바 **🔗 초대** — 누르면 방 링크가 복사된다 (주소는 화면에 안 보인다) |
| 이 문제 넘기기 (강제 스킵) | 문제 아래 "⏭ 방장" (확인 팝업) 또는 `Alt+K` / `F4` → 확인 `Enter` |
| 일시정지 재개 | `Alt+R` / `F8` — ★ 자동 재개 없음. 방장이 눌러야 이어진다 |
| ★ 강퇴 · 차단 (R041) | PC: 그 사람의 **참여자 칸을 누른다** / 휴대폰: 위쪽 **👥** → 그 사람 → **강퇴**(다시 들어올 수 있다) 또는 **차단**(이 방엔 다시 못 온다) → 최종 확인. 접속 중인 사람도 · 게임 중에도 된다 |
| 게임 강제 종료 | `Alt+Q` → 확인 (진행 중 문제 정답은 공개하지 않는다) |
| 결과 화면 다시 하기 / 로비로 | `Alt+A` / `Alt+L` (또는 ←→ 로 버튼을 고르고 Enter) — ★ **다시 하기 = 같은 설정으로 5초 뒤 바로 시작**(그때 접속 중인 사람만, 취소 가능) · 로비로 = 설정을 바꾸러 간다 |
| 단축키 전체 보기 | 입력창 옆 **⌨** 또는 `Alt+G` / `F9` (★ R039 — 버튼마다 붙어 있던 단축키 글자는 지웠다. 목록 창에만) |
| ★ 이모티콘 직접 등록 (캐릭터 그림 등) | 화면은 아직 없다 — DB-ADMIN "이모티콘 직접 등록" 의 SQL |
| 부적절한 프로필 사진 지우기 | DB-ADMIN "프로필 사진" |
| 규칙·설명 | 상단 바 **ⓘ 안내** 에 모아 두었다 (화면에는 진행 알림만) |

### ★ 문제 풀 — 같은 모임이 몇 판까지 새 문제를 받나 (R032 측정)

50문제 기준, 4~6명 모두 처음일 때 → **상만 약 11판 · 중+상 약 38판 · 전체 약 78판** (사람 수와 거의 무관 — 한 판에 전원이 같은 문제를 보기 때문). 이미 한 판들만큼 줄어든다. 측정: `node scripts/measure-pool-exhaust.mjs` (활성 3,949 · 상 577 기준)

### 문제가 생겼을 때

| 상황 | 할 일 |
|------|------|
| 터널이 잠깐 끊김 (Wi-Fi 등) | ★ **1~2분 기다린다.** 터널 창이 살아 있으면 **같은 주소로 돌아온다.** 터널을 껐다 켜면 주소가 바뀌고 다들 다시 로그인해야 한다 |
| 전원이 끊겨 게임이 멈춤 | 게임은 **일시정지**된다. 다들 돌아오면 방장이 **재개**(`Alt+R`). ★ **5분** 동안 아무도 안 돌아오면 방이 사라진다 |
| 마지막 사람이 "나가기" 를 누름 | 방이 즉시 닫힌다 (끊김과 다르다) |
| 서버(터미널 A)를 껐다 켬 | 진행 중 게임은 **사라진다** (경험 기록은 남는다). 방을 새로 만든다 |
| `git pull` 에러 | **VPN** 부터 확인 |
| "문제가 부족합니다" | 난이도·분야를 더 켜거나 문제 수를 줄인다 |
| 친구가 비밀번호를 잊음 | `npm run reset-password -- --login-id 아이디 --generate` (새 비밀번호가 한 번만 출력된다) |
| ★ 테스트(`npm run verify`)가 "서버가 기동 중 종료" · `EACCES` 로 실패 | Windows 가 포트 구간을 예약한 것이다(코드 문제 아님). `netsh interface ipv4 show excludedportrange protocol=tcp` 로 확인 — 테스트 도구는 다른 포트를 알아서 고른다. 게임 서버 3000 이 막히면 `.env` 의 `PORT` 를 예약 밖 값으로 바꾼다 |
| 그 밖 (포트 사용 중 · DB 오류 등) | 11-DEPLOY 6장 표 |

## 2부 — 플레이어용 (단톡방에 그대로 붙여 넣기)

```
🎮 퀴즈 하는 법
1. 링크 접속 → ★ 처음이면 회원가입부터(아이디·비번 4자 이상·닉네임 — 한글 10자 · 영어·숫자 12자까지) → 로그인 → 방장이 준 방 링크로 입장
2. 문제가 나오면 채팅창에 답을 치면 끝! 먼저 맞힌 1명만 1점 (문제당 40초, 정답 공개 8초)
   - 띄어쓰기·대소문자 상관없음 / 틀려도 벌점 없음, 몇 번이고 쳐도 됨
3. 힌트: 🔒 칸이 남은 30초에 일반 힌트(있는 문제만), 15초에 초성으로 열려요
4. 넘기고 싶으면 문제 아래 분홍 "⏭ 넘기기" (또는 Alt+S / F2) — 다시 누르면 취소
   옆의 동그라미가 사람 수만큼 있고 누를 때마다 하나씩 차요. ⚑ 까지 차면 넘어가요 (혼자일 땐 안 됨)
5. 이미 풀어 본 문제는 "이미 풀어본 퀴즈입니다" + 내 칸에 "경험" — 맞혀도 점수 없음, 내가 친 정답은 남들에게 가려져요
6. 닉네임·★프로필 사진은 로비(게임 시작 전)에서 위쪽 ✏️ 로 — 사진은 📷 로 골라 동그라미 안에 끌고 키워 맞춘 뒤 "등록". 점수·기록은 그대로
7. 끊기면 같은 링크로 다시 들어오면 이어짐 (방장이 재개를 눌러 줌)
8. 위쪽 ⚙ 에서 테마·소리 (Alt+T / Alt+M) — 로그인하면 계정에 저장돼요. 소리는 화면을 한 번 누른 뒤부터
9. 채팅은 마우스 휠로 올려 볼 수 있어요. 새 메시지가 오면 ↓ 를 누르면 맨 아래로 (건드리지 않으면 늘 맨 아래)
10. 정답을 맞히면 빵빠레 🎉 — 정답 공개 8초 동안 내가 치는 채팅이 모두에게 크게 떠요 (소감). 놀리든 자랑하든!
    ※ 휴대폰은 정답 공개·결과 때 키보드가 내려가요 (화면을 보라고). 다시 치려면 입력칸을 누르세요
11. 간발의 차로 늦으면 "뒷북" 에 이름과 몇 초 늦었는지가 떠요 (3초 안에 친 정답만)
12. 채팅은 한 번에 300자까지. 채팅 소리가 시끄러우면 ⚙ 의 "채팅 소리" 음량을 줄이세요 (내 귀에만 적용)
13. ★ 이모티콘: Alt+1~0 (👍😂😮😭😡👏🔥🤔🎉☠️) 또는 입력창 왼쪽 😊 — 내 칸에 크게 떠요. 정답 판정과는 무관
    😊 → "✏️ 칸 바꾸기" 로 내 10칸을 바꿀 수 있어요 (검색 가능, 계정에 저장)
14. 휴대폰은 위쪽 👥 를 누르면 참여자 사진·순위·점수가 보여요
※ 단축키 전체: 입력창 옆 ⌨ (Alt+G) · 그 밖 안내는 오른쪽 위 ⓘ
```
