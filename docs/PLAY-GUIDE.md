## 1부 — 방장(건우)용

### 켜기 (순서대로)

| # | 명령 | 하는 일 | 건너뛰어도 될 때 |
|---|------|--------|-----------------|
| 0 | Docker Desktop 실행 | DB 컨테이너가 돌 바탕 | — |
| 1 | `git pull` | 최신 코드·문항 파일 받기 | ★ 에러가 나면 먼저 **VPN** 을 끈다/확인한다 |
| 2 | `npm install` | 의존성 설치 | `package.json`·`package-lock.json` 이 안 바뀌었으면 |
| 3 | `npm run db:up` | DB(PostgreSQL, 포트 5434) 컨테이너 켜기 | 이미 떠 있으면 |
| 4 | `npm run db:backup` | 지금 DB 를 `backups/quizweb-날짜.dump` 로 저장 | — (플레이 전 권장) |
| 5 | `npm run db:migrate` | 새 DB 변경(마이그레이션)만 골라 적용 — 이미 적용된 것은 건너뛴다 | 새 `migrations/*.sql` 이 없으면 (돌려도 무해) |
| 6 | `npm run build` | shared·server·client 빌드 (화면 파일 `client/dist` 를 만든다) | 코드가 안 바뀌었으면 |
| 7 | 터미널 A: `npm run dev` | 서버 켜기 (`http://localhost:3000`). 시작할 때 shared·server 를 다시 빌드한다 | — |
| 8 | 터미널 B: `npm run dev:tunnel` | 외부 접속 주소(`https://….trycloudflare.com`)를 받는다 | — |
| 9 | 터미널 B 에 뜬 주소를 단톡방에 공유 | 방을 만든 뒤 방 안 **"초대 링크 복사"** 로 방 링크를 공유해도 된다 | — |

> ★ 처음 한 번만: `.env` 파일(`DATABASE_URL` · `PORT` · `SESSION_SECRET`)과 `cloudflared` 설치가 필요하다 — 11-DEPLOY 1장.
> ★ R024~R028 에 DB 변경(0007 문제 점수 · 0008 일반 힌트)이 추가됐다 — 오래 안 켰다면 5번을 빼먹지 않는다.

### 끄기

1. 터미널 B `Ctrl+C` (터널) → 2. 터미널 A `Ctrl+C` (서버) → 3. `npm run db:backup` (경험 기록 보관) → 4. `npm run db:down` (DB — 켜 둬도 된다)

### 방장 조작

| 하는 일 | 방법 |
|--------|------|
| 방 만들기 | 로그인 후 "방 만들기" — 1인당 방 1개 · 최대 10명 |
| 설정 | 문제 수(1~200, 프리셋 50/100/200) · 시작 방식(즉시 / 카운트다운 3~60초) · **난이도 하·중·상** (복수 선택, 하나 이상) |
| 시작 | 시작 버튼 (카운트다운 중 취소 가능) |
| 이 문제 넘기기 (강제 스킵) | `Alt+K` / `F4` → 확인 `Enter` |
| 일시정지 재개 | `Alt+R` / `F8` — ★ 자동 재개 없음. 방장이 눌러야 이어진다 |
| 끊긴 사람 내보내기 | 참가자 목록에서 (슬롯이 바로 빈다) |
| 게임 강제 종료 | `Alt+Q` → 확인 (진행 중 문제 정답은 공개하지 않는다) |
| 결과 화면 다시 하기 / 로비로 | `Alt+A` / `Alt+L` — 다시 하기는 설정을 이어받고 시작은 방장이 누른다 |
| 단축키 전체 보기 | `Alt+G` / `F9` |

### ★ 문제 풀 — 같은 모임이 몇 판까지 새 문제를 받나 (R032 측정)

50문제 기준, 4~6명 모두 처음일 때 → **상만 약 11판 · 중+상 약 38판 · 전체 약 78판** (사람 수와 거의 무관 — 한 판에 전원이 같은 문제를 보기 때문). 이미 한 판들만큼 줄어든다. 측정: `node scripts/measure-pool-exhaust.mjs` (활성 3,949 · 상 577 기준)

### 문제가 생겼을 때

| 상황 | 할 일 |
|------|------|
| 터널이 잠깐 끊김 (Wi-Fi 등) | ★ **1~2분 기다린다.** 터널 창이 살아 있으면 **같은 주소로 돌아온다.** 터널을 껐다 켜면 주소가 바뀌고 다들 다시 로그인해야 한다 |
| 전원이 끊겨 게임이 멈춤 | 게임은 **일시정지**된다. 다들 돌아오면 방장이 **재개**(`Alt+R`). ★ **5분** 동안 아무도 안 돌아오면 방이 사라진다 |
| 마지막 사람이 "나가기" 를 누름 | 방이 즉시 닫힌다 (끊김과 다르다) |
| 서버(터미널 A)를 껐다 켬 | 진행 중 게임은 **사라진다** (경험 기록은 남는다). 방을 새로 만든다 |
| `git pull` 에러 | **VPN** 부터 확인 |
| "문제가 부족합니다" | 난이도를 더 켜거나 문제 수를 줄인다 |
| 친구가 비밀번호를 잊음 | `npm run reset-password -- --login-id 아이디 --generate` (새 비밀번호가 한 번만 출력된다) |
| 그 밖 (포트 사용 중 · DB 오류 등) | 11-DEPLOY 6장 표 |

## 2부 — 플레이어용 (단톡방에 그대로 붙여 넣기)

```
🎮 퀴즈 하는 법
1. 링크 접속 → 회원가입(아이디·비번 4자 이상·닉네임) → 로그인 → 방장이 준 방 링크로 입장
2. 문제가 나오면 채팅창에 답을 치면 끝! 먼저 맞힌 1명만 1점
   - 띄어쓰기·대소문자 상관없음 / 틀려도 벌점 없음, 몇 번이고 쳐도 됨
3. 힌트: 남은 20초에 일반 힌트(어려운 문제만), 10초에 초성
4. 넘기고 싶으면 Alt+S (또는 F2) = 스킵 투표
5. 이미 풀어 본 문제는 "이미 풀어본 퀴즈입니다" 표시 — 맞혀도 점수 없음
6. 끊기면 같은 링크로 다시 들어오면 이어짐 (방장이 재개를 눌러 줌)
※ 단축키 전체: Alt+G
```
