# 프로젝트 개요

## 이 프로젝트가 무엇인가

친구들끼리 방을 만들고 초대 링크를 공유해 함께 즐기는 **실시간 웹 상식 퀴즈 게임**이다.

스타크래프트의 상식 퀴즈 맵에서 핵심 재미만 가져와 독립 실행되는 웹 게임으로 만든다.
스타크래프트와는 무관하다.

- 최대 10명이 하나의 방에서 실시간 플레이
- PC 웹 + 모바일 웹. 둘이 같은 방에서 함께 플레이
- 주관식 텍스트 퀴즈
- **별도의 답안 입력창이 없다. 채팅창에 입력하는 모든 메시지가 답안 제출이다**
- 정답을 가장 먼저 제출한 사람이 1점
- 문제 경험 이력을 계정별로 영구 저장. 이미 풀어본 문제는 채팅은 되지만 정답 판정에서 제외
- 게임 중간 참가와 재접속 지원

핵심 재미는 **문제를 보고 채팅창에 미친 듯이 답을 입력하는 것**이다.

전체 게임 규칙은 [01-GAME-RULES.md](01-GAME-RULES.md) 를 본다. 그것이 정본이다.

## 지금 어디까지 왔는가

**Phase 0 완료.** 게임 로직은 아직 없다.

지금 동작하는 것

- 모노레포 스캐폴딩 (server / client / shared / pipeline)
- 로컬 PostgreSQL + 전체 스키마 마이그레이션 + 시드 문제 53개
- 정답 정규화 / 힌트 생성 / 순위 계산 / 스킵 임계값 — **순수 함수 구현 완료, 테스트 97건 통과**
- 서버: 헬스체크, Socket.IO 연결, 시계 오프셋 측정, 부팅 시 정리 절차
- 클라이언트: 서버 시계 동기화 진단 화면
- Cloudflare quick tunnel로 외부 공개 (WebSocket 통과 확인)

기능별 상세 상태는 [05-STATUS.md](05-STATUS.md) 를 본다.

## 개발 단계

| Phase | 내용 | 상태 |
|-------|------|------|
| 0 | 저장소·문서 골격, 스캐폴딩, DB, shared 순수 함수, 최소 서버·클라이언트, 외부 공개 | **완료** |
| 1 | 계정 / 방 (회원가입, 로그인, 닉네임, 방 생성·입장, 10명 제한, 방장) | 미착수 |
| 2 | 로비 (참가자 목록, 경험률, 게임 설정, 초대 링크, 로비 채팅, 게임 시작) | 미착수 |
| 3 | 핵심 게임 루프 (문제 표시, 30초 타이머, 채팅, 정답 판정, 선착순, 점수, 정답 공개, 다음 문제) | 미착수 |
| 4 | 게임 시스템 (힌트, 스킵 투표, 강제 스킵, 강제 종료, 결과, 다시 하기) | 미착수 |
| 5 | 실시간 안정성 (중간 참가, 연결 종료, 재접속, 일시정지, 상태 복구 — **검증·보강 성격**) | 미착수 |
| 6 | 경험 시스템 완성 (판정 제외, 경험률 실값, 개인 알림, 경험자 공개, 마스킹) | 미착수 |
| 7 | UI/UX (PC·모바일 최적화, 단축키, 플레이어 색상, 채팅 UX, 예외 상황 UI) | 미착수 |

### Phase 3에 미리 넣는 것

경험 시스템(Phase 6)은 정답 판정에 직접 개입하므로, Phase 3에서 **자리를 미리 만든다.**

- 판정 자격 게이트 (`canAnswer(player, question)` 훅. Phase 3에서는 항상 true)
- 문제 선정 인터페이스 (Phase 3에서는 무작위)
- 개인별 페이로드 분리 구조
- 경험 기록 DB 쓰기

동시성(race condition)과 타이머 동기화도 Phase 3에서 **처음부터 구조로** 해결한다.
나중에 붙일 수 없는 성질이기 때문이다. Phase 5는 신규 구현이 아니라 검증·보강이다.

### 데이터 트랙 (Track D)

게임 Phase와 **병렬로** 진행하는 별도 트랙이다. 문제 DB를 채운다.
게임 서버와 코드가 분리되어 있고 접점은 DB 스키마뿐이다.

| 단계 | 내용 | 상태 |
|------|------|------|
| D1 | OpenTDB 수집 → Gemini 가공 → 역검증 → 검수 (약 1,100건 예상) | 설계 완료, 미착수 |
| D2 | 위키데이터 템플릿 생성 (CC0, 규모 무한) | 미착수 |
| D3 | ETRI 등 한국어 원본 데이터셋 | 미착수 |
| D4 | 직접 작성 보강 | 상시 |

**개발·테스트는 시드 53문제로 충분하다. 친구들과의 실제 플레이는 1,000건 이상 확보 후에 한다.**

파이프라인 설계는 [03-DATA-MODEL.md](03-DATA-MODEL.md) 와 `pipeline/README.md` 참조.
