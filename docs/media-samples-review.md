> 칸마다 하나만 표시하면 된다 — **☐좋음 ☐너무 쉬움 ☐너무 마니악함** (☐ → ☑ 로 바꾸거나 x 를 넣어 주면 된다)

## 먼저 볼 것

- **층** — `대중`: 그 작품을 본 적 없어도 이름은 아는 수준 (지금 기준으로도 출제) / `팬 세부`: 좋아했던 사람이 "아 그거!" 하는 수준 (지금 기준이면 알 가치 2 라 출제하지 않는다)
- 대중 **33** · 팬 세부 **27** — 채점자(score-v1, 장르를 섞어 따로 매김)는 대중을 전부 알 가치 3, 팬 세부를 2 (16) / 3 (11) 으로 갈랐다
- ★ 정하고 싶은 것: **팬 세부 가운데 어디까지 내도 되는가.** "알 가치 2" 라도 이 모임에서 재밌으면 내는 쪽으로 기준을 바꿀 수 있다
- 점수: 난이도 1~5 (높을수록 어렵다) · 알 가치 1~5 (3 이상 출제) · 접근성 = 중분류 값 (같은 중분류는 같다). 힌트는 난이도 3 이상에만 붙였다
