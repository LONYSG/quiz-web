# 문제 품질 기준서

> ★★ **문제를 만들고, 채점하고, 거르고, 중복을 판정하는 기준은 이 문서 하나만 본다.**
> 현재 유효한 기준만 둔다. **왜 바뀌었는지는 [07-DECISIONS.md](07-DECISIONS.md) 에 있다** (01-GAME-RULES 와 같은 원칙).
> 프롬프트(`pipeline/prompts/*.md`)는 이 문서를 모델에게 전달하는 수단이다. ★ 둘이 어긋나면 **이 문서가 정본**이고 프롬프트를 고친다.
>
> 각 규칙 끝의 `근거` 는 그 규칙이 생긴 실측 사례다. 규칙을 지우거나 고칠 때 먼저 읽는다.
> R023 의 `★ 결정 필요` 는 R024 에 모두 확정되었다 (Q-101 · Q-102).

마지막 갱신: **R024** (채점 세 축을 외부 기준표로 확정 · Q-102 반영)

## 0. 게임이 문제에 요구하는 것 (모든 규칙의 전제)

- 주관식. 보기가 없다. 답을 **채팅으로** 친다. 30초, 먼저 맞힌 1명만 점수.
- 판정은 **정규화 후 정확 일치**: 공백 제거 / 영문 소문자 / 전각→반각 / NFC. ★ 구두점·기호는 지우지 않는다 (`A+B` ≠ `AB`, `4·19` ≠ `4.19`).
- 마지막 10초에 **초성 힌트**. 힌트는 대표 정답으로 만든다.
- 정답 공개와 함께 **해설이 5초** 보인다. ★ 정답은 그때 이미 화면에 있다.
- 한 번 본 문제는 그 사람에게 다시 나와도 점수가 없다. ★ 한 게임 안에서 정답이 겹치는 문제를 내지 않는다 (D-054, ★ 미구현).

## 5. ★★ 채점 세 축 — 외부 기준표 (R024 확정)

> ★★★ 세 축은 **만든 뒤에 매기는 평가**다. 점수를 정해 놓고 문제를 맞추지 않는다 (R011 — 난이도 1~2 가 91% 로 몰렸다).
> ★★★ 기준은 **교과 과정·급수·접하는 곳** 같은 외부 기준 + 채점자의 판단이다. 목표는 정밀함이 아니라 **흔들리지 않는 것**. 한 단계 오차는 괜찮다.
>   ★ 근거 (Q-98 / R023): 정의 문장만으로는 모델 버전마다 다르게 읽었고, 사람이 정하는 앵커도 "모르는 문제의 난이도는 정할 수 없다" (건우) — 앵커 방식은 폐기했다 (D-110).
> ★★★ **점수마다 근거를 한 줄로 남긴다.** 예: "난이도 2 — 중학 과학" / "알 가치 3 — 대중적 애니 제목". 숫자만 남으면 흔들려도 왜 그런지 알 수 없다.
> ★ 이 표는 `pipeline/prompts/score-v1.md` 와 `question-v3.md` 에 **글자 그대로** 들어간다. 셋이 다르면 이 문서가 정본이다 (R023 퇴행 — D-107).

### 5-1. 난이도 (difficulty) — **이 사실을 어디서 접하는가**

| 단계 | 학문 분야 | 교과 밖 분야 (대중문화·스포츠·생활) |
|---|---|---|
| 1 | 초등 교과 | 누구나 일상에서 |
| 2 | 중학 교과 | 방송·뉴스에서 흔히 |
| 3 | 고교 교과 | 관심 있는 사람은 안다 |
| 4 | 대학 교양·수능 심화 | 애호가가 안다 |
| 5 | 전공·자격증 | 마니아도 헷갈린다 |

- ★ 급수 시험이 있는 분야(한국사능력검정·한자 급수 등)는 그 급수를 보조 근거로 쓴다.
- ★ **대상이 아니라 묻는 사실**의 단계다. 세종대왕은 초등이지만 "몇 대 왕인가" 는 더 높을 수 있다.
- ★ 난이도는 거르는 기준이 아니다 (D-044). 1회차는 난이도를 올리지 않는다 (D-093).

### 5-2. 알 가치 (worthKnowing) — 몰랐다가 알게 되면 **"아 그렇구나"** 가 되는가

| 단계 | 기준 |
|---|---|
| 5 | 교과서에 나오는 지식 |
| 4 | 교양·시사 상식 / 한 분야의 기본 어휘 |
| 3 | 대화 소재로 쓸 만한 이야깃거리. ★ **누구나 아는 작품·인물의 이름 맞히기를 포함한다** |
| 2 | 그 분야 팬이 아니면 알 이유가 없는 세부 (중계 별칭·게임 내부 명칭·팬 용어 등) |
| 1 | 기록·수치·조연 — 알아도 남는 것이 없다 |

- ★★ 대중적 작품 제목 맞히기는 **3 (출제)** 이다 — 건우: "제목 맞히기도 꽤 재밌다." (명탐정 코난)
- 만들지 않는 유형: 역사적 의미 없는 연도 / 널리 알려지지 않은 인물 / 작품·제품의 내부 수치·조연 / 기록·순위 세부.
- ★ "어려운 문제를 만들지 말라" 가 아니다. **알 가치 없는 문제**를 만들지 않는 것이다.

### 5-3. 접근성 (accessibility) — **이 분야를** 한국 성인이 아는가

| 단계 | 기준 |
|---|---|
| 5 | 초등·중학 교과 과목 / 전 국민 일상 |
| 4 | 고교 교과 / 대부분이 관심 |
| 3 | 관심층이면 안다 |
| 2 | 애호가 영역 |
| 1 | 전문가·전공자 영역 |

- ★★ **"분야" 는 중분류 수준**(영화·축구·와인 등)으로 본다 (Q-101 확정). 문항의 어려움은 난이도가 맡는다 — 좁게 잡으면 두 축이 섞인다.
- ★★ 그래서 **같은 중분류의 문항은 모두 같은 접근성**이다. 중분류별 값은 `data/pipeline/criteria/mid-accessibility.json` 한 곳에 둔다 (문항마다 매기지 않는다 — D-111).
  ★ 중분류가 없는 옛 문항만 문항별로 매긴다.

| M2 | 소재 = `subject`(대상) · `aspect`(각도) · `knowledgePoint`(맞히게 해 주는 지식) · `probableAnswer`(예상 정답) | seed-v3 |
| M3 | 금지 목록 = **같은 소분류의 전체 이력** (usedSeeds / usedAnswers — 후자는 참고용) | D-078 |
| M4 | ★ **전역 정답 경고**: 예상 정답을 DB·미적재 라운드·같은 초안에 대조한다. **경고지 금지가 아니다** — 같은 지식이면 버리고, 답만 같고 지식이 다르면 살려 이유를 적는다 | D-101 — V001 에서 답이 겹친 쌍의 76.4% 가 실제 중복 |
| M5 | 라운드 안에서 같은 답은 거절 (숫자 정답은 예외). ★ D-054(한 게임 안 정답 중복 금지)가 구현되면 이 규칙을 없애고 D1(지식 기준)으로 통일한다 | D-090 · D-097 / Q-102 #3 확정 (R024) |
| M6 | 상한 12 / 하한 없음. 알 가치 3 미만이 되면 **멈추고** 몇 건에서 왜 멈췄는지 적는다 | D-096 |
| M7 | 1회차는 난이도를 올리지 않는다 | D-093 — 주류 소진 뒤 "어렵게" 는 마이너 대상으로 간다 (myth/3) |
| M8 | 인물은 장르·분야 소분류가 맡는다 (시대 소분류 아님). 소재가 그대로 정답이어도 된다 | D-083 · D-087 |

## 9. 중복 판정

| # | 규칙 | 근거 |
|---|------|------|
| D1 | ★★ **"그 문제를 맞히게 해 주는 지식이 같은가"**. "대상이 같은가" 가 아니다 | Q-91 (D-091) — 동음이의 '미르' |
| D2 | 답이 같아도 지식이 다르면 different (포르투갈어) | Q-96 확정 |

| D4 | 처리는 쌍이 아니라 **연결 요소(그룹)** 단위 | D-063 |

| D7 | 판정은 VERIFY 전담. 생성 세션은 후보만 남긴다 | R021~ |
| D8 | ★ **같은 대상을 단서만 바꿔 맞히게 하는 문제는 same** (사우스 파크를 캐릭터 이름으로 / 그림체로). 단 **알게 되는 사실이 다르면 different** (사르트르 — 노벨상 거절 / 실존주의) | Q-102 #1 확정 (R024). ★ V002 제안 C39(유명 대상의 별개 사실을 same 으로 오판하기 쉽다)와 같은 경계 — 이 규칙이 그 답이다 |
