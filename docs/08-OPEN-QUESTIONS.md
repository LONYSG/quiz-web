### Q-94. ★★ 손실률이 3.5% 로 올랐다 — 3,000건 목표의 소재 수를 얼마로 잡을 것인가

**상태**: ★ R019 실측. 결정 필요

| | R017 | R018 | **R019** |
|---|---|---|---|
| 소재 | 200 | 194 | **720** |
| 거절 | 0 | 1 | **10** |
| 격리 | 1 | 5 | **15** |
| **손실률** | 0.5% | 3.1% | **3.5%** |
| 대조 대상(기존 DB) | 306 | 505 | **693** |

★★ **곡선이 완만해졌다.** 0.5 → 3.1 은 여섯 배였는데 3.1 → 3.5 는 13% 상승이다.
★ 격리 15건은 **전부 라운드 간 대조와 DB 대조에서 나왔다.** 라운드 안 중복은 0이었다(D-090).

**★ 이것이 뜻하는 것** — 손실률은 대조 대상 수가 아니라 **"흔한 지식이 이미 얼마나 쓰였는가"** 를 따라간다.
기린·피타고라스 정리·페니실린·북극성처럼 **누구나 떠올리는 소재**부터 소진되기 때문이다.
★ 그래서 대조 대상이 693 → 3,000 이 되어도 손실률이 비례해 오르지는 않을 것으로 본다.

| 안 | 내용 |
|----|------|
| (가) 손실률 5% 로 잡는다 | 3,000건에 소재 3,160개. ★ 실측 3.5% 보다 보수적이다 |
| (나) 손실률 8% 로 잡는다 | 3,000건에 소재 3,260개. ★ R018 의 "더 오를 수 있다" 경고를 그대로 따른다 |
| (다) 다음 라운드를 한 번 더 재고 정한다 | ★ 곡선이 꺾인 것인지 이번만 그런 것인지 아직 점이 셋뿐이다 |

★ 내 권장: **(가)**. 곡선이 꺾인 것이 실측으로 보였고, 모자라면 다음 라운드에 채우면 된다.
★ 소재를 과하게 만드는 쪽이 오히려 비싸다 — 쓰지 않은 소재도 `usedSeeds` 에 남아 다음 라운드의 금지 목록을 부풀린다.

**영향**: 중간. 남은 237개 소분류의 소재 개수를 정한다.

### Q-93. ★★ 넓은 소분류로 돌렸더니 **난이도가 내려가고 알 가치 1~2 가 처음 나왔다**

**상태**: ★ R019 실측. 결정 필요

| | R017 (넓은 20) | R018 (좁은 20) | **R019 (넓은 60)** |
|---|---|---|---|
| 접근성 평균 | 3.49 | 3.16 | **3.61** |
| 난이도 평균 | 3.04 | 3.24 | **2.64** |
| 알 가치 평균 | 3.93 | 3.76 | **4.15** |
| 알 가치 1~2 | 0건 | 0건 | **12건 (1.7%)** |
| 난이도 4 이상 | 29.0% | 38.8% | **15.8%** |

★★ **난이도가 뚜렷하게 내려갔다.** 3.24 → 2.64 다.
★ 동시에 접근성과 알 가치는 올랐다. → **넓은 소분류는 주류 소재를 먼저 쓰게 만든다.**

★ 알 가치 1~2 로 매긴 12건은 대체로 이런 것들이다:
`쿠키 영상` / `오프닝` / `리스폰` / `롤드컵` / `미리보기` / `컬러링` / `무빙` / `마음의 소리` / `탈취` / `인사`
→ ★ **소재가 소진된 소분류의 끝자락**에서 나왔다. 12건을 채우려고 밑바닥을 긁은 것이다.

| 안 | 내용 |
|----|------|
| (가) 그대로 둔다 | ★ 1.7% 는 낮다. 게임은 쉬운 문제도 필요하다 |
| (나) 알 가치 2 이하를 자동으로 거른다 | ★ 12건을 잃는다. 대신 소분류당 12건을 못 채운다 |
| (다) 소분류당 개수를 소분류마다 다르게 잡는다 | ★★ 고갈 표(`remainingUsable`)가 이미 그 자료다. 8개짜리 소분류와 14개짜리 소분류가 있다 |

★ 내 권장: **(다)**. 모든 소분류에 12을 강요하는 것이 알 가치를 떨어뜨린 원인이다.
★ 다만 이번 라운드에는 **일부러 12로 고정했다** — 고정하지 않으면 고갈 지점을 잴 수 없기 때문이다.

**영향**: 중간. 남은 237개 소분류의 품질을 정한다.

### Q-92. ★ 생성자와 판정자의 일치율이 **더 떨어졌다** — 생성 단계에서 더 할 수 있는 일이 있는가

**상태**: ★ R019 실측. 결정 필요

| | R017 | R018 | **R019** |
|---|---|---|---|
| 후보 쌍 | 5 | 11 | **35** |
| 일치 | 5 | 7 | **16** |
| 일치율 | 100% | 64% | **46%** |

★★ **주의 — R019 의 수치는 앞의 둘과 성격이 조금 다르다.**
R017·R018 은 생성 세션이 쌍마다 판정을 적어 두고 비교했다.
★ R019 는 60개 소분류·720건이라 쌍마다 적지 않았다. 대신 이렇게 읽는다 —
**생성해서 살아남은 문제는 모두 생성 세션이 `different` 로 본 것이다.** 그래서 불일치 19건이 곧 Gemini 의 `same` 이다.

**★★ 불일치 19건의 성격이 중요하다.**

```
라운드 안        1쌍   → 일치 (미르, 양쪽 다 different)
라운드 간·DB    34쌍  → 불일치 19쌍
```

★ **생성 세션은 라운드 간·DB 를 보지 않는다.** 금지 목록(`usedSeeds`/`usedAnswers`)은
**같은 소분류 안**만 담기 때문이다. 기린이 `db:36`(소분류 없음)에 있다는 것을 알 길이 없었다.

| 안 | 내용 |
|----|------|
| (가) 금지 목록을 **소분류 밖까지** 넓힌다 | ★★ 위험하다. R017 에서 "usedAnswers 는 자동 금지가 아니다" 로 못박았다(D-047) |
| (나) 소재 단계에서 정답 후보를 미리 뽑아 DB 와 대조한다 | ★ 소재에는 아직 정답이 없다. `subject` 로 대조하면 근사치는 된다 |
| (다) 지금대로 둔다 | ★ 판정 단계가 잡고 있다. 손실률 3.5% 는 감당할 수 있는 수준이다 |

★ 내 권장: **(다)**. 불일치 19건은 **전부 판정 단계가 제대로 잡아 냈다.**
★ (나)를 하면 호출이 늘고, 생성 전에 대조하면 "쓸 수 있는 소재" 가 줄어 고갈이 앞당겨진다.
★★ 즉 이것은 **결함이 아니라 역할 분담**이다 — 생성 세션은 라운드 안을, 판정 단계는 밖을 맡는다(D-090).

**영향**: 작음. 지금 구조가 이미 감당하고 있다.

### Q-67. ★ 인접 중분류의 경계를 어디까지 좁힐 것인가

**상태**: 결정 필요 (카테고리 목록은 건우가 확정한다)

**R011 실측에서 나온 반례 두 개** — 대분류가 달라도 같은 문제가 나왔다.

```
world-geo > 대륙·바다   "지구상에서 면적이 가장 넓은 대양은?"  → 태평양
earth     > 해양        "세계에서 가장 넓은 바다는?"          → 태평양

theatre   > 연극 고전    "셰익스피어 4대 비극 중 하나는?"       → 햄릿
world-lit > 시·희곡      "'사느냐 죽느냐'가 나오는 희곡은?"     → 햄릿
```

★ 건우의 원칙 "다른 카테고리 + 같은 정답 → 문제없음" 의 반례다.
★ 원인은 중분류 두 개가 **같은 축을 공유**하는 데 있다(D-040의 규칙 위반).
경계 문장을 넣었지만 충분히 좁지 않았다.

**선택지**

| 안 | 내용 |
|----|------|
| (A) 경계 문장을 더 좁힌다 | `earth > 해양` = 해류·수온·심해 등 **현상**만 / 바다의 크기·이름은 `world-geo`. `theatre` = 공연·무대·제작만 / 희곡 텍스트는 `world-lit` |
| (B) 중분류를 합친다 | 겹치는 둘을 하나로. ★ 그러면 중분류가 넓어져 후보군이 커진다 |
| (C) 그대로 두고 중복 판정에 맡긴다 | 실측에서 정답 일치로 12쌍 중 11쌍을 잡았다. 검수에서 걸러진다 |

**권장안**: (A) + (C). 경계를 좁히면 발생을 줄이고, 중복 판정이 남은 것을 잡는다.
★ (B)는 하지 않는 편이 낫다고 판단한다 — 중복 2쌍 때문에 트리를 좁히면
"트리를 넓혀 규모를 늘린다" 는 구조 자체가 약해진다.

**★ R012에서 한 것** — (A)를 적용했다.
```
지구과학·기상 > 해양   "★ 해류·수온·조석·심해 등 현상과 구조만.
                        '가장 넓은 바다는?' 처럼 이름·크기를 묻는 문제는 세계 지리로"
세계 지리 > 대륙·바다   "★ 바다와 대륙의 이름·위치·크기·경계만"
공연·연극 > 연극 고전   ★ 소분류를 삭제하고 "연극 사조·연출" 로 바꿨다.
                        희곡 텍스트는 세계 문학으로 보낸다 — 축을 무대로 통일했다
```
★ 효과는 다음 라운드 대량 생성에서 확인된다. 지금은 경계만 좁혔다.

**영향**: 중간. 규모가 커질수록 커진다.

### Q-66. ★ 역검증 불일치를 "표기 변형 후보" 로 볼 것인가

**상태**: 결정 필요 (판정 규칙 변경이므로 실측 근거가 더 필요하다)

**R011 실측 — 역검증 불일치 탈락 2건**

```
"캐나다 국기 중앙의 나뭇잎 종류는?" → 단풍잎
   역검증 답 "단풍나무"    (우리 집합에 "단풍나무 잎" 은 있으나 "단풍나무" 는 없다)

"정팔각형 모양의 규제표지는?"      → 일시정지
   역검증 답 "정지"        ★ "정지" 는 사람이 실제로 칠 표기다. 빠져 있었다
```

★ 두 번째는 **오탈락에 가깝다.** 역검증이 잡은 것은 애매함이 아니라 **빠진 표기 변형**이다.
그런데 현재 규칙은 불일치 + 확신 높음이면 탈락시킨다.

★ 첫 번째는 다르다. "단풍나무" 는 잎이 아니라 나무다. 그것을 정답에 넣으면 안 된다.
→ **두 경우를 자동으로 구분할 방법이 지금은 없다.**

**선택지**

| 안 | 내용 |
|----|------|
| (A) 현행 유지 | 불일치는 탈락. ★ 안전하지만 멀쩡한 문제를 버린다 |
| (B) 불일치도 검수 대기로 | 사람이 "빠진 표기" 인지 "다른 대상" 인지 판단한다. ★ 검수 부담이 늘어난다 |
| (C) 부분 문자열이면 검수 대기 | "정지" ⊂ "일시정지" 처럼 포함 관계일 때만 살린다. ★ "단풍나무" ⊄ "단풍잎" 이라 이 표본에서는 정확히 갈린다 |

**★ 이번 라운드에 고치지 않았다.** 근거: R010에서 역검증 판정을 고쳤다가
정상 문제 6건을 전부 오탈락시킨 경험이 있다. **표본 2건으로 판정 규칙을 바꾸지 않는다.**
탈락한 것은 `processed/` 에 남아 있으므로 규칙을 고치면 `rejudge` 로 회복할 수 있다(D-035).

**권장안**: 표본을 더 모은 뒤 (C). 지금은 (A) 유지.

**영향**: 낮음~중간. 생존율 1% 안쪽이다.

### Q-65. ★ 카테고리 계층 마이그레이션(0003)의 적용 시점

### Q-63. ★ Gemini 유료 전환 여부 — **전제가 무너졌다. 다시 판단해야 한다**
