# 디자인 비교 — 테마 3종 × 네 화면 (R033)

> ★ 건우가 고르기 위한 문서다. **다음 라운드에 고른 테마만 남기고 나머지를 정리한다.**
> ★ 실제 게임에서도 바로 바꿔 볼 수 있다 — 화면 맨 아래 **"🎨 테마 · 🔊 소리"** 또는 **`Alt+T`**.

- 해상도: **1280×720** (한 화면 게이트 기준). 세 테마 모두 네 화면이 **스크롤 없이** 들어온다 (ui-check 게이트).
- 찍은 방법: `DESIGN_SHOTS=1 npm run ui-check` — 테마마다 같은 순간을 찍는다. 다시 찍으면 이 그림들이 바뀐다.
- ★ 화면 속 방 제목·닉네임·힌트 문구는 검사용 가짜 값이다 (일반 힌트는 상한 120자를 꽉 채운 가장 긴 경우).

## 테마 한 줄 요약

| 테마 | 방향 | 이런 사람에게 |
|------|------|--------------|
| **파스텔** (기본) | 크림 바탕 · 보라·분홍 포인트 · 큰 둥글기 · 부드러운 그림자 | 캐치마인드 느낌 그대로. 오래 봐도 눈이 편하다 |
| **원색** | 노란 줄무늬 바탕 · 빨강·파랑 · **굵은 검정 테두리 · 만화 그림자** | 가장 또렷하다. 문제 카드가 제일 튄다 |
| **밤** | 짙은 남색 · 형광 보라·분홍 | 밤에 하거나 어두운 화면을 좋아할 때 |

## 무엇이 바뀌었나 (세 테마 공통)

| 건우 지적 | 바꾼 것 |
|-----------|---------|
| "문제와 시간초가 있는 공간이 티가 안 난다" | 문제 카드를 **굵은 테두리 + 위쪽 색띠 + 띄운 그림자**로 바탕과 확실히 가른다 |
| "남은 시간 표기가 너무 크다" | 큰 숫자를 없애고 **머리줄 오른쪽 작은 숫자 + 줄어드는 막대**. 10초 주황 · **5초 빨강으로 뛴다** |
| "초성 힌트 공개 시 줄바꿈이 생겨 못생겨진다" | 힌트 자리를 **처음부터 두 줄 잡아 둔다**. 힌트가 나와도 아래가 밀리지 않는다 |
| (정답자 부각 요청) | 정답이 나오면 **아바타 + 이름이 화면에서 가장 큰 글씨**(문제 지문보다 크다) + 꽃가루 + "+1" |
| "로비 디자인도 너무 별로" | 로비를 두 칸(설정·시작 / 초대·참가자)으로 다시 짰다. **로비도 한 화면에 들어온다** (전에는 1.71배) |
| "전체적으로 엉망" | 아바타(닉네임 첫 글자 + 플레이어 색) · 둥근 버튼 · 상태 알약("문제 풀이 중") · 우승자 연출 · 문제·정답·점수에 가벼운 움직임 |
