당신은 이미 만들어진 퀴즈 문제(난이도 4~5)에 **일반 힌트 한 문장**을 붙입니다.

■ 규칙 — 기준서 4-1 (그대로 옮긴 것)

■ 쓰는 순서
  1. 질문·정답·해설을 읽는다.
  2. 이 답에 닿는 **길**을 하나 고른다 — 이름의 유래 / 같은 무리 / 연결된 사람·곳·사건 / 쓰임.
  3. 그 길을 **질문과 엮어야** 답이 나오게 쓴다. 질문이 이미 준 단서와 맞물려 "아!" 하게.
  4. ★ 스스로 시험한다 — **질문을 가리고 힌트만 읽는다.** 답이 곧바로 떠오르면 떠먹여 주기다. 다시 쓴다.
  5. ★ 힌트 속 낱말이 정답의 **다른 이름**(우리말·원어·번역어·옛 이름·본명·약칭)인지 본다. 그렇다면 뺀다.
  6. 해설과 같은 사실이 아닌지 본다 — 해설이 할 말을 남긴다.

■ 예
  도와주기 (좋다)
    질문 "커피 재배지가 적도 주변에 띠처럼 몰려 있는 구역은?"
    힌트 "'Corn Belt'처럼 작물 이름 뒤에 '띠'를 뜻하는 영어를 붙인 말이다."  → 질문의 커피 + 힌트 → 커피 벨트
  떠먹여 주기 (안 된다)
    "포스트잇을 만든 회사다." (3M) / "하늘과 바다를 칠할 때 흔히 쓰는 색이다." (파랑) / "쿠란이 이 언어로 쓰였다." (아랍어)
  다른 이름 (안 된다)
    "우리말로는 '외팔보'라고 한다." (정답 캔틸레버 — 외팔보를 치면 오답) / "산스크리트어로는 '무드라'" (정답 수인)
  정답 글자 (안 된다)
    "차나무의 옛 속명 'Thea'에서 왔다." (테아닌) / "'해돋이'에 빗댄 이름" (지구돋이 — '돋이')

■ 덧붙임
  · 숫자 정답은 초성이 가려진다 — 숫자의 범위나 성격(무엇의 수)을 주되, 자릿수를 거의 다 알려 주지 않는다.
  · 두 글자 정답은 초성과 합치면 거의 답이다 — 힌트만 읽고 답이 나오지 않게 한다.
