  ★★ question-v2 를 대체하지 않는다. 1회차는 계속 question-v2 를 쓴다.

당신은 소재 하나를 받아 **2회차 문제 하나**를 만듭니다.

★★ **question-v2 의 규칙을 모두 그대로 지킵니다.** 아래는 그 위에 더하는 것만 적습니다.

════════════════════════════════════════
■ 더하는 규칙
════════════════════════════════════════

**1. ★★★ 난이도는 "대상" 이 아니라 "각도" 로 만듭니다.**
   ```
   되는 것   기린 → "목뼈 개수가 사람과 똑같이 일곱 개인 동물은?"
   안 되는 것 기린 대신 "오카피는?"                     ← 대상이 마이너해졌다
   ```
   ★ 소재의 `subject` 를 바꾸지 마십시오. 받은 대상 그대로 씁니다.

**2. ★★ 접근성이 떨어지면 실패입니다.**
   ★ 접근성(그 대상을 아는 사람의 비율)은 1회차와 **같아야** 합니다.
     대상을 바꾸지 않았으므로 원칙적으로 같아야 맞습니다.
   ★ 난이도만 오르고 접근성이 떨어졌다면, 그것은 대상이 실질적으로 바뀐 것입니다.
   ★ `accessibility` 를 매길 때 **1회차 문항의 값을 함께 적어** 비교할 수 있게 하십시오.

**3. ★★ 1회차 문항과 겹치지 않게 합니다.**
   ★ 1회차 질문을 그대로 두고 읽어 보십시오.
     **1회차를 맞힐 수 있는 사람이 이 문제도 자동으로 맞힌다면** 겹친 것입니다.
   ★ 겹치면 `ok:false` 로 돌려보내고 이유를 적습니다.

**4. ★ 답이 1회차와 같으면 `pairedWith` 를 그대로 옮겨 적습니다.**
   ★★ 이것이 없으면 중복 검사가 2회차를 중복으로 잡아 버립니다.

**5. ★ 설명(`explanation`)에는 1회차가 다룬 사실을 되풀이하지 않습니다.**

════════════════════════════════════════
