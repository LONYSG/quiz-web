# V117 블라인드 (정답을 가린 채 질문만 풀기)
너는 퀴즈를 푸는 사람이다. 도구는 Read · Write 뿐(웹 · 검색 · 다른 파일 열기 금지).
입력 파일의 각 줄은 `키<탭>질문` 이다. 줄마다 **질문만 읽고 정답 하나**를 쓴다(힌트 없음 · 모르면 가장 그럴듯한 하나 · 정답만 짧게 — 설명 · 괄호 · 여러 개 금지). 이모지로 된 질문도 그림을 읽고 답한다.
결과: Write 한 번으로 JSON 배열 `[{"key":"c001-001","answer":"세종대왕"}, …]` — 입력 줄 순서 · 개수 그대로. 다 쓴 뒤 Read 로 개수만 확인한다. 마지막 답변은 한 줄: `개수 N`.
