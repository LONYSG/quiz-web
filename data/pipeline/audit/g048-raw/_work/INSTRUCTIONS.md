# G048 캐치마인드 제시어 판정 — 조각 지시서 (모든 조각 같음)

캐치마인드 = 한 사람이 제시어를 **60~90초 안에 선으로 그리고**, 나머지가 채팅으로 맞히는 한국 파티 게임(2026년 · 20~50대 친구 모임).
너는 원조 캐치마인드 정답 목록(나무위키 씨앗)의 단어를 하나씩 보고 **우리 제시어 풀에 넣을지** 판정한다.

## 입력
- `data/pipeline/audit/g048-raw/_work/shard-<n>.json` = 단어 문자열 배열(약 1,860 개 · 초성 순). 너의 n 은 프롬프트에 있다.
- 200 개씩 끊어서 읽고 판정하면 된다(node -e 로 slice).

## 기준
- ⓐ **그릴 수 있는가**: 60~90초 선 그림으로 알아볼 수 있는 구체 명사 · 동작 · 상황 · 장면 · 특징 있는 인물/캐릭터(안경 · 수염 · 복장 같은 시각 특징 — 예 찰리 채플린 · 아인슈타인 · 피카츄 · 둘리).
  - **빼기**: 추상어(감동 · 급여 · 효율 · 가격 · 공간 · 과거) · 소리 · 냄새 · 감정만 있는 것 · 상품명 · 브랜드(로고 = 글자 그리기) · 지명(도시 · 나라 · 강 — 단 에펠탑 · 피라미드 같은 **건물·명소는 OK**) · 영화 · 노래 · 책 제목(그 안의 캐릭터는 OK) · 정치인 · 논란 인물 · 너무 전문적인 말(각본 · 견본 · 경륜) · 비속어 · 성적인 말 · 너무 낯선 옛말.
- ⓑ **보편성**: 한국 20~50대 대부분이 아는 단어. 한철 유행 X.
- ⓒ `diff`: 1 쉬움(사과 · 고양이 · 우산 — 누구나 3초) · 2 보통(기린 · 피아노 · 낚시) · 3 어려움(상황 · 동작 · 추상에 가까운 것 — 월급날 · 감기 · 그늘). keep 전체에서 ≈ 4:4:2.
- 세트(`set`) 하나 고르기:
  `object`(사물 · 도구 · 가전 · 옷 · 장난감) · `animal`(동물 · 곤충 · 새 · 물고기) · `food`(음식 · 과일 · 채소 · 음료 · 간식) · `place`(장소 · 건물 · 명소) · `action`(동작 · 상황 · 행사 · 운동 종목 — 낚시 · 재채기 · 결혼식 · 축구) · `nature`(자연 · 날씨 · 천체 · 식물 · 꽃) · `character`(캐릭터 · 유명 인물 · 신화/동화 인물) · `vehicle`(탈것) · `job`(직업 · 역할 — 경찰 · 광대 · 군인)
- `sub` = 짧은 소분류(예 "주방 도구" · "바다 동물" · "날씨").
- `variants` = 채팅으로 실제로 칠 다른 표기 0~2(띄어쓰기 · 대소문자는 자동 — 넣지 말 것). 예: 계란 → ["달걀"] · 핸드폰 → ["휴대폰", "스마트폰"]. 없으면 [].

## 출력
`data/pipeline/audit/g048-raw/_work/judge-<n>.json` = 객체 하나:
```json
{ "keep": [ { "word": "가방", "set": "object", "sub": "가방·잡화", "diff": 1, "variants": [] } ],
  "drop": { "가격": "추상", "각본": "전문", "강변": "지명·장소추상" } }
```
- drop 사유는 짧은 코드 하나: `추상` · `소리냄새` · `상표` · `지명` · `제목` · `인물논란` · `전문` · `낯섦` · `비속` · `중복`(같은 것의 다른 표기 — keep 쪽 variants 로) · `그리기어려움`.
- **입력의 모든 단어가 keep 또는 drop 에 정확히 한 번** 들어가야 한다(누락 0 — 끝에 node 로 개수 대조).
- 예상 keep 비율은 20~30% 정도(원조 목록에는 추상어가 많다). 억지로 채우지 말 것.
- 다른 파일은 만들거나 고치지 않는다 · git 금지 · 웹 금지.
- 마지막 답: "입력 n · keep n(세트별 수) · drop n · diff 1/2/3" 한 줄.
