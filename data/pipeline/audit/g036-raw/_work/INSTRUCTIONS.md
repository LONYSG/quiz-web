# G036 주제 세트 수집 — 조각 지시서 (docs/18 §9 가 정본)

너는 한국어 퀴즈 게임의 미니게임 데이터 수집 조각이다. 맡은 주제마다 `data/minigame/topics/<slug>.json` 파일 하나를 만든다. **DB 는 건드리지 않는다. 다른 파일은 고치지 않는다.**

## 출처
- 주제마다 **한 페이지**(공식 목록 · ko.wikipedia · 나무위키 표 · Wikidata SPARQL · 공식 API — Data Dragon · PokeAPI). 1~3 페이지 안에서 하나로 닫히는 출처를 고른다(둘째 출처 대조는 나중 라운드 몫).
- WebFetch 를 쓴다. curl/fetch 를 쓰면 User-Agent 는 `quiz-web-g036/1.0`. 개인 정보(이메일 · 이름)는 어떤 요청에도 넣지 않는다. 429 면 4초 쉬고 한 번 더.
- 받은 원자료(목록 표 · API 응답 요지)는 `data/pipeline/audit/g036-raw/<slug>.src.txt`(또는 .json)에 남긴다(크면 이름 목록만).

## 파일 꼴 (그대로)
```json
{ "topic": "<slug>", "nameKo": "나라 이름", "kind": "closed", "version": 1, "asOf": "2026-11-08", "createdRound": "G036",
  "status": "candidate", "source": [{ "url": "...", "note": "무엇을 읽었는지 한 줄", "fetchedAt": "2026-11-08" }],
  "liar": true, "draw": false, "timeSec": 30, "tags": ["지리"], "count": 193,
  "items": [ { "id": "<slug>-001", "name": "가나", "variants": [], "tags": ["아프리카"], "draw": false, "liar": true, "qid": null } ],
  "verify": null }
```
- 항목 칸은 `id · name · variants · tags · draw · liar · qid` 필수, `year`(정수 · 있을 때만) · `note`(짧게 · 있을 때만). 다른 칸 금지.
- `id` = `<slug>-001` 부터 빈틈없이 이어서(3자리). 순서는 출처 순서(또는 가나다 · 연도 — 파일 note 에 적지 않아도 됨).
- `qid` 는 언제나 `null`(GEN 이 나중에 기계로 채운다).
- `count` = items 수. `timeSec` 은 항목 150 넘으면 60, 아니면 30.
- 머리 `liar`/`draw` = 이 세트를 라이어 · 캐치마인드 제시어로 쓸 만한가. 항목 `liar` = 모두가 알고 한마디씩 설명할 거리가 있나 · 항목 `draw` = 그림으로 그려 맞힐 수 있는 구체 사물인가(사람 이름 · 추상어는 false).

## 수 · 항목
- closed 는 **공식 목록 전부**(빼지 않는다). 목록 기준(어느 시점 · 무엇을 넣고 뺐는지)은 source.note 에 한 줄.
- `name` = 한국에서 쓰는 표준 표기(정본 하나).
- `variants` = **한국에서 실제로 치는** 다른 표기만: 띄어쓰기·외래어 표기 흔한 변형(스테인레스/스테인리스 꼴) · 약칭(맨유) · 옛 이름(해태 타이거즈) · 정식/짧은 이름. **안 받는 것**: 번역어 · 일반어 · 설명 꼴 · 다른 대상.
- **영문(로마자) 변형은 사람·작품·캐릭터 이름에만**(롤 챔피언 Ahri · 포켓몬 Pikachu · 영화 원제) + 화학 원소 기호·영어 이름(브리프 지정). 나라 · 도시 · 구단 · 산 · 강 · 역 같은 것은 영문 변형을 넣지 않는다.
- 변형에 쓸 수 있는 기호: 공백 · 마침표 · 가운뎃점 · 작은따옴표 · 하이픈 · & · : · ! · ? 뿐. 괄호 · 슬래시 등은 쓰지 않는다(필요하면 name 에만 괄호).
- **유일성(세트 안)**: 두 항목의 name 이 정규화로 같으면 안 되고, 한 항목의 변형이 다른 항목의 name·변형과 같으면 안 된다. 이름이 겹치는 것(부산 중구 · 대구 중구 / 강원 고성군 · 경남 고성군 / 콩고 둘)은 **구별되는 꼴을 name 으로**(부산 중구 · 고성군(강원) 꼴) 하고 겹치는 짧은 꼴(중구 · 콩고)은 **변형으로도 넣지 않는다**. 판정은 괄호 · 가운뎃점 · 공백 · 대소문자를 지운 뒤 비교하므로 "고성군(강원)" 의 name 정규화는 "고성군" 이 된다 → 이런 경우 괄호 말고 "강원 고성군" 꼴을 쓴다.
- 다 쓰면 `node scripts/topics-check.mjs data/minigame/topics/<slug>.json` 를 돌려 **막힘 0** 이 될 때까지 고친다(경고는 괜찮다). 뺀 항목 · 고민한 기준은 마지막 보고에.
