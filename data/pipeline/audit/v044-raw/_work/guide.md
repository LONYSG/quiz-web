# V044 지시서 — 라이어 제시어 세트 전수 판정 (판정만 · 세트 파일 수정 금지)
게임: 라이어. 기본형 = 라이어는 주제만 안다. **바보형** = 라이어가 정답이 아닌 비슷한 단어 `fool`(2~3 중 무작위 1)을 "정답인 것처럼" 받는다(라이어인 줄 모름). 걱정: "호날두를 받았는데 정답이 메시일 수 있겠다 싶으면 라이어가 바로 눈치챈다".
입력 줄: `번호 | name [변형;…] | sub | era | diff | fool: a / b / c`. 파일 한 세트 = 50~60 항목, 전부 한 줄씩 직접 본다(스크립트로 판정 자동 생성 금지).

## 항목마다
1. **보편성·era**: 20~50대 한국인 대부분이 아는가(아니면 remove). era classic 인데 2015 이후 것 / modern 인데 한철 유행 → era fix 또는 remove. 논란 인물(정치·사건·범죄·폭로) → remove.
2. **게임성**: 한마디로 돌려 설명할 거리가 있나. 너무 넓은 상위어(물건·음식)·너무 좁은 것(모델명·특정 회차)·1글자 → remove/fix. `diff` 1(아이도)/2(보통)/3(어려움·고인물) 가 맞나(전부 본다, 틀리면 diff fix).
3. ★ **fool 하나하나** — 판정 ok / tooClose / tooFar / bad + 대안 1(제안):
   ⓐ name 과 같은 소분류(sub)인가 ⓑ **1:1 짝·라이벌·같은 작품 인물이 아닌가**(호날두↔메시 · 코카콜라↔펩시 · 해리↔론 · 짱구↔철수)
   ⓒ **"이 fool 을 받고 남들의 설명을 들으면 정답을 2개 안으로 좁힐 수 있나"** → 좁혀지면 tooClose(예: 거북이↔자라, 사실상 동의/아종)
   ⓓ 너무 멀어 첫 한마디에 들키면 tooFar(예: 돼지 fool 하마 — 가축 vs 야생)
   ⓔ bad = 일반인이 모르는 단어(예: 고양이 fool 삵) · 정답과 정규화가 같은 꼴 · name 의 변형과 같음. fool 이 같은 세트 다른 항목 name 이어도 허용.
   애매하면 **엄하게(tooClose)**. fool 이 2개 미만으로 줄면 대안을 같은 sub 에서 제안.
4. **중복·변형**: 세트 안 같은 대상 두 번(음차 다름), variants 가 15 §2(한국에서 실제로 치는 표기, 오타·넓은 말 X)에 맞는지, 라이어 키워드 맞히기에서 받아야 할 흔한 표기 빠짐.
5. **sub** 가 틀린 것(예: 거미 sub "곤충" — 거미는 곤충이 아님)도 fix.

## 연예인·음악 세트(실존 인물): 논란(정치·성범죄·폭력·병역·사생활 폭로·계약 분쟁 등 보도된 큰 건) 있는 인물은 remove(사유 한 줄, 확신 낮으면 unsure 로 구분해 표시). 웹은 전체 ≤ 3회, 인지도·논란 의심 항목에만.
