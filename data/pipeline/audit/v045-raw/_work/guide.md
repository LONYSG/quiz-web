# V045 지시서 — 캐치마인드 제시어(draw-*) 전수 판정 (판정만 · 세트 파일 수정 금지)
게임: 캐치마인드. 한 사람이 제시어를 **선 그림으로 60~90초** 안에 그리고 나머지가 **채팅으로 친 글**이 name/variants 와 (정규화 + 괄호·가운뎃점·끝맺음 무시) 같으면 정답. 정규화는 띄어쓰기·대소문자를 이미 무시(아이언맨 2 = 아이언맨2). 조사·하이픈은 안 받음.
입력 줄: `번호 | name [변형;…] | sub | d<diff>` (속담은 | note 가 더 붙음). 모든 줄을 직접 본다(판정 스크립트 생성 금지).

## 항목마다
1. **그릴 수 있나**: 추상어·소리·냄새·상표·지명(건물 제외)·한자어 개념, 선 그림으로 알아볼 수 없는 것(미생물·비슷비슷한 작은 물고기) → remove. 
2. **그림 중복**: 같은 세트 안에서 그림이 사실상 같은 쌍(거북이↔자라, 붕어↔잉어↔송사리, 가위 종류, 같은 모양 다른 이름)은 맞힌 쪽이 억울하니 한쪽 remove(대표를 남김). 상하위(시계↔손목시계)도 한쪽.
3. **보편성**: 세대 불문 20~50대 한국인이 아는가. 한철 유행·특정 게임/팬덤 전용 → remove.
4. **diff**: 1 = 누구나 3초 안에 알아봄 · 2 = 보통 · 3 = 상황·속담·고인물. 틀리면 diff fix(제안 값).
5. **변형**(채팅 정답): 정규화가 이미 받는 꼴은 제외. 빠진 흔한 표기(띄어쓰기로 안 되는 약칭·'~이' 꼴·음차 두 꼴·속담 앞부분 전체/줄임)는 variants 추가 제안(항목당 ≤ 3, 오타·넓은 말 X). 다른 항목 name/변형과 겹치면 안 됨.
6. **인물·캐릭터**: 그림으로 알아볼 시각 특징(안경·수염·복장)이 있는가. 논란 인물(정치·사건·범죄)은 remove. 종교 인물은 unsure.
7. sub 가 틀린 것(예: 달팽이 sub '곤충')은 sub fix.

## 출력: data/pipeline/audit/v045-raw/<청크이름>.json — 기준 맞춤 예: data/pipeline/audit/v045-raw/C0-animal.json 와 같은 꼴
{"chunk":"..","sets":{"<slug>":{"items":N,"issues":[{"id":"<slug>-NNN","name":"..","probs":[{"t":"remove|diff|variant|sub|dup|person","d":"사유","fix":"제안(전체 값)"}]}],"unsure":["id: 이유"],"okCount":N}}}
- 문제 있는 항목만 issues 에. 한 청크가 한 세트의 일부이면 sets[slug].items 는 그 청크의 항목 수. 애매하면 unsure 로(넣지 않는다). 웹 전체 ≤ 2회.
