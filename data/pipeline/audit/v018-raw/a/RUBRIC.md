# V018 — V018 ① 활성 난이도 1 전수 품질 점검 (기준은 V014 와 같다 · 난이도는 다시 매기지 않는다)

이미 활성인 문항을 **판정만** 한다(DB 쓰기·파일 수정(출력 파일 외)·서버·빌드 금지). 난이도 값은 판정 근거로 쓰지 않는다. 기준: `docs/15-QUALITY-STANDARD.md` §3-1(읽기 좋음·묻는 문장 끝) · §3-2(정답 유일성·한정어·단정어·바뀔 수 있는 사실·문서 대조) · §4-1 H0~H12(hint-v5: H2 정답 글자·조각 · H3 질문 되풀이 · H4 해설과 같은 사실 · H5 사실 문서로 · H9 "질문을 모르는 보통 한국 성인이 힌트만 보고 정답을 바로 말하는가" · H12 같은 정답 활성 문항의 질문·해설과 같은 사실) · §2 B2(이름 요구 질문의 일반어 변형) — 먼저 §3-1·§3-2·§4-1 을 읽는다.

## 판정 순서 (문항마다)
1. **정답 유일성**(3-2): "질문의 모든 조건을 만족하는 다른 답이 실제로 있는가" — 같은 작가의 다른 작품 · 같은 인물의 다른 업적 · 같은 무리의 다른 이름 · 변형 누락(한국에서 실제로 쓰는 표기). 있으면 fix(한정어를 묻는 문장 안에 더함 vs 변형 추가 — 어느 쪽이 나은지 이유 한 줄). 실제 예는 `otherAnswers` 에.
2. **질문 사실**(3-2): 질문의 숫자·이름·연도·동사를 문서(WebFetch)로 열어 글자 대조 — 틀리면 fix(fact-error), 단정이 약하면(학설·시간 의존) fix(assertive: 한정어 제안). 해설의 사실도 같이(E1~E6: 정답만 알려 주는 문장 · 틀린 사실 · 단정).
3. **읽기 좋음**(3-1): 질문이 한눈에 들어오는가 · 한정어가 묻는 문장 안에 있는가 · 문장이 과하게 길거나 끊기는가. 가볍게 보되 심하면 fix(readable).
4. **힌트**: H2(정답 글자·한 글자 조각 포함 — "이 탑" ↔ 에펠탑 꼴) → H3 → H4 → H5(문서로) → H9 판정 문장 → H12(같은 정답 활성 문항 질문·해설과 같은 사실) 순. 세기만으로 fix 하지 않는다. 같은 정답 활성 힌트와 **같은 문장**이면 fix.
5. 문서를 못 열었거나 문서에 그 문장이 없으면 `unverified`(basis 는 web 일 때만 true/false) — 지식(기억)으로 true 를 달지 않는다. 틀린 증거가 없으면 verdict ok(reason 에 unverified).
6. 같은 항목에 fix 이유가 여럿이면 categories 에 모두. 제안(proposal)은 바꿀 칸 전체 문구(question · explanation · hint · variants) — 새 사실은 url 을 열어 확인.

## 결과 형식 (`<조각>.out.json` — 입력 순서 그대로 JSON 배열 · key = id 문자열)
```json
{"id":"387","verdict":"ok|fix","categories":[],"reason":"한 줄","uniqueness":{"unique":true,"otherAnswers":[]},"facts":[{"claim":"…","where":"q|e|h","result":"true|false|unverified","basis":"web|none","source":"URL|null"}],"readable":true,"hint":{"ok":true,"issue":null},"proposal":{"question":null,"explanation":null,"hint":null,"variants":null},"urls":["WebFetch 로 연 url"],"note":null}
```
categories: `not-unique` `variants` `fact-error` `assertive` `scope` `readable` `explanation` `expose` `h-letters` `h-weak` `h-famous` `h-pair-same` `h-error` `other`.

## ★ 보정 표본 6건 (VERIFY 가 먼저 읽고 정한 선 · 교훈 F)
1. **#3270 사라예보**("1992년부터 약 4년 세르비아계 군대에 포위 … 보스니아의 도시", 힌트 "1984년 겨울 올림픽이 열린 도시") — 질문 조건이 하나로 좁혀짐 · 힌트가 두 번째 줄 사실(올림픽) · 정답 글자 없음 → **ok**(사실은 문서로 열어 대조).
2. **#387 아파넷**(힌트 "미국 국방부 산하 고등연구계획국의 영문 약칭에 '망'을 덧붙인 이름이다") — 영문 약칭 ARPA + net = 정답 낱말을 풀어 쓴 조각(H2) → **fix h-letters**(다른 사실 힌트 제안 — 문서로 확인).
3. **#3472 개자추**(한식 · 산불로 타 죽은 진나라 충신) — 한식 유래의 인물로 하나 · 해설·힌트 다른 사실 → **ok**(전하는 한정 확인).
4. **#2174 조성**("으뜸음을 중심으로 곡의 분위기를 잡아 주며, 장조와 단조로 나뉘는 체계") — 일반어 정답 — '조(調)'·'음계' 같은 이웃 낱말이 후보인지 사전·위키로 보고, 질문 조건이 조성 쪽으로만 닫히면 ok · 이웃 낱말이 실제로 조건을 채우면 fix(변형 또는 한정어).
5. **#3737 플라톤 입체**(다섯 정다면체 → 철학자 이름을 따 무엇이라 — 정답에 '플라톤' 이 질문에 안 나옴 · 힌트는 이 철학자의 본명 아리스토클레스 일화) — 정답 글자(플라톤)는 힌트에 없음 → **ok**(일화 사실은 문서로).
6. **#5140 파라과이**(양면이 다른 세계 유일의 국기 · 뒷면 인장) — 단서가 질문 한 문장 · 해설 "경계와 방어를 나타낸다고 풀이된다"는 '풀이된다' 한정으로 ok → **ok**(V011 에서 확인한 문장).

## V018 추가 (CV-41 — 15 §3-2 한 줄, G013)
