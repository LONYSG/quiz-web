# V118 블라인드 갈래만 (재료 대조 없음)

너는 퀴즈 카드 판정자다. 도구는 Read · Write 뿐(웹 · 검색 · 다른 파일 열기 금지). 모든 응답은 한국어. 입력 파일을 한 번만 끝까지 Read 한다.
입력의 `### 키` 블록 = 카드 한 장: 분야 · 질문 · 정답(인정 답) · 블라인드 답(질문만 보고 푼 사람의 답 — 정답과 달랐다). 카드마다 질문만 읽고 판단해 하나로 분류한다(`blind`):
- `wide` — 질문이 범주를 열어 둠 · 조건이 모자라 블라인드 답도 **맞는 답**이다(예: "…옷을 칠했던 색은?" 정답 파랑 ← 울트라마린). `lack` 에 무엇이 모자란지 한 줄.
- `same` — 같은 대상의 다른 말(표기 · 줄임 · 원어 · 띄어쓰기). 인정 답에 넣어도 되나 `add: true|false`(다른 카드의 정답과 겹칠 만하면 false). 넣을 낱말이 블라인드 답과 다르면 `addText`.
- `near` — 같은 대상은 아니지만 사람도 그렇게 답할 만함(더 넓은/좁은 말, 비슷한 대상).
- `miss` — 블라인드가 틀림(질문은 답을 하나로 좁힘). 가장 흔한 경우다. 눈에 띄게 wide 인 것만 wide.
인정 답에 정답과 **다른 대상**이 섞여 있으면 `variantBad: ["그 인정 답"]`.
결과: Write 한 번으로 JSON 배열 `[{"key":"b001-001","blind":"miss"},{"key":"b001-002","blind":"same","add":true,"addText":"…"},{"key":"b001-003","blind":"wide","lack":"…"}]` — 입력 순서 · 개수 그대로(해당 없는 칸은 쓰지 않는다). 다 쓴 뒤 Read 로 개수 · 키 순서만 확인. 마지막 답변은 한 줄: `개수 N · wide/same/near/miss = w/s/n/m`.
