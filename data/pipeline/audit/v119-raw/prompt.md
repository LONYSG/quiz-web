# V119 판정자 지시 (Sonnet · 읽기 전용)
한국어 퀴즈 카드(질문 q · 정답 a · 힌트 hint · 해설 exp)의 **사실 주장**이 맞는지, **출처 페이지를 직접 열어** 구절과 견준다. 앞 판정자는 이 카드를 "기억으로" 넘겼다 — 기억으로 다시 ok 하지 말 것.
입력: 입력 json(카드 배열). 출력: 지정된 출력 경로에 JSON 배열 하나(Write 한 번, 그 뒤 Read 로 확인).
## 할 일 (카드마다)
1. q · hint · exp 의 검증 가능한 주장(연도 · 수 · 이름 · 장소 · "처음/유일/최초" 단정 · 인과)을 뽑는다.
2. 웹으로 연다: 위키 본문(ko/en `https://ko.wikipedia.org/w/index.php?title=...&action=raw` 또는 일반 페이지 · WebFetch), 공식 누리집. 403 이면 web.archive.org 로. WebSearch 는 출처를 찾는 용도로만 — **판정 근거는 직접 연 페이지 구절**.
3. 주장마다 구절과 견준다. 판정:
 - `ok`: 주장 모두가 연 페이지 구절로 맞음.
 - `fix`: 틀렸거나 단정이 지나침 — `fix:[{field:"q|hint|exp", span:"카드 글의 틀린 구절", why, right:"맞는 값/고친 문구", url, quote}]`
 - `drop`: 답이 틀렸거나 고칠 수 없음.
 - `unopened`: 페이지를 못 열어 확인 못 함 — 이유를 쓴다. **요약이나 기억으로 ok 로 메우지 말 것.** (주장 일부만 못 열면 열린 것은 판정하고 못 연 것을 `unopened:[…]` 에 적는다.)
4. 큰 일(수천 년 전 일화 · 설)은 "~전해진다"로 쓰였으면 설로 보고 ok. 문장을 매끄럽게 하자는 fix 는 내지 않는다(사실 · 단정 · 답이 하나인지만).
## 출력 항목 형식
{"id":"카드id","verdict":"ok|fix|drop|unopened","why":"한 줄","fix":[...],"web":[{"url":"연 주소","quote":"그 페이지 구절(짧게)","result":"맞음|틀림|못 찾음"}],"unopened":["못 연 주장"]}
카드 하나에 web 항목이 최소 하나(연 주소+구절). 입력 카드를 하나도 빠뜨리지 말 것(개수 대조함). 마지막 메시지는 한 줄.
