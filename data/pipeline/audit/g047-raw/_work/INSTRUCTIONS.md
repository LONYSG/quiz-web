# G047 라이어 제시어 재생성 — 조각 지시서 (모든 조각 같음)

너는 한국 파티 게임 "라이어 게임" 제시어 DB 를 **새로** 만든다(2026년 11월 기준 · 한국 20~50대 친구 모임이 플레이).
게임: 모두 같은 키워드를 받고 라이어 1명만 모른다 → 한 사람씩 키워드를 **한마디로 돌려 설명** → 라이어를 찾는다.
바보형 모드: 라이어에게 정답 대신 **비슷한 다른 단어(fool)** 를 정답인 척 보여 준다 → 라이어는 자기가 라이어인 줄 모른다.

## 입력
- 씨앗: `data/pipeline/audit/g047-raw/seed/seed.json`
  - `toz[]` = {citizen, imposter, page, section} — 외부 블로그의 쌍(961). **참고만** — 그대로 복사하지 말고 단어마다 판단.
  - `ours[]` = {word, topic, variants} — 우리 옛 open 세트(animal · food · job · place · instrument · sport · object · vehicle · movie-drama · character · fruit-vegetable · snack-drink · proverb · idiom4). proverb · idiom4 는 무시.
- 너의 담당 주제(브리프 아래 "담당")에 맞는 씨앗 단어를 **전부** 훑는다(toz 의 citizen · imposter 둘 다 + ours 해당 세트 + 다른 페이지에 흩어진 관련 단어).

## 출력 (주제마다 두 파일 — JSON · UTF-8)
1. `data/pipeline/audit/g047-raw/_work/out-<slug>.json` = 배열 40~60 개(목표 50):
   `{ "name": "김치찌개", "variants": [], "sub": "국물 음식", "era": "classic", "diff": 1, "fool": ["된장찌개", "부대찌개", "순두부찌개"] }`
2. `data/pipeline/audit/g047-raw/_work/drop-<slug>.json` = 씨앗에서 **보고 뺀** 관련 단어 배열 `{ "word": "...", "from": "toz|ours", "why": "유행|어려움|좁음|넓음|중복|논란|게임성|1글자|다른주제" }` — 담당 주제와 관련 있는 씨앗 단어는 남기든 빼든 **한 번씩** 판단한다(남긴 것은 out 에, 뺀 것은 drop 에).

## 단어 기준 (찬종 — 꼭 지킴)
- ⓐ **보편성**: 한국 20~50대 대부분이 아는 것. `era`:
  - `"classic"` = 세대 불문 레전드(김치 · 타이타닉 · 손흥민 · 피카츄)
  - `"modern"` = 2015 이후 정착해 2026 에도 누구나 아는 것(뉴진스 · 오징어 게임 · 쿠팡 · 탕후루는 X(한철) · 마라탕 O)
  - **한철 유행 · 올해 밈 · 특정 팬덤만 아는 것 · 해외에서만 유명한 것은 넣지 않는다.**
- ⓑ **게임성**: 한마디씩 돌려 설명할 거리가 여러 개 있어야 한다. 너무 넓은 상위어(음식 · 사람 · 동물 · 물건) X · 너무 좁은 것(특정 모델명 · 특정 회차 · 조연) X.
- ⓒ `diff` 1 쉬움(초등학생도) · 2 보통 · 3 어려움(아는 사람은 아는) — 세트 안 비율 ≈ **4:4:2**.
- ⓓ **2026 센스**: 씨앗에 없어도 지금 모두가 아는 것은 넣는다(세트의 ≤ 15%) — 예: 영화 "파묘" · 캐릭터 "쿠로미" · 브랜드 "다이소".
- ⓔ **1글자 name 금지** · 한 세트 안 상하위 중복 금지(라면 ↔ 컵라면) · 한 세트 안 name 유일.
- ⓕ **논란 인물 금지**: 정치인 · 범죄 · 사건 · 학폭/마약/음주운전 등 논란이 있었던 연예인 · 은퇴 논란 · 고인 중 비극적 사건으로만 유명한 경우. 의심되면 뺀다(drop why "논란").
- ⓖ name = 한국에서 가장 흔한 표기. `variants` = 실제로 치는 다른 표기만(띄어쓰기 · 대소문자 · 괄호는 자동으로 받으니 넣지 말 것) — 영문 표기는 사람 · 작품 · 브랜드 이름일 때만(BTS · Netflix · IU). 없으면 `[]`.
- ⓗ 특수문자 금지(name · variants · fool): 쓸 수 있는 것 = 한글 · 영문 · 숫자 · 빈칸 · 가운뎃점(·) · 하이픈(-) · 앰퍼샌드(&) · 콜론 · 마침표 · 쉼표 · 물음표 · 느낌표 · 아포스트로피. ♀ · ★ · 괄호 금지.

## fool (바보형 단어) — 가장 중요
- 항목마다 **2~3 개**(문자열 · 각 1~20자 · name 과 다름 · 같은 세트의 다른 항목이어도 되고 아니어도 됨).
- **같은 소분류(`sub`) 안**: 김치찌개(국물 음식) → 된장찌개 · 부대찌개 · 순두부찌개.
- **1:1 라이벌 · 고정 짝 금지**: 호날두↔메시 · 코카콜라↔펩시 · 삼성↔애플 · 맥도날드↔버거킹 · 톰↔제리 · 마블↔DC · 짜장면↔짬뽕 · 나이키↔아디다스 · 카카오톡↔라인 · 축구↔풋살 같은 "당연한 짝" 은 fool 에 넣지 않는다(라이어가 "아 내 건 바보 단어고 정답은 짝이구나" 하고 바로 안다).
- **같은 작품 · 같은 그룹 출신 금지**: 해리 포터 → 론 X · 뽀로로 → 크롱 X · 지민 → 정국 X.
- 기준: **fool 을 받은 사람이 남들 설명을 들어도 정답을 2개 이하로 좁힐 수 없다** + **너무 멀어서 첫 한마디에 들키지도 않는다**. 같은 소분류의 "비슷한 급 · 비슷한 인지도" 3개가 이상적.
- 좋은 예: 호날두 → 네이마르 · 손흥민 · 음바페 / 아이유 → 태연 · 볼빨간사춘기 · 백예린 / 김치 → 깍두기 · 된장찌개 · 파전? (X — 파전은 다른 소분류) → 깍두기 · 동치미 · 겉절이 / 타이타닉 → 노트북 · 라라랜드 · 비긴 어게인(로맨스 영화) / 펭귄 → 북극곰 · 바다표범 · 물개 / 스타벅스 → 투썸플레이스 · 이디야 · 메가커피 / 피아노 → 오르간 · 하프 · 신시사이저? (건반 소분류면 오르간 · 신시사이저 · 아코디언) / 소방관 → 경찰관 · 구급대원 · 해양경찰 / 지하철 → 기차 · 모노레일 · 경전철 / 우산 → 양산 · 우비 · 장화.

## 나쁜 예 (이렇게 하지 말 것)
1. "탕후루" — 한철 유행(2023) → drop 유행
2. "두바이 쫀득쿠키" — 올해 밈 → drop 유행
3. "아이폰 15 프로" — 너무 좁음(모델명) → drop 좁음
4. "음식" · "동물" — 상위어 → drop 넓음
5. fool 에 1:1 짝: 코카콜라 → ["펩시"] X
6. fool 이 같은 작품: 해리 포터 → ["론", "헤르미온느"] X
7. fool 이 너무 멂: 김치찌개 → ["피자", "초밥"] X(첫 마디 "빨갛고 국물" 에 들킴)
8. 특정 팬덤만 아는 아이돌 멤버 개인(그룹 대표 1~2명 정도만, 대중 인지도 기준)
9. 해외에서만 유명한 연예인(한국 대중이 모름) → drop 어려움
10. 논란 인물(마약 · 음주운전 · 학폭 · 정치) → drop 논란

## 형식 확인(끝나기 전에 스스로)
- out 배열 40~60 · 모든 항목에 name · variants(배열) · sub · era(classic|modern) · diff(1|2|3) · fool(2~3)
- name 2글자 이상 · 세트 안 유일 · fool 에 name 없음 · diff 비율 ≈ 4:4:2 · modern ≤ 절반
- 다 쓴 뒤 `node -e` 로 JSON 이 파싱되는지 확인.
- 다른 파일은 만들지도 고치지도 않는다(data/minigame 이하 금지 · git 금지).
- 마지막 답: 주제마다 "수 · era classic/modern · diff 1/2/3 · drop 수" 한 줄씩만.
