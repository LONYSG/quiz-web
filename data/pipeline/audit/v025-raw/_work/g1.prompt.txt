- ★★ **사실은 문서로만 닫는다 — 항목마다 `webOpen:TRUE` 이거나 재채점 결과가 4~5 이면 facts 의 url 을 WebFetch 로 직접 열어 주장마다 대조한다. 지식(내 기억)으로 true 를 달면 무효다. 문서를 못 열었거나 문서에 없으면 `unverified`(basis 는 web 일 때만 true/false 를 쓴다).** 질문 문장의 숫자·연도·동사·단정어를 문서 문장(`«…»`)과 글자 대조한다. 같은 url 은 항목당 한 번.
