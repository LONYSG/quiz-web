# G097 같은 정답 묶음 판정 기준 (모든 판정자 공통)

찬종(기획자) 원문 2026-11-16: "각도가 다르더라도 답이 같으면 웬만하면 하나만 두자. 사람들이 풀면서 '이거 나왔던 문제 아니야?' 라고 하더라. 숫자 같은 정답 말고, '백조의 호수'처럼 누가 봐도 유일한 존재로 인식되는 정답들은 좋은 문제 하나만 두고 나머진 지우자."

입력: `chunk-NN.json` — 묶음(gid) 배열. 묶음 = 정답(또는 다른 표기)이 겹치는 한국어 퀴즈 주관식 카드 2장 이상. 카드 칸: id · grade(등급, 낮을수록 쉬움) · answer · variants · question · hint · explanation · applied(새 글 실림 = 근거 선 카드) · sampleFix(표본 판정에서 고쳐진 적 있음) · gptWorth(`drop_candidate` = 문항 작성자가 "같은 문제 쌍의 끌 쪽"으로 표시) · gptNote · angle(재료 단계의 "같은 정답 문항과 가르기" 메모).

## 1. 묶음마다 verdict 셋 중 하나
- `one` — **유일한 존재로 인식되는 정답**: 작품 · 인물 · 사건 · 장소 · 물건 · 음식 · 개념 · 제도 · 생물 · 기관의 이름(백조의 호수 · 헨리 8세 · 미토콘드리아 · 떡볶이 · 뉴딜 · 아랍어 · 사르트르). 각도가 달라도(한 카드는 역사, 한 카드는 어원) **one** 이다. → 한 장만 남긴다.
- `keep_all` — **답이 흔한 값**이라 문제끼리 남남인 것: 숫자 · 연도 · 개수 · 색 · 방향 · 예/아니오 · 요일 · 계절 · 대륙 이름처럼 여러 다른 사실의 답으로 흔히 쓰이는 값(정답 "3" · "빨강" · "1945년" · "유럽" · "북쪽"). 두 카드가 같은 사실을 묻는다면 keep_all 이 아니라 one 으로 본다(같은 문제는 하나만).
- `ask` — 정말 가르기 어려운 것만. 대표: **동음이의**(정답 낱말은 같지만 가리키는 것이 다르다 — "진"(술) ↔ "진"(시황제의 나라), "퀸"(밴드) ↔ "퀸"(체스 말)). 묶음 안에서 일부만 같은 존재인 경우(3장 중 2장은 같은 것 · 1장은 다른 뜻)도 `ask` 로 두고 why 에 어느 id 들이 같은 것인지 적는다.
- 애매하면 `one` 쪽으로 기운다(찬종 "웬만하면 하나만"). 단 동음이의는 반드시 `ask`.

## 2. `one` 이면 남길 한 장(keep) — 순서대로
1. 근거가 선 카드: `applied: true` 이고 `sampleFix: false` 인 쪽.
2. **해설에 "오~ 그렇구나" 할 이야기가 있는 것**(뜻밖의 사연 · 유래 · 반전 · 재미있는 숫자). 사전 풀이를 되풀이한 해설보다 이야기가 있는 해설.
3. 질문이 대표 사실(그 정답을 가장 잘 떠올리게 하는 사실)을 친절하게 담은 것 — 꼬지 않고, 들으면 바로 "아 그거" 할 수 있는 질문.
4. 비슷하면 grade 가 낮은(쉬운) 쪽 · 그래도 비슷하면 id 가 작은 쪽.
- `gptWorth: "drop_candidate"` 인 카드는 **끌 쪽의 강한 후보**다(다른 카드가 명백히 나쁘지 않으면 끈다).
- 카드 문장을 고치거나 새로 쓰지 않는다. 고르기만 한다.

## 3. 출력 (반드시 이 형식 · 파일 하나 · 다른 말 없이)
`result-NN.json` = 객체. 입력의 **모든 gid 가 키로 한 번씩**(누락 0):
```json
{
  "S0001": { "verdict": "one", "keep": 123, "why": "같은 작품 · #123 해설에 초연 실패 이야기 · #456 은 사전 풀이" },
  "S0002": { "verdict": "keep_all", "keep": null, "why": "숫자 3 — 서로 다른 사실" },
  "S0003": { "verdict": "ask", "keep": null, "why": "동음이의 — #99 술 진 · #4861 진나라" }
}
```
- `keep` 은 `one` 일 때 그 묶음의 id 하나(숫자) · 그 밖에는 null.
- `why` 는 한국어 한 줄(60자 안팎) — 왜 그 판정 · 왜 그 카드.
