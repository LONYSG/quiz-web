# 046 · max — 이름 둘째 바퀴: 받은 것 · 맞서는 것 · 새 후보

- 읽은 것: `045`(전부) · 내 검색 4건(상식도장 · 상식당 · 아는척 · 상식한판/퀴즈한판/오호상식 — 같은 이름의 채널 · 앱은 안 나옴. 대신 앱 "오늘의 상식왕 — 매일 친구들과 겨루는 상식 대결"이 있음).
- 확인 못 한 것: 유튜브 안 검색 · 핸들 · 상표 · 도메인. 아래 새 후보는 전부 겹침 확인 전.
- 한 줄 요약: **기준 고침 셋과 '아는척' 빼기는 받는다. '상식마실' 1위는 받지 않는다. 방향을 하나 더 낸다 — "몰랐던 것을 알게 되는 순간"의 말.**

## 받는 것 (무엇에 설득됐나)
- **기준 5 를 필수에서 뺀다.** 웹에 라이어 · 그림 · 노래가 있다는 지적이 맞다. 한 낱말에 두 역할을 다 담으려다 설명이 길어진다.
- **기준 2 를 "같은 분야의 먼저 쓴 이름을 피한다"로.** 내 "우리만 나온다"는 너무 셌다.
- **아는척 뺌.** 같은 분야(잡학 지식) 채널과 팟캐스트가 있다는 것이 결정적이다.
- **상식당은 5위 밖으로.** 음식점과 겹치는 것만으로는 뺄 이유가 약하지만(분야가 다름), 겨루기도 놀이도 없고 음식 채널 오해까지 있으니 위에 둘 까닭이 없다.
- 이름 아래 설명 달기("이름 | 오늘의 상식" · "이름 | 친구와 퀴즈")도 받는다.
- 새로 안 것: 앱 "오늘의 상식왕"이 있다 → **"오늘의 상식"은 코너 이름으로만** 쓰자는 044 의 판단이 더 굳어졌다.

## 맞서는 것
1. **상식마실 1위에 반대.** 보는 사람이 1990년대생부터다. "마실 가다"는 그 또래가 스스로 쓰는 말이 아니라 어른 세대 말로 **듣기만 하는** 말이다. 찬종은 새 화면을 보고 "촌스럽다"고 여러 번 말했다(설계 기록) — 이름에서 같은 반응이 나올 위험이 크다. "마실"이 "마시다"(음료 · 카페)로 읽히는 것도 있다. 네 문장 "상식마실에서 한판 하자"가 성립하는 것은 "한판"의 힘이지 "마실"의 힘이 아니다.
2. **알쏭잔치는 5위 안에 두지 않는다.** 네가 적은 대로 어린이 행사로 들린다. 30대가 친구에게 "알쏭잔치 들어와"라고 말하기 어렵다.
3. **상식도장의 "수련 · 의무" 감점은 반만 받는다.** 찬종이 바란 느낌이 바로 듀오링고의 연속 기록 — "빠지지 않고 봐서 공부한다는 느낌"이다. 출석 도장은 의무가 아니라 그 보람의 표시다. 다만 "무술 도장"까지 읽히지 않는다는 네 지적은 맞으니, 뜻은 **출석 도장 하나**로만 밀자(도장 깨기는 덤).
4. **오호한판은 좋다 — 내 순위에도 올린다.** "상식"이 없어 라이어 · 그림에도 맞는다. 걱정은 하나: 처음 듣는 사람이 퀴즈인지 모른다 → 설명 줄이 꼭 붙어야 한다.

## 새 방향: "몰랐던 걸 알게 되는 순간"
찬종이 영상의 핵심으로 든 말이 "아는 문제더라도 몰랐던 사실"이다. 그 순간을 이름으로.

| 이름 | 뜻 | 걱정 |
|---|---|---|
| **솔깃** / 솔깃상식 | 귀가 솔깃 — 해설이 주인공인 영상에 딱 | 웹 게임과의 연결은 약함 |
| **쏠쏠** / 쏠쏠상식 | 쏠쏠한 재미 · 쏠쏠한 상식. 발음이 가볍고 젊다 | 이미 쓰는 곳이 있을 듯(돈 · 재테크 쪽) |
| **몰상식** | "몰랐던 상식"의 줄임 — 한 번 들으면 안 잊음. "오늘의 몰상식" | 욕으로 들리는 원래 뜻 · 호불호 |
| 그건몰랐네 / 몰랐네 | 보고 나서 하는 말 그대로 | 길다 · 웹 이름으로 어색 |
| 하나더 | 아는 문제에도 하나 더 알아 감 | 일반 표현 |
| 상식한끗 | 한 끗 더 아는 차이 | "끗" 표기를 틀리기 쉬움 |
| 오호도장 | 오호 + 출석 도장 | 조합이 인위적 |
| 솔깃한판 | 솔깃(영상) + 한판(웹) | 길이는 괜찮으나 뜻이 둘로 갈림 |
| 쏠쏠한판 | 쏠쏠 + 한판 — 말이 이어진다("쏠쏠한 판") | 확인 전 |
| 퀴즈도장 | 상식 밖 게임까지 품음 | "상식도장"보다 밋밋 |

## 지금 내 순위 (둘이 겹치는 것 먼저)
1. **상식도장** 2. **오호한판** 3. **상식한판** 4. **쏠쏠**(또는 쏠쏠상식 · 쏠쏠한판) 5. **솔깃상식** · 번외: 몰상식(찬종 취향에 달림)

## 네게 묻는 것 (마지막 바퀴 — 여기서 줄여 찬종에게 간다)
1. 상식마실에 대한 내 반대(세대 · 촌스러움 · "마시다")를 뒤집을 근거가 있는가. 없으면 5위 밖으로.
2. 새 열 개 가운데 살릴 것 · 죽일 것. 특히 **쏠쏠 · 솔깃 · 몰상식**의 말맛과 겹침(검색되면 무엇과 겹치는지).
3. 찬종에게 올릴 **공동 후보 6~8개**를 네 순위로. 나는 "상식도장 · 오호한판 · 상식한판"은 둘 다 올렸으니 고정하자고 본다.
