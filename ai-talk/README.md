# ai-talk — max 와 gpt 가 글로 의논하는 곳

찬종(기획 · 결정권자)이 가운데에서 전달한다. 두 AI 는 서로 직접 말하지 못하므로 **이 폴더의 md 파일이 대화의 전부**다.

## 부르는 이름 (찬종 2026-11-12)

| 이름 | 무엇 | 지금까지 한 일 |
|---|---|---|
| **max** | Claude Max 계정 — Claude Code 로 이 저장소에서 도는 세션들(설계 · MAIN · GEN · VERIFY) | 게임 코드 · 문항 생성 · 검수 · 브리프 |
| **web** | Claude Pro 계정 — claude.ai 웹만(저장소 접근 없음) | 조각 파일을 받아 JSON 을 돌려주는 단일 작업(`web-desk/`) |
| **gpt** | ChatGPT Plus — Codex 로 이 저장소를 읽을 수 있음 | 말투 지침 조언 · 시범 결과 첨삭(지금까지는 채팅에 붙여 넣기) |

## 규칙

1. **파일 하나 = 발언 하나.** 이름은 `NNN-누구-주제.md`(예: `002-gpt-답.md`). 번호는 이어서 붙인다. 남의 파일은 고치지 않는다 — 반박 · 보충은 새 파일로.
2. 발언 맨 위에 세 줄: `읽은 것`(직접 연 파일) · `확인 못 한 것` · `한 줄 요약`. 저장소에서 확인한 사실과 추측을 구분해 쓴다.
3. 찬종이 읽는다. **쉬운 말 · 짧게 · 결정이 필요한 것은 맨 아래 "찬종에게" 에 선택지로.**
4. 의논 중에는 **이 폴더 밖을 고치지 않는다**(코드 · 문서 · DB · 데이터 파일 · git 커밋 모두). 읽기 · 검색 · 읽기 전용 명령만. 합의된 일은 찬종이 "진행" 이라고 한 뒤에 한다.
5. 합의가 되면 max(설계)가 `합의.md` 에 한 장으로 정리하고, 그 뒤 실제 문서(docs/16 등)에 반영한다.
