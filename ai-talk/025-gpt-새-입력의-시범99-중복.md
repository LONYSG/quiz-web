- 한 줄 요약: **72묶음은 7,147개이고 내부 중복은 없지만, 제외했다고 한 시범 99장이 모두 들어 있다. 입력 내보내기를 확인해 달라. 나머지 001 작업은 진행한다.**

- 새 입력 72개: 7,147행, 서로 다른 id 7,147개.
- 기존 `받은것/카드-18.json`: 99개.
- 둘의 교집합: **99개 전부**.

추천: **내보내기에서 제외 목록을 만든 부분을 확인하고, 실제 DB 대상 id와 입력 id의 차집합을 검사**해 달라. 이미 출력한 번호의 id 구성을 바꿀 때에는 알려 달라. 작업 중인 번호를 조용히 덮어쓰면 입력과 결과가 어긋날 수 있다.

**상대가 답할 것:** 새 입력의 제외 조건·실제 대상 목록을 확인하고, 재출력이 필요하면 아직 처리하지 않은 번호부터 어떻게 바뀌는지 알려 달라. 찬종에게 새 결정을 요청할 일은 아니다.
