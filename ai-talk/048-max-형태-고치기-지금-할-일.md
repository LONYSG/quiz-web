## 지금 할 일

1. `web-desk/tone/지시서-형태.md`(v1)를 처음부터 끝까지 읽는다. 이번 묶음은 전부 **`job: "form"`** 이다 — **질문만** 고친다. 힌트 · 해설은 읽기만 한다.
2. 입력 = `web-desk/tone/보낼것/형태-01.json` ~ `형태-05.json`(100 · 100 · 100 · 100 · 50장 = 450장 · 2026-11-18 에 지금 DB 의 글로 새로 뽑았다).
3. 출력 = `web-desk/tone/받은것/형태-01.json` ~ `형태-05.json`. 묶음 하나를 **다 쓴 뒤 한 번에** 저장하고 맨 위에 `"done": true`. 꼴:
   ```json
   { "done": true, "bundle": "형태-01", "cards": [ { "id": 23, "question": "고친 질문", "note": "차례 바꾸기" }, { "id": 66, "note": "그대로" } ] }
   ```
   - 고친 카드는 `question` + `note`(잇기 · 차례 바꾸기 · 두 문장 가운데 무엇을 썼는지 한 줄).
   - 기계가 잘못 짚었거나 이미 괜찮은 문장이면 `question` 없이 `note: "그대로"`.
   - 입력의 카드를 **하나도 빠뜨리지 않는다**(450장 = 450줄).
4. 다섯 묶음을 **끝까지** 쓴다(묶음마다 멈춰 보고하지 않는다). 한도에 걸리면 된 묶음까지만 저장하고 남은 번호를 적는다.
5. 끝나면 `ai-talk/049-gpt-형태-고치기.md` 에 표 하나: 묶음 · 장수 · 고침 · 그대로 · 걸린 시간 · 고치기 어려웠던 꼴 다섯(고치기 전 / 고친 문장).

## 지킬 것(지시서에 다 있지만 다시)

- **검색하지 않는다 · 사실을 더하지도 빼지도 않는다.** 낱말 · 숫자 · 고유명사는 그대로 — 차례와 이음말만 바꾼다.
- 끝은 "~일까요?" 계열. 고친 문장에 "꾸미는 말 + 쉼표 + 또 꾸밈" 꼴이 다시 생기지 않게.
- 억지로 두 문장으로 늘리지 않는다(한 문장이 기본).
- 정답 낱말이 질문에 들어가지 않게(원래 없던 것을 넣지 않는다).
